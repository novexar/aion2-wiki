## A. 右側チャットパネル

- [ ] ヘッダーの「チャット」を、ページ遷移ではなくパネルの開閉トグルにする（キーボード: `Ctrl+J`。`aria-expanded`、`aria-controls`）。`/chat` ルートは残し、開くとパネルを開いた状態でホームにリダイレクト（既存リンク互換）
- [ ] パネルは `lg`（1024px）以上で右端に固定幅 `24rem`（min 20rem / max 40rem、左端ドラッグでリサイズ可、幅は localStorage に保存）。開いている間は本文グリッド（WikiShell / ホーム / 索引）が `calc(100% - パネル幅)` に縮み、オーバーレイで覆わない（本文を左に押し出す）
- [ ] `lg` 未満は全画面シート（上からヘッダー付き、閉じるボタン）。本文は隠れる
- [ ] 開閉状態は localStorage に保存し、再訪時に復元。初回は閉じている
- [ ] パネル構成（上から）: タイトル行「チャット」＋「新しい会話」「履歴」「閉じる」ボタン（アイコンのみ可、`aria-label` 必須、装飾なし）／ メッセージ一覧（内側スクロール）／ 入力欄（複数行、`Enter` 送信・`Shift+Enter` 改行、送信中は停止ボタン）
- [ ] 既存の RAG・ストリーミング・引用チップ・API キー設定（未設定時はパネル内に設定フォームを表示）をそのまま使う。文言は監査の規則どおり（説明過剰にしない）
- [ ] 記事ページでパネルを開いたとき、入力欄の上に「この記事を文脈に含める」チェック（既定 ON）を置き、ON なら現在記事のチャンクを検索結果の先頭に加える
- [ ] 右目次（Issue #5 C）とパネルが同時に表示される場合、目次は本文カラム右端に残し、パネルはさらにその右。幅が足りない（本文 < 40rem）場合は目次を非表示にする

## B. 履歴のローカル永続化

- [ ] 保存先は IndexedDB（`idb` パッケージ可）。sessionStorage の既存実装を置き換える。スキーマ: `conversations {id, title, createdAt, updatedAt}`、`messages {id, conversationId, role, content, citations, createdAt}`。容量目安 5MB 超で古い会話から警告
- [ ] 会話は複数持てる。「履歴」でリスト（タイトル＝最初の質問の先頭 30 文字、更新日時順）、クリックで切替、各行に削除。「すべて削除」は確認ダイアログ付き（ブラウザの `confirm` は使わず自前のダイアログ）
- [ ] 自動削除・期限切れはしない。消すのはユーザー操作のみ
- [ ] API キーは従来どおり localStorage。履歴の書き出し（JSON ダウンロード）を設定ページに置く（任意）
- [ ] ストレージが使えない環境（プライベートモード等）では、保存できない旨を 1 行で表示しメモリ上で動作
