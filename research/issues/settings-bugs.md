オーナー報告（2026-10-08、ライブサイト確認後）の不具合 2 件。

## 1. 設定を開くと閉じる手段がない

現状: ヘッダーの設定アイコンを押すと設定画面が開くが、閉じる操作がない（アイコンを再度押しても閉じない）。

改修:
- [ ] 設定アイコンをトグルにする。設定が開いている状態で再押下すると閉じて元のページへ戻る（`/settings` ルートなら直前のページへ `navigate(-1)`、履歴がなければホーム）。`aria-pressed` / `aria-expanded` を付ける
- [ ] 設定画面の右上に「閉じる」ボタン（× アイコン、`aria-label="閉じる"`）も置く。`Escape` でも閉じる
- [ ] 設計上は、設定をページではなく右側パネル（チャットパネルと同じ仕組み、同時には片方だけ開く）にしてもよい。工数が小さい方を選ぶが、どちらでも上記の閉じる手段は必須
- [ ] モバイル（390px）でも閉じるボタンが見える位置にあること

## 2. Gemini モデル選択のドロップダウンが開かない（Android で確認）

現状: 設定の「モデル」ドロップダウンをタップしても候補が表示されない。デスクトップでは未確認。

改修:
- [ ] 原因を特定する（カスタム listbox が `pointer`/`hover` 前提になっている、`touchstart` で閉じている、`position: fixed` 要素が透明で描画されていない、など）。Playwright の Android エミュレーション（`devices['Pixel 7']`、`hasTouch: true`、Chrome Android UA）で再現してから直す
- [ ] 修正方針: ネイティブ `<select>` を使う（スタイルは `appearance-none` ＋ 右端の矢印で統一）。モバイルでは OS 標準のピッカーが開くので最も確実。候補は現行のモデル一覧（最新 flash / pro 系）＋「その他（手入力）」で、手入力時はテキスト欄を表示
- [ ] デスクトップ（マウス）・キーボード（↑↓ Enter）・タッチの 3 通りでテストを追加
- [ ] 同様のカスタムドロップダウン／ポップオーバーが他にあれば（テーマ切替、履歴メニュー等）同じ観点で点検し、結果を Issue に記載
