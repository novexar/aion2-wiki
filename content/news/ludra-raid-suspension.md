グローバル版で唯一の10人レイド「深淵の再錬：ルドラ（Sanctuary Raid: Ludra）」は、正式サービス開始の10月5日に**一時的に削除**されました。現在、ゲーム内の聖域メニューからルドラには入れません。この記事は公式告知の内容と、復帰まで新規プレイヤーが知っておくべきことをまとめたものです。

根拠：[S01] [S02]

## 公式告知の要点

NC は10月5日に「Update on Sanctuary Raid」という告知を出しました。

| 項目 | 内容 |
| --- | --- |
| 何が起きた | 正式サービスのビルドでルドラを一時的に削除 |
| 理由 | アーリーアクセス期間に、NC の想定より低い育成段階で討伐された。同じ戦闘をそのままグローバルで出したくない |
| 復帰後 | 核となる戦闘の雰囲気は残しつつ、「このバージョン固有の新しい・調整されたギミックと攻撃パターン」を追加 |
| 復帰日 | 未定。**10月16日までに**復帰日と First Clear イベントの詳細を案内 |
| EA の討伐者 | 欧州リージョンでアーリーアクセス中に討伐した全員に記念称号。他リージョンについては言及なし |
| EA で得たルドラ装備 | 一時的に削除。復帰時に入手者へ返還し、強化に使った素材も補填 |
| First Clear | 復帰時に新しい初回討伐イベント。固有の報酬と、リセットされる「殿堂」への掲載 |

根拠：[S01] [S02]

> **注意**：公式告知ページ本体は JavaScript 描画のためタイトルの確認に留まります。内容は公式告知を直接引用した AION2 Hub と AION2 Times で照合しました。

## ルドラとはどんなコンテンツか

- 10人（5人×2パーティ）で挑む聖域レイド。グローバル版の開始時点で唯一の聖域。
- 入場条件は Lv45・合計アイテムレベル 2,800。報酬キューブの受取にオードエネルギー40（アジア版は80）。
- 週1回の報酬付き討伐。報酬には取引可能ギーナ1,000,000や、IL102 の唯一（金）武器などが含まれる。
- 道中にラフ（Rahu）・ケトゥ（Ketu）の中ボスがあり、最終ボスがルドラ。

根拠：[S03]

## 新規プレイヤーへの影響

1. **当面の目標は IL2,800 まで**。ルドラは復帰後も入場条件が変わる可能性があるため、復帰告知を待ってから最終目標を決めてよい。
2. **深淵のブレスレット（Abyssal Bracelet）など「ルドラ経由」の装備は今は入手できない**。全身を唯一（金）にする計画で、ブレスレットの2枠目をルドラ品に頼っていた場合は、復帰まで保留になる。
3. **ルドラ用のオードエネルギーを貯めておく必要はない**。上限（560／会員840）を超えると回復が止まるので、遠征・超越で使う（[[odyle-energy]]）。

根拠：[S02] [S03]

## 韓国版との違い

韓国版では聖域が複数あり（侵食の浄化所、ムスペルの聖杯、悲嘆の雪原など）、ルドラは初期の聖域です。グローバル版はルドラ1つから始まり、他の聖域の実装時期は未発表です（[[korea-update-history]]）。

根拠：[S04]
