NC はグローバル版の開始に合わせて「Launch FAQ」を公開しています。遊ぶ前に知っておくべき大枠（どこで遊べるか、何が有料か、何が引き継げないか）がまとまった公式文書です。この記事はその要点を日本語で整理したものです。

> **注意**：公式告知ページは JavaScript で描画されるため、本 Wiki の調査ではタイトルの存在確認までしか直接できていません。本文の内容は、公式告知を引用して「NC written」と明記している Aion 2 Maps と Aion 2 viki、日本公式 FAQ を引用する AION2 Times の3資料で照合しました。最終的な文言は公式サイトで確認してください。

根拠：[S01] [S02] [S03] [S04]

## プラットフォームとアカウント

| 項目 | 公式 FAQ の内容 |
| --- | --- |
| 対応プラットフォーム | Windows PC のみ。Steam と NC PURPLE。ゲーム内容は同じで、サーバーも共通 |
| Steam と PURPLE の行き来 | Steam キャラクターは Steam ログインで PURPLE からも遊べる。逆は NC アカウントに Steam を連携してから |
| スマホ・コンソール | グローバル版は PC 専用。コンソール版は「準備中」だが機種・時期は未発表（[[roadmap-and-upcoming]]） |
| コントローラー | 「遊べるが、公式にはサポートしていない」 |
| Linux・Steam Deck | 「遊べるかもしれない」。公式サポートは Windows の Steam／PURPLE のみ |
| Twitch 連携 | Twitch Drops は実際に遊んでいるアカウント（Steam か NC）と連携する（[[twitch-linking-pitfalls]]） |

根拠：[S03] [S04]

## 地域と言語

- サーバーリージョンは5つ：北米東部、北米西部、欧州、南米、アジア（東京）。リージョンロックは無く、どこからでも選べるが、キャラクターをリージョン間で移動することはできない。
- 18の国と地域（中国、韓国、台湾、ロシア、ベルギー、オランダなど）からはプレイも決済もできない。日本は対象外。
- 対応言語は英語・フランス語・ドイツ語・スペイン語・ポルトガル語（ブラジル）・ロシア語・日本語・韓国語の8言語。中国語は無い。音声は英語・日本語・韓国語。

根拠：[S03] [S04]

## 課金方針

- 基本プレイ無料。ショップの装飾アイテムは「ゲームプレイ・戦闘上の優位を与えない」、消耗品は「通常プレイでも入手でき、装備成長や長期的な戦闘力に影響しない」と説明されている。
- 月額の「クァイリン特級メンバーシップ」（14.99ドル／日本では2,350円）は任意。取引所の購入、交換所（ギーナ↔キューナ）、遠隔倉庫などが会員向け（[[membership]]）。
- ボット対策として、プレイヤー同士の直接取引は無効化されている。取引は取引所経由。

根拠：[S03] [S05]

## 引き継ぎと移行

| 質問 | 答え |
| --- | --- |
| 韓国・台湾版のデータを引き継げる？ | できない。別サービス |
| Launch Scale Test のデータは？ | 全消去。名前の予約も無し |
| 同じ名前は作れる？ | 同一サーバー内では重複不可。別サーバーなら同名可 |
| キャラクター枠 | 最初4枠、最大8枠（追加は1枠1,000キューナ） |

根拠：[S03] [S04] [S05]

## 混雑時の扱い

満員サーバーでは「良好な状態の会員（members in good standing）」が優先待機列に入ります。運営処分中やルール違反の疑いがあると優先列から外れます。FAQ は「会員」の定義を明示していません。

根拠：[S03]

## この FAQ を読むときのコツ

1. 「できない」と書かれていることは、後の告知で変わることがある（例：ファウンダーズパックの外形がアカウント共通になる変更）。日付の新しい告知を優先する。
2. 価格は米ドル表記が基準。日本円は別の告知で確認する（[[membership-jp-price-notice]]）。
3. 日本語版の公式サイト（aion2.plaync.com/ja-jp）にも同じ告知が翻訳されるが、翻訳の時差があるため、急ぐときは英語版も見る（[[jp-official-channels]]）。
