日本向けの公式コラボは、現時点では「ゲーム内のイベント」ではなく、公式X（@AION2_JP）での抽選応募や、現地の施設での企画が中心です。この記事では、期間・応募方法・賞品・注意点をまとめます。ゲーム内で受け取れる報酬のイベントは [[community-launch-events]] と [[twitch-drops-and-war-for-atreia]] を参照してください。

根拠：[S01] [S02]

> **注意**：応募条件や賞品は変更されることがあります。応募は必ず公式Xのキャンペーン投稿と、キャンペーンサイトの規約で確認してください。この Wiki は応募の窓口ではありません。

## 森永製菓「エンゼルパイ」コラボ

エンゼルパイを天族、デビルズパイを魔族に見立てた企画です。公式の案内に、コラボパッケージの店頭販売やゲーム内イベントとの連動は書かれていません。

| 項目 | 内容 |
| --- | --- |
| 応募期間 | 2026年9月8日（火）〜10月15日（木） |
| 応募方法 | AION2 公式X（@AION2_JP）と森永製菓公式X（@morinaga_angel）の両方をフォローし、9月8日のキャンペーン対象ポストをリポスト |
| 当選人数 | 合計330名（抽選） |
| 応募資格 | 日本国内に在住し、郵便物を受け取れること。賞品の発送時点まで両アカウントをフォローしていること |
| 無効になる場合 | Xアカウントが非公開、ポストが検索対象外、リポストを削除、DMを受け取れない設定 |

根拠：[S01]

- 外見変更券は「配布から30日以内にキャラクターの外見を1回変更できる券」と説明されていますが、配布の時期や方法は案内に書かれていません。
- 当選者には X のDMで通知されます。指定の期日までに回答する必要があります。
- 賞品の発送は11月下旬から12月下旬の予定です。
- 賞品の転売や譲渡は避けるよう明記されています。抽選結果や抽選方法の問い合わせには答えない旨も記載されています。

根拠：[S01]

10月5日の正式サービス開始をはさむ長い期間なので、始めてから応募しても間に合います。

## バンジージャパン「岐阜バンジー」コラボ

日本で最も長い215m落下の「岐阜バンジー」で、AION2 のキャラクターのような翼を表現した「AION2 コラボ特製ウイングスーツ」を着て挑戦できる企画です。

| 項目 | 内容 |
| --- | --- |
| 期間 | 2026年10月5日（月）〜2027年3月3日（水） |
| ウイングスーツ | 1着のみ。着用希望は予約前にバンジージャパンのコールセンターへ電話連絡が必要（0278-72-8133、年中無休 8:30〜17:30） |
| 掲示物 | 国内の運営6施設に AION2 のポスターと巨大フラッグ（フラッグは10月10日以降） |
| 注意 | 営業予定は各施設で異なる。富士バンジーは11月1日に営業再開予定、みなかみバンジーは10月31日までの設置 |

設置されるのは岐阜バンジー（岐阜）、竜神バンジー（茨城）、猿ヶ京バンジー（群馬）、富士バンジー（静岡）、開運バンジー（奈良）、みなかみバンジー（群馬）です。

根拠：[S02]

## ストリーマー PR 配信（10月6日〜）

日本公式は、10月6日から順次、ストリーマーによる PR 配信を行うと案内しています。天族側に SHAKA、Zerost、しゃるる、おぼ、若桜有理。魔族側に関優太、Clutch_Fi、トナカイト、猫麦とろろ、シスルの計10名が告知されています。

根拠：[S02]

## 正式サービス開始時の同時接続者数の発表

NC は10月6日に、正式サービス開始直後の同時接続者数が40万人を超えたと発表しました（[[player-numbers-and-reception]]）。同日、Steam の「売上上位」「人気の新作」「話題の無料作品」の3部門で同時に1位とも発表されています。

根拠：[S02]
