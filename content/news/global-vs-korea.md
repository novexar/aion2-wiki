グローバル版 AION2 は、韓国・台湾で2025年11月19日に始まったゲームの「そのままの輸出」ではありません。NC は gamescom で「シーズン1を、1年分の品質改善とバランス調整を折り込んだ形で出す」と説明しており、レベル上限・クラス数・装備の上限・成長数値・経済が韓国版と違います。この記事は、韓国版や台湾版の攻略動画・ティア表を見る前に押さえるべき差の総覧です。

根拠：[S05] [S01]

> **注意**：差の多くはクライアントのデータ抽出（datamine）と配信の観察に基づく非公式な整理です。NC がパッチノートで一覧にしたものではありません。ゲーム内の表示が最優先です。

## 一目でわかる主要な差

| 項目 | グローバル版（2026-10-05〜） | 韓国・台湾版 |
| --- | --- | --- |
| レベル上限 | 45 | 50（2026-07-01 の Chapter 1 以降） |
| クラス数 | 8（拳星／Brawler なし） | 9（拳星あり） |
| 装備の最上位等級 | 唯一（金）。アイテムレベル最大102 | 英雄（赤）あり。8月12日には6ティアの英雄アクセサリーも追加 |
| プラットフォーム | PC のみ（Steam と PURPLE） | PC＋モバイル |
| メンバーシップ | 1種類、30日 $14.99（日本 2,350円）。サーバー単位 | 2種（約45ドル相当）とする資料と、2026年6月17日に1種へ統合されたとする資料がある（S06） |
| 拡張エリア | ヴェルテロン、アルトガルド、混沌のロワー・レシャンタ | 上記に加えエルテネン（天族）とモルヘイム（魔族）のLv46以上 |
| 遠征 | 6種。Hard モードと試練（Ordeal）なし | 追加の遠征が多数 |
| 聖域 | ルドラのみ（現在は一時削除中） | 複数 |
| シーズン | シーズン1（2026-09-30〜12-16） | シーズン2以降、2026年7月から「チャプター」制 |

根拠：[S01] [S02]

## 位置づけ：「調整済みシーズン1」

- グローバル版は「韓国版が最初に出したシーズン1の改良版」で始まる。シーズン2の更新や Chapter 1 など、約1年分の内容は NC の手元に温存されている。
- NC は「韓国版を近いモデルとして追い、新シーズンはおよそ3か月ごと」と述べたが、韓国版との日付差は「どのくらい遅れるか未定。速くも遅くもなりうる」としている。
- 韓国版の2026年3月25日パッチ（全クラス改修、ディーヴァニオンとスティグマの構造、通常ギーナ／刻印ギーナの区別、PvP／PvE 能力値の分離）は、グローバル版が開始時から取り込んでいる。

根拠：[S05] [S02]

## クラスと戦闘

- **クラス**：8クラス。拳星（Brawler）は作成できません。ただし「Lv45までのスキル構成は韓国版 2026-09-16 パッチ後のもの」で、9月23日の2点（ローブ・オブ・コールドの足止め、グラディエーターの突進の方向補正）だけ未反映とされます。
- **スティグマ**：レベル上限20（韓国版25）、スロットは4つでLv22／27／32／37に解放。クラスごとに13種。
- **スキル／スティグマポイント**：Lv45時点でスキル203・スティグマ29（韓国版は231・23）。
- **クリティカル／回避の上限表示**：ツールチップ上は会心50%・回避30%（韓国版80%・50%）。
- **ボスの床攻撃**：予兆から着弾までが24フレーム（韓国版8）とする報告が1件あります。単一資料のため参考扱いです。

根拠：[S01]

> **韓国版のみ**：クラス調整は毎週続いています。韓国版のティア表や「最強」の断定はグローバル版の数値に当てはまらないので、[[class-tier-and-recommendation]] の注記を優先してください。

## 装備と強化

| 項目 | グローバル版 | 韓国・台湾版 |
| --- | --- | --- |
| 最上位等級 | 唯一（金）。英雄・神話装備なし（製作でも作れない） | 英雄（赤）あり |
| 装備枠 | 20（ペンダント、ブローチ、印章なし） | 追加枠あり |
| 強化上限 | レア+5／エピック+10／唯一+15 | +10／+15／+15 |
| 強化1段の伸び | アイテムレベル依存で小さい（唯一武器+15でIL36なら攻撃力+61、IL102なら+174） | 一律225 |
| 翼 | 翼の強化なし。遠征の翼は征服から封印状態でドロップ（最終ボス0.75%、中ボス0.25%） | 翼強化システムあり |
| フィールド | 精錬石や唯一装備のドロップは約4分の1 | — |

NC は配信で「少なくともシーズン1は英雄等級の装備を入れない。製作でも英雄は作れない」と明言しました。理由は進行ペースを抑えるためです。配信では「韓国版」とは名指ししませんでした。シーズン1の期間そのものも、配信では説明がありませんでした。

根拠：[S01] [S04]

## 成長システム

- **ディーヴァニオン**：ボードは5枚（ネゼカン、ジケル、ヴァイゼル、トリニエル、アズフェル）。アリエルはなし。ネゼカン・ジケル・ヴァイゼルは各134（韓国版210）、トリニエルは168。ステータスノードは弱く、スキルノードは同じ。韓国版にあるマルクタンとユスティエルのボードはありません。
- **パンテオン**：能力値は10種すべて半減（1ポイント0.1%、韓国版0.2%）。
- **称号**：半数は隠し、表示される称号の効果も弱め。
- **ペット**：207種、レベル上限3。ナチュラ系はMPでなくスタミナ。
- **ペット種族理解度（Genus）**：分析4クリスタル、洞察1→10に250,000ギーナなど、安くなった一方、スマイトはスペシャルボードの4枠目のみ。
- **賢者の石**：モノリスからは出ない。地域クエストが1キャラ58、自地域の封印ダンジョン61か所が各2＋ディーヴァニオンクリスタル2。

根拠：[S01]

クエストの目的地への自動転送が少ない（43件対583件）ため、レベリングの移動時間は韓国版より長い傾向があります。ヴェルテロン／アルトガルドの本編が求める討伐数も約1.9倍です。

根拠：[S01]

## 経済・課金

- **直接取引**：プレイヤー間の直接取引は「ボット対策」として無効。取引所は Lv45 で解放、購入にはメンバーシップが必要（[[trading-rules]]、[[market-and-exchange]]）。
- **メンバーシップ**：「クァイリン特級メンバーシップ」1種のみ。30日 $14.99、サーバー単位（[[membership]]）。韓国版の2段階前提（約45ドル相当）の計算を持ち込まないこと。
- **オードエネルギー**：全員3時間に15、上限560（メンバー840）。韓国版は無料10／メンバー15とする報告があり、グローバル版は全員15です（[[odyle-energy]]）。
- **ショップ**：外見品中心で「ゲームプレイ上の有利なし」と明記。韓国版では発売直後に能力値に影響する品をセット販売して謝罪・撤回した経緯があり、グローバル版の方針はその後に整理されたものです。

根拠：[S01] [S02] [S05]

## 韓国版の資料を使うときのチェックリスト

1. レベル50前提のルート（エルテネン／モルヘイム）は使えない。
2. 9クラス前提のティア表は拳星を含む。そのままでは当てはまらない。
3. メンバーシップ2種前提の費用計算は不要。
4. シーズン3・4の数値をローンチの事実として読まない。
5. モバイルUIのスクリーンショットや仕様はグローバル版に存在しない。
6. 英雄等級・パンテオン・称号・強化値など、成長の「数値」は別物として扱う。
