正式サービス開始に合わせて、NC は公式のコミュニティイベントを複数開催しています。全リージョン共通のものは、超越ダンジョンのリーダーボード、外見コンテスト、ガイド募集、スクリーンショット企画です。日本を含む「アジアサーバー」だけが対象のイベントは別にあり、見落としやすいので分けて整理します。

根拠：[S01] [S02] [S03]

> **注意**：公式の「Community Launch Events Overview」は題名のみ確認でき、本文は取得できませんでした。内容は報酬表を写した AION 2 Maps と、NC Japan のプレスリリース全文を引用した GameWith で確認しています。参加は NC の Discord で行う企画が多く、参加方法は各イベントの公式お知らせが正です。

## 全リージョン共通のイベント

| イベント | 期間 | 内容 |
| --- | --- | --- |
| 超越ダンジョン リーダーボード | 〜11/2（アーリーアクセスのサーバーは9/30、他は10/5から） | 超越の「デウス研究基地」「砕けたアルカニス」を攻略してランクポイントを集める。サーバー・クラス別に順位 |
| Daeva Makeover | 〜10/19 | クローゼットでキャラクターのスクリーンショットを2枚（顔アップと全身）投稿 |
| Guides for Glory | 10/5〜11/2 | 9/30以降に書いたゲームのガイドを投稿 |
| Beauty of Atreia | 10/5〜11/9 | 週ごとのテーマ（世界・キャラクター・ペット）のスクリーンショットを Discord、または X と Instagram にハッシュタグ #BeautyOfAtreia で投稿 |

投稿・応募は NC の Discord のイベントチャンネルで、リージョン、サーバー、キャラクター名を添えて行います。

根拠：[S02]

### 超越リーダーボードの報酬

| 順位 | 報酬 |
| --- | --- |
| 上位10位 | 強化石×35,000、増幅石（唯一）×30、Philosopher's Stone: Revelation、ソウルコーデックス：リセット×5、復活の精霊石×20 |
| 11〜50位 | 強化石×12,000、増幅石（唯一）×15、ソウルコーデックス：リセット×3、復活の精霊石×10 |

- 対象はサーバーごと・クラスごとの順位です。自分の順位は ESC → 超越 → ランク → クラスで確認できます。
- ランクポイントは超越ダンジョンのクリアで増えます。入場条件と難易度は [[transcendence-overview]]、[[deus-research-base]]、[[shattered-arkanis]] を参照してください。

根拠：[S02]

| 聖域「ルドラ」討伐イベント | 9/30 23:00〜ルドラ初討伐まで | アーリーアクセスのいずれかのプレイヤーが初討伐したら、アジアサーバーの全プレイヤーにオードエネルギー（刻印）×4、復活の精霊石（刻印）×5、鍵：ヒドゥンキューブ（刻印）×2 |
| シューゴフェスタ王者決定戦 | 9/30 23:00〜10/31 23:59 | 期間中に最も多く優勝したプレイヤーに2,000キューナ（無償）。9名 |

| Discord 攻略交流 | 9/30 23:00〜10/31 23:59 | 公式 Discord の「攻略・情報交換」に攻略を投稿。抽選で4,000キューナ＋オードエネルギー×10（10名）、公式マウスパッド＆シール（10名） |

> **注意**：「ルドラ初討伐」は、アーリーアクセス期間に欧州などで既に討伐されています（[[ludra-raid-suspension]]）。アジアサーバーへの報酬の配布状況は、公式のお知らせで確認してください。この記事では、配布済みかどうかは確認できていません。

## 参加するときの注意

1. 応募には公式 X（@AION2_JP）のフォローや、公式 Discord への参加が条件になるイベントが多い。公式サイトのリンクから入る（[[jp-official-channels]]）。
2. 投稿内容は公開される。キャラクター名、サーバー名の写り込みを確認する。
3. キャッシュバックは事前登録が必須で、即時還元ではない。登録の条件と対象の決済は、公式のイベントページで確認する。
4. 期間は日本時間と太平洋時間で表記が違う。投稿前に公式のお知らせで時刻を再確認する。
