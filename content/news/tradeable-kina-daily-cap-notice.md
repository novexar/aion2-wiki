> **要確認**：NC の公式告知でこの上限を明記したページは特定できていません。「1日100万」「上限到達で通常モンスターのドロップが止まる」は AION 2 Maps（S01）と aion2.vi.ki（S02）が一致していますが、S02 は韓国・台湾版の報告（配信者の情報）であり、独立した第2資料とは言えません。グローバル版の数値と挙動はゲーム内の表示を優先してください。なお韓国版では2025年11月26日の緊急メンテナンスで1日200万に拡大された記録があり（AION2 Hub の更新ノート翻訳）、その後に引き下げられたとされるため、数値は変わりうる点にも注意してください。

取引できる「通常ギーナ（Kina）」には、1日あたりの取得上限があります。グローバル版では**1日100万**とされ、毎日のリセット（日本時間16:00）で戻ります。上限に達すると、通常のモンスターがアイテムを落とさなくなります。BOT（自動操作）対策として入った仕様で、広いフィールドで長時間狩るだけの金策は頭打ちになります。

根拠：[S01] [S02]

## 仕様の要点

| 項目 | 内容 |
| --- | --- |
| 対象 | 取引可能な通常ギーナ（刻印ギーナは別。[[kina-and-bound-kina]]） |
| 1日の上限 | 1,000,000 |
| リセット | 日次リセットと同時（07:00 UTC＝日本時間16:00。全リージョン共通） |
| 上限に達すると | 通常のモンスターからのドロップが止まる |
| フィールドのパーティ | パーティ全員がドロップ停止の影響を受ける |
| ダンジョンのパーティ | 上限に達した本人だけが影響を受ける |
| 韓国・台湾版 | 通常のフィールドモンスター由来のギーナが1日100万（アビスには同種の上限なしと報告） |

根拠：[S01] [S02]

> **韓国版のみ**：韓国・台湾版では、上限は2025年11月26日のパッチ前後に入り、12月10日に下げられ、2026年1月7日に CAPTCHA（人間確認）が追加された経緯があります。これは aion2.vi.ki が Aion2 Hub の翻訳パッチノートを引用して述べたもので、グローバル版に同じ履歴はありません。

根拠：[S02]

## 影響を受ける行動と受けない行動

| 行動 | 影響 |
| --- | --- |
| フィールドで通常モンスターを狩る | 上限に達するとアイテムが出なくなる |
| 遠征・超越の報酬キューブで出る通常ギーナ | 別の仕組み（キューブの減額ライン）が主。下の注記を参照 |
| クエスト・日課の報酬（刻印ギーナ） | 取引可能ギーナの上限とは別枠 |
| 取引所での売却益 | 取得上限の対象かは資料に記載なし |

根拠：[S01]

> **注意**：キューブのギーナが1日100万の上限に含まれるかは、資料に明記がありません。確認できていないので、上限に近づいたらゲーム内の表示で確かめてください。ルドラの報酬ギーナ（100万）は、キューブ報酬として別扱いと書かれています。

## 上限に合わせた立ち回り

1. 取引可能ギーナの主な稼ぎ先は、遠征「征服」と超越のキューブです。1回の受取で20万〜48万が出ます（[[kina-farming]]）。
2. 上限が気になる場合は、フィールド狩りよりキューブ中心にする。
3. 上限に達したら、通常モンスターは「経験値とクエスト目的」の用途に切り替える。ドロップは期待しない。
4. 複数キャラクターで稼ぐ場合も、上限は日次で戻る。サブキャラクターの征服報酬はサーバー倉庫でメインに渡せる（[[server-shared-limits-and-alts]]）。

根拠：[S01]

## 直接取引は無効

グローバル版ではプレイヤー間の直接取引が無効（2026年9月19日以降）です。ギーナの移動は取引所と、サーバー倉庫を使ったキャラクター間の移動に限られます。サーバーをまたぐアイテムの受け渡しは、NC がリアルマネートレードとみなすと明記されています。

根拠：[S02] [S01]
