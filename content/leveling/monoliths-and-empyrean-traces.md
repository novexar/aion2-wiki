神の痕跡（Empyrean Trace）は、フィールドのあちこちに置かれた羽の形のオブジェクトです。集めて、その地域の神のモノリス（Monolith）で「共鳴」させると、モノリスのレベルが上がり、恒久的なステータス上昇とアイテム報酬が貰えます。収集中に消えない永続成長なので、Lv45までは通り道のものだけ拾い、Lv45後にまとめて回収するのが効率的です。

根拠：[S01] [S02]

## 集め方

1. ワールドマップに白い羽のアイコンで表示されているので、エピソードの目的地周辺のものを拾う。
2. 近づいてFキーを押す。「回収中」のバーが出て羽が赤く光り、終わると黒くなる。
3. 1か所につき、その地域の痕跡が **3個** 貰える。
4. 回収済みの羽はマップから消える。残っているアイコンを順に回れば取り残しが分かる。

痕跡は地域別のアイテムです。ベルテロンで集めたものはベルテロンのモノリス、アルトガルドで集めたものはアルトガルドのモノリスでしか使えません。共鳴できない時は、痕跡の地域とモノリスの地域が合っているか確認してください。

根拠：[S01] [S02]

## 利用できるのはLv16から

エピソードのクエスト「Empyrean Monolith」（推奨Lv16）で使い方が案内されます。痕跡自体はそれより前から拾えるので、見かけたら先に拾って構いません。使えるようになった時に、すぐ何レベルか上げられます。

根拠：[S01] [S02] [S04]

## 地域ごとの数

| 地域 | 神の痕跡の数 | モノリスのレベル | 備考 |
| --- | --- | --- | --- |
| ベルテロン（天族） | 560 | 30まで | |
| アルトガルド（魔族） | 560 | 30まで | |
| 混沌のエレシュランタ下層（アビス） | 200 | 20まで（全部集めるとLv16まで） | アイテムレベル1,000が必要 |

エルトネンとモルヘイムのモノリスは韓国・台湾版のチャプター1のもので、グローバル版では使えません。

根拠：[S03] [S05] [S06]

## 共鳴に必要な数（ベルテロン／アルトガルド）

必要数は累計です。表は主なレベルのみ抜き出しています。

| モノリスLv | 累計の痕跡数 |
| --- | --- |
| 2 | 1 |
| 5 | 20 |
| 10 | 70 |
| 15 | 140 |
| 20 | 235 |
| 25 | 375 |
| 30 | 560 |

根拠：[S03]

> **要確認**：Aion 2 Mapsは「80個でLv10、255個でLv20」と書いています。AION2HUBのデータ表では、Lv10は70個、Lv11が80個、Lv20は235個、Lv21が255個です。1段ずれた数え方の違いと思われ、Lv30の560個は両者で一致します。

## 共鳴の報酬（Lv30まで）

レベルが上がるたびに、10種類ある主神ステータスのうち2つが1ずつ上がります。上がる組み合わせと順番は決まっています。Lv30まで上げると、幻想と知恵が+5、残りの8つが+6になります。

| 共鳴Lv | 主な報酬 |
| --- | --- |
| 2〜29 | 啓示のアミュレット強化スクロール×1（毎レベル） |
| 2〜9 | 鍵：ヒドゥンキューブ（Lv2〜5は1個ずつ、Lv6〜9は2個ずつ） |
| 10 | 地域タイトル |
| 11〜19 | 魂の書：初期化（1個ずつ、2個ずつ、3個ずつと増える） |
| 20 | 地域タイトル |
| 21〜29 | 突破石の欠片（Amplify Stone Fragment (Unique)）（1個ずつ、2個ずつ、3個ずつと増える） |
| 30 | 啓示のアミュレット強化スクロール×2、地域タイトル |

Lv30までの合計は次のとおりです。

| 報酬 | 合計 |
| --- | --- |
| 啓示のアミュレット強化スクロール | 30個 |
| 鍵：ヒドゥンキューブ | 12個 |
| 魂の書：初期化 | 18個 |
| 突破石の欠片 | 18個 |
| 地域タイトル | 3種 |

アルトガルドのタイトルは「アルトガルド探求者」「アルトガルド守護者」「アルトガルドの聖者」です。

根拠：[S01] [S02] [S03]

## 啓示のアミュレット

モノリスで貰う強化スクロールは、専用装備「啓示のアミュレット」を育てるために使います。アミュレットは落ちた装備に入れ替えず、スクロールで+10まで強化し、物質変換で上の等級に上げていきます。+10まで成功率100%です（[[belt-and-amulet]]）。

| 段階 | 必要 | 効果 |
| --- | --- | --- |
| レア +0→+10 | スクロール10個、ギーナ232,000 | アイテムレベル+23（変換含む） |
| エピック +0→+10 | スクロール10個、ギーナ1,579,000 | +29（変換含む） |

根拠：[S01] [S05]

## スキルポイントは出ない

> **注意**：韓国・台湾版のモノリスはスキルポイントを与えますが、グローバル版のモノリスは **スキルポイントを与えません**。代わりに、自陣営の地域クエストが知恵の石58個、封印ダンジョンが各2個を与えます（[[regional-quests]]、[[sealed-dungeons]]）。一部の日本語サイトがモノリスでスキルポイントが貰えると書いていますが、これはグローバル版には当てはまりません。

根拠：[S04]

## サブキャラとの共有

同じサーバー内では、「神の痕跡継承」で収集状況をキャラクター間で共有できます。継承するとモノリスのレベルがそのままコピーされるわけではなく、収集状況を継承した上で、そのキャラクターでモノリスと共鳴して報酬を進めます。対象地域のモノリスを使える状態まで進めておく必要があります。

装備の「継承」システムとは別のものです。

根拠：[S01]

## 回収のタイミング

| 時期 | 動き |
| --- | --- |
| Lv1〜45 | 通り道のものだけ拾う。マップを埋め尽くす必要はない |
| Lv45後 | 取り残しをまとめて回収し、モノリスでLv30まで共鳴（[[what-to-do-at-45]]） |
| アイテムレベル1,000後 | アビスの200個を集め、アビスのモノリスで共鳴（Azphel結晶36個） |

アビスの痕跡は混雑時には全部集めるのに2時間以上かかることがあるため、人の少ない早朝などがおすすめです。

根拠：[S01] [S05]
