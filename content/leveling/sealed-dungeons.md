封印ダンジョン（Sealed Dungeon）は、フィールドのマップ上に「？」で表示されるソロ用のインスタンスです。各キャラクターが一度だけクリアでき、ディーヴァニオン結晶・知恵の石・強化石といった恒久的な成長素材が貰えます。クラスを問わず1人で入ります。レベリング中に通り道のものを拾い、残りはLv45以降に回収するのが基本です。

根拠：[S01] [S02] [S03]

## 基本情報

| 項目 | 内容 |
| --- | --- |
| 数 | 自陣営の地域に61か所（天族はベルテロン、魔族はアルトガルド） |
| 入場 | ソロ。クラス不問 |
| 繰り返し | 不可。キャラクターごとに一度きり。サブキャラは別に回収する |
| 構成 | モンスターの群れ、ボス、時に小さな仕掛け。レベリング中は少し手強い |
| 場所の確認 | ワールドマップ > 探険 > 封印ダンジョン。クリア済みもここで確認できる |
| 解放 | Lv10から。推奨レベル10〜40に分かれて並ぶ |

> **注意**：駐屯地もマップで「？」として表示されるため、「？」のすべてが封印ダンジョンとは限りません。

根拠：[S01] [S03] [S05]

## 初回クリア報酬

AION2HUBのデータでは、自陣営の封印ダンジョンは、クリアの1回目に次の報酬が貰えます。

| 報酬 | 量 |
| --- | --- |
| ギーナ | 15,000 |
| 強化石 | 1,250 |
| ディーヴァニオン結晶 | 2 |
| 知恵の石 | 2 |
| 翼の素材 | 2 |
| 石像の欠片（万神殿用） | 2 |
| 称号 | 1 |

自陣営の61か所で、ディーヴァニオン結晶は計122個、知恵の石は計122個になります。

根拠：[S01] [S02] [S04]

> **注意**：グローバル版では神のモノリスが知恵の石を出さなくなったため、封印ダンジョンと地域クエストが知恵の石（スキルポイント）の主な入手元です（[[regional-quests]]）。

## 順番に開く4か所

61か所のうち4か所は、順番にクリアしないと入れない連鎖になっています。

| 陣営 | 順番 |
| --- | --- |
| 天族 | Distorted Cave → Fissure Cave → Rift Cave → Ruins of the Ancient City of Roah |
| 魔族 | Lost Ruins → Twisted Pit → Rift Fissure → Ruins of the Ancient City of Roah |

根拠：[S01]

DBに登録されている名前の例は次のとおりです（日本語表記）。アキロ盗賊団の巣窟、アウルラウの祈祷室、ガーディアンの武器庫、カラットの巣、キウスの住処、クラカの祭壇、クラル兵営、クンバフムの洞窟、シュラクの洞窟、タルゴスの洞窟。

根拠：[S02] [S05]

## 他陣営の封印ダンジョン

Lv45以降は、時空の亀裂（約3時間ごとに開く）経由で他陣営の地域に入り、そちらの封印ダンジョンも回収できます。

| 項目 | 内容 |
| --- | --- |
| 報酬 | ディーヴァニオン結晶なし。強化石2,500、アビスポイント1,000、ギーナ15,000 |
| 滞在 | 亀裂ごとに1時間ほど |
| 状態 | 通常はPvEモードで入る |
| 注意 | 相手陣営の衛兵NPCに近づくと、PvP対象になり得る |

詳細は [[spacetime-rift]] と [[abyss-overview]] を参照してください。

根拠：[S01] [S03]

## 回収の進め方

1. Lv10〜45：エピソードの通り道にあるものと、覚醒ゲージが足りない時の近場のもの。
2. Lv45：残りの自陣営分を回収する（段階2、[[what-to-do-at-45]]）。
3. アイテムレベル1,000以降：他陣営の分を亀裂で回収する。

覚醒ゲージの補充になるため、封印ダンジョンはレベリング中の「補給源」としても有用です（[[ascension-quests-and-gauge]]）。初回キャラは「近いならクリアする」くらいの判断で十分です。

根拠：[S01] [S03]

## 韓国・台湾版との違い

> **韓国版のみ**：チャプター1（Lv50まで）で、エルトネンとモルヘイムに封印ダンジョン計20か所が追加されています。グローバル版（Lv45上限）では未開放です。
