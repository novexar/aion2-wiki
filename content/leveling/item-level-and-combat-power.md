アイテムレベル（Item Level、IL）は、Lv45以降の進行を決める数字です。遠征の征服、アビス、超越などの入場条件はほぼすべてILで決まります。装備の等級や強化段階など、見える数字を単純に足したものなので、何を足せばいくつ上がるかを把握すると、費用の安い順に上げられます。

根拠：[S01] [S02]

## ILに含まれるもの

| 要素 | ILへの加算 |
| --- | --- |
| 装備している各部位 | その装備自体のアイテムレベル |
| 強化 | 1段階ごとに+1（+15まで） |
| ディーヴァニオン | 結晶1個を使うごとに+1（4個のノードなら+4）。PvPのAzphelボードも加算（アジア版の情報） |
| 魔石・ソウルストーン | 1行ごとに、色で+1（灰）、+2（緑）、+3（青）、+4（黄）。ベルト・アミュレット・ルーンには付かない |
| Amp（増幅） | 1段階ごとに+5（アジア版の情報） |
| アルカナ | カード自体のIL（20・40・60・80、等級により）＋カードのレベルごとに+1 |
| 翼・ペット・称号 | 加算されない |
| 万神殿の石像 | 加算されない（資料により見解が割れる） |

根拠：[S01]

## ILが上がる効率の順

同じギーナで増えるILを比べると、最初の数段階が圧倒的に効率的です。効率の良い順に上げるのが基本です。

| 手順 | ILの増加 | ギーナ | 100万ギーナあたりのIL増 |
| --- | --- | --- | --- |
| ディーヴァニオン結晶1個、激突のルーン | +1、+40 | なし | — |
| 高潔のベルト（レア）+0→+10、エピックへ変換 | +10、変換で+13 | 232,000＋スクロール10個 | 約100 |
| エピック（Lv38）装備 +0→+5 | +5 | 69,850 | 約70 |
| ユニーク（Lv54）装備 +0→+5 | +5 | 99,150 | 約50 |
| エピック（Lv38）装備 +5→+10 | +5 | 274,000 | 約18 |
| ベルト／アミュレット エピック+0→+10、ユニークへ変換 | +10、変換で+19 | 1,579,000＋スクロール10個 | 約18 |
| ユニーク（Lv86）装備 +0→+10 | +10 | 775,100 | 約13 |
| Amp 1段階（ユニーク+15、Lv54以上） | +5 | 約880,000（平均） | 約6 |
| ベルト／アミュレット ユニーク+0→+10 | +10 | 5,026,000＋スクロール10個 | 約2 |
| Amp 2・3段階（Lv70以上） | +10 | 約5.4M | 約2 |
| Amp 4・5段階（Lv86以上） | +10 | 約19.9M | 約0.5 |
| ユニーク（Lv86）装備 +10→+15 | +5 | 約11.9M（平均） | 0.5未満 |

> **注意**：同じ装備でも +10→+15 は +0→+5 の約75倍のギーナがILあたりにかかります（Maps）。置き換える予定の装備は、+5程度で止めるのが基本です。

抽出（Extraction）すると、強化に使った強化石は戻りますが、ギーナは戻りません。

根拠：[S01]

## 戦闘力（Combat Power）との違い

| 指標 | 意味 |
| --- | --- |
| アイテムレベル | 装備などの数値の合計。**入場条件の判定に使われる** |
| 戦闘力 | キャラクターの強さの目安。ILが高くてもステータスが弱ければ、与ダメージは伸びない |

募集（野良パーティ）では、入場条件よりも高い戦闘力や、武器・ガーダーのAmpを要求されることがよくあります。条件ぎりぎりのILで入ると、敵が硬く時間切れになりやすいという声もあります。

アジア版の攻略記事には、戦闘力が数十万、ILが数千という2つの桁の違う指標が出てきます。数字が100倍ずれて見える時は、指標の取り違えを疑ってください。

根拠：[S01] [S03] [S04]

## 数字の読み方のコツ

1. 入場条件はILで見る（[[progression-path-700-to-2800]]）。
2. 野良の条件は戦闘力を見る。
3. Lv45までは装備が頻繁に置き換わるので、ILを上げすぎない。本格的なIL上げはLv45後（gamerchも同じ見解）。

次の節目の目標は、まず700、次に1,000です。700で最初の征服に挑め、1,000でアビスが開きます（[[road-to-il-1000]]）。
