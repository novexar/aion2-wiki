最初の1週間は、「Lv45まで行く」「一度きりの成長要素を回収する」「日課の型を作る」の3つで決まります。全部を完璧にこなす必要はありません。次のアイテムレベルの節目に必要なものだけを見て進めてください。

> **注意**：サービス開始日以降の細かい期限（クーポン、Twitch Dropsなど）は変わる可能性があります。ゲーム内とNCの公式告知を優先してください。

## 先に知っておく仕組み

| 項目 | 内容 |
| --- | --- |
| 日次リセット | 毎日 07:00 UTC（日本は16:00）。全リージョン共通 |
| 週次リセット | 水曜の同じ時刻 |
| 期限切れで失うもの | オードエネルギー、シューゴフェスタの鍵、悪夢の回数は上限でそれ以上貯まらない |
| サーバー共有の制限 | 使命クエスト、デイリーダンジョンなどは、サーバー内の全キャラクターで共有 |

根拠：[S04]

## 1日目

| 順番 | やること | 補足 |
| --- | --- | --- |
| 1 | 陣営・サーバー・クラスを決めてキャラクターを作る | 友人と遊ぶなら陣営とサーバーを揃える。サーバー移動は同じ陣営内のみ |
| 2 | UIと操作の設定を直す | HUD編集でUI比率とチャットの文字サイズを変えられる |
| 3 | 郵便を受け取る | ローンチ報酬のペットと箱が届く（[[launch-rewards-and-codes]]） |
| 4 | クーポンを入力する | 設定 > その他 > アカウント > クーポン入力（Lv9のクエストで解放） |
| 5 | メインストーリーでLv45へ | [[leveling-1-to-45-overview]] |
| 6 | 使命の最初の5件 | Lv45から。ただしLv45前にジャーナルの使命タブを開かない |

初日の目標として、MeinMMOは「メインキャラのLv45到達」「悪夢の解放（2日目に最初の回数を貰うため）」「使命5件」を挙げています。腕に自信があれば数時間でLv45に着きますが、時間と混雑の状況次第では全部は終わらないので、Lv45到達を優先してください。

根拠：[S02] [S03] [S05]

> **要確認**：MeinMMOはサブキャラも早めにLv22にすることを推奨しています（オードエネルギーの回復を開始するため）。ただしゲーム内でのオードエネルギー解放レベルはMapsなど他の資料では確認できていません。

## 2日目〜

| 優先 | やること | 目的 |
| --- | --- | --- |
| 毎日 | 使命を5回 | 日課報酬の確保。回数は持ち越せない |
| 毎日 | オードエネルギーがあふれないか確認 | 15個/3時間の回復が上限（560、会員840）で無駄になる |
| 毎日 | シューゴフェスタの鍵 | 毎日3個。上限12（会員21） |
| 毎日 | 悪夢（Lv45） | 毎日2回。最大14回まで貯まる |
| 週前半 | 使命の「指令」 | アビスポイントなど |
| 1週間で | メインストーリーを完走 | Lv45の4次覚醒へ |
| 1週間で | 地域クエスト・封印ダンジョン・駐屯地・神の痕跡 | [[what-to-do-at-45]] の段階2 |
| 1週間で | アイテムレベル1,400を目標 | 以降のバクロン空中島が本命の更新先 |

根拠：[S02] [S04] [S06]

## 週次の確認

- 覚醒戦（Ascension Trial）：週3回。リセット前の最終日に入ると、その週に到達した最高難度に入れる。
- 悪夢のボス：リセット前日まで待つと、アイテムレベルが上がった分だけ上の難度に挑める。
- デイリーダンジョン：週14回（サーバー共有）。
- 指令（Commands）：首都から最大12件。アビス下層からは最大20件（サーバー単位）。
- アビスショップの石：週50個。

根拠：[S04]

## アイテムレベルの節目

| アイテムレベル | 解放されるもの |
| --- | --- |
| 700 | クラオ洞窟・ドラウプニルの征服 |
| 1,000 | アビス、覚醒戦（最初の難度） |
| 1,400 | ウルググ峡谷・バクロン空中島の征服 |
| 1,600 | 超越の1段階 |
| 2,100 | 炎の神殿・獰猛な角岩窟の征服 |

> **注意**：Ludra（聖域レイド、アイテムレベル2,800）はNCの告知により、グローバル版の正式サービス開始時点で一時的に取り下げられています。再登場の案内は10月16日までと告知されています（[[ludra-raid-suspension]]）。

根拠：[S01] [S04] [S06] [S07]

## 初週にやらなくてよいこと

- 低レベル装備の最大強化（置き換える前提の装備は、+5程度で十分）
- 採集・製作のやり込み
- 週の途中で入る闘技場（PvP）。報酬を狙う場合を除く
- 友人から直接アイテムを受け取る（直接取引は無効化されている）

根拠：[S02] [S03] [S06]
