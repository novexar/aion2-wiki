グローバル版AION2のレベル上限は **45** です。Lv45までの道のりは、メインストーリー（エピソード）を追うだけでほぼ完結します。ストーリーが経験値の大半をくれて、新しいマップやシステムの解放も担うためです。このページは「どう進めれば迷わないか」を最初に決めるための全体図です。

根拠：[S01] [S04] [S05]

## 結論：迷ったらこの順番

1. メインストーリー（エピソード）を進める。
2. 覚醒（Ascension）クエストが出たら、通常の地域クエストより優先する。
3. 進行が止まったら（覚醒ゲージ不足など）、現在地に近い封印ダンジョンや地域クエストで補う。
4. 補ったらすぐエピソードに戻る。

「同じ場所で延々とモンスターを狩る」必要はありません。フィールド狩りは経験値効率が低く、素材やギーナ集めが中心になります。

根拠：[S01] [S05]

## レベル帯ごとの目安

| レベル帯 | 優先すること | 備考 |
| --- | --- | --- |
| 1〜9 | エピソードのみ | 天族はポエタ、魔族はイシャルゲン。Lv5〜6で1次覚醒（翼） |
| 10〜21 | エピソード＋通り道の成長要素 | 封印ダンジョン、駐屯地、地域クエストが使えるようになる |
| 22 | 2次覚醒を最優先 | スティグマが解放される |
| 22〜31 | エピソード＋近場の地域コンテンツ | 経験値が足りない時は封印ダンジョンで補う |
| 32前後 | 3次覚醒を最優先 | 新しい翼 |
| 32〜39 | エピソード＋不足分の育成 | メインだけでは経験値が足りなくなりやすい |
| 40〜44 | エピソード中心 | 最終章 |
| 45 | 4次覚醒、ストーリー完走 | 以降は装備（アイテムレベル）の育成に移る |

根拠：[S01] [S02] [S06]

> **注意**：覚醒のレベルは「推奨レベル」です。レベルが足りても覚醒ゲージが100%でないと覚醒できません。詳しくは [[ascension-quests-and-gauge]] を参照してください。

## 各陣営のルート

| 項目 | 天族（Elyos） | 魔族（Asmodian） |
| --- | --- | --- |
| 最初の地域 | ポエタ（Lv3〜9） | イシャルゲン（Lv3〜7） |
| 本拠地の地域 | ベルテロン | アルトガルド |
| 最終盤 | Lv40〜45でScarlet Forest、幻影神の庭園 | Lv40〜45でZikel's Core周辺 |

ルートの詳細は [[elyos-leveling-route]] と [[asmodian-leveling-route]] にまとめています。

根拠：[S03] [S07]

## 寄り道の考え方

最速でLv45に着くだけなら、ストーリーを一直線に進めるのが最短です。ただしLv45到達後に「回収し直す」成長要素が多く残ります。そのため初回キャラは次のくらいが現実的です。

| 要素 | Lv45までの扱い |
| --- | --- |
| 封印ダンジョン | 通り道にあるものはクリア。経験値不足や覚醒ゲージ不足の時にも使う（[[sealed-dungeons]]） |
| 地域クエスト | エピソードと同じ場所にあるものだけ（[[regional-quests]]） |
| 駐屯地 | 通り道のものだけ。ベルト強化スクロールが貰える（[[strongholds]]） |
| 神の痕跡（羽） | 見かけたら拾う。まとめてはLv45後でよい（[[monoliths-and-empyrean-traces]]） |
| ヒドゥンキューブ | 鍵があれば通り道で開ける（[[hidden-cubes]]） |
| 転送ポイント（キスク） | 見つけたら解放しておくと移動が楽 |
| 採集・製作のやり込み、低レベル装備の厳選 | 後回しでよい |

マップを100%埋めてから次の地域へ進む必要はありません。「全部やる」と「全部無視する」の中間が最も効率的です。

根拠：[S01] [S05] [S06]

## 装備は強化しすぎない

Lv45までは装備の更新が頻繁です。数レベルで交換する装備に強化石やギーナを注ぎ込むと損をします。

- 敵を問題なく倒せているなら、そのまま進める。
- 火力や耐久が足りなくなったら、使っている武器など必要な部位だけ強化する。
- 上位装備が出たら交換する。

本格的な装備強化は Lv45 到達後です（[[what-to-do-at-45]]）。

根拠：[S01] [S04]

## 所要時間の目安

初回プレイでLv45まで **およそ10〜15時間** という見積もりが、ドイツのメディアMeinMMOから出ています。クラスやMMO経験、寄り道の量で大きく変わります。経験者が装備・スキル操作を最適化したタイムアタックでは、これよりかなり短くなります。

根拠：[S04]

## 経験値が足りなくなる時

特にLv30台は、メインストーリーの経験値だけでは次のクエストの条件に届かないことがあります。チャプターは「覚醒ゲージ」（赤い進行バー）に紐づいているためです。この場合は、以下の順で補います。

1. 現在地に近い封印ダンジョン
2. エピソードと目的地が重なる地域クエスト
3. 近くの駐屯地

遠くまで1つずつ回収しに行くより、現在の進行ルート周辺をまとめて処理するほうが移動時間を減らせます。

根拠：[S01] [S04] [S05]

## 混雑時のコツ

サービス開始直後などは、クエスト対象のモンスターが枯れることがあります。同じ場所で再出現を待つより、クエストマーカーの範囲内で別の敵を探したほうが早い場合があります。

根拠：[S01]

## Lv45になったら

Lv45に着くと、アビス、超越、悪夢、アルカナなどがまとめて解放されます。ただしアイテムレベル（装備の強さ）の条件で入れないものも多く、育成の軸はキャラクターレベルからアイテムレベルへ移ります。次の手順は [[what-to-do-at-45]] を参照してください。

根拠：[S02] [S03] [S06]
