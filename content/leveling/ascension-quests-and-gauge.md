覚醒（Ascension）は、冒険者が「ディーヴァ」として段階を上げていくクエスト群です。Lv5・22・32・45に1回ずつ、合計4段階あり、段階ごとに上の等級の翼が貰え、次のレベル帯のメインストーリーに進めるようになります。メインストーリーを一直線に進めていると途中で止まることがあり、原因はたいてい **覚醒ゲージ** の不足です。

根拠：[S02] [S04]

## 覚醒の4段階

| 段階 | クエスト名（DB表記） | 目安Lv | 主な内容 |
| --- | --- | --- | --- |
| 1次（覚醒の道I） | 気を感じる者 | 5 | 翼と飛行が解放される |
| 2次（覚醒の道II） | 声を聞く者 | 22 | スティグマ、万神殿（Pantheon）が解放される |
| 3次（覚醒の道III） | 夢を見る者 | 32 | 新しい等級の翼。スティグマのレベル上げが可能に |
| 4次（覚醒の道IV） | 悪夢を見る者 | 45 | アビスでの引き渡しと組み合わさる（[[story-locks-and-abyss-handin]]） |

DBには、これに続く「誓約する者」（覚醒の道V）も登録されています。グローバル版（Lv45上限）で受けられるかは確認できていないため、この記事では扱いません。

レベルが足りただけでは覚醒できず、覚醒ゲージを100%にする必要があります。覚醒ごとに、夢の分かれ道、夢の残骸、苦痛の夢といった専用エリアを順に進みます。

根拠：[S02] [S03] [S04]

## 覚醒ゲージとは

覚醒ゲージは、陣営ごとに用意されたクエストの進行度です（DBには「天族の覚醒ゲージ」「魔族の覚醒ゲージ」が別に登録されています）。メインストーリーの経験値だけでは100%に届かないことがあり、その場合は **現在の地域で未完了のコンテンツ** で補います。

| ゲージを増やせるもの | 優先度 |
| --- | --- |
| 地域クエスト | 高。最初に確認する |
| 封印ダンジョン | 高。現在地に近いものから |
| 駐屯地 | 中 |
| エピソード | 通常どおり進める |

すべてを片っ端から消化する必要はありません。ゲージが足りなくなった時点で、現在地付近の地域クエストや封印ダンジョンを数件消化して、増加を確認するのが効率的です。

根拠：[S01] [S04] [S05]

## 2次覚醒「声を聞く者」（Lv22）の手順

Lv22前後の最初の大きな壁です。「声を聞く者」が出ない・進まない場合は、次の表で原因を切り分けます。

| 確認項目 | 内容 |
| --- | --- |
| 覚醒ゲージ | 100%まで進める |
| 前の覚醒 | 「気を感じる者」を完了している |
| エピソード | 「幻影の祈祷室」（Illusion Oratory）まで進める（天族の例） |
| レベル | 22前後 |

覚醒ゲージが100%でも「声を聞く者」がすぐ出るとは限りません。ゲージは条件の1つにすぎず、ストーリー側の条件も必要です。ゲージが満タンなのに進まない場合は、さらに地域クエストを探すのではなく、エピソードを進めてください。

### 進め方

1. 覚醒ゲージを必要量まで上げる。
2. 前提のエピソードと覚醒を終える。
3. 「声を聞く者」が出たら、ジャーナルを開いて覚醒関連の項目から選び、移動操作で「夢の分かれ道」へ向かう。
4. 夢の分かれ道でアサールと会話する。
5. 「夢の残骸」に入り、「意志の夢の破片」を入手する。
6. 「苦痛の夢」に入って覚醒を進める。

フィールド上で「夢の分かれ道」を探し回る必要はありません。ジャーナルからの移動を使います（[[navigator-and-journal]]）。

根拠：[S01]

## 確認の順番（詰まった時）

1. 覚醒ゲージが100%か確認する。
2. 100%未満なら、近くの地域クエストを進める。
3. 100%なら、エピソード進行を確認する。
4. 「幻影の祈祷室」まで終わっているか確認する。
5. 前の覚醒「気を感じる者」が終わっているか確認する。
6. 「声を聞く者」が出たらジャーナルの覚醒項目を開く。

根拠：[S01]

## 覚醒は後回しにしない

2次覚醒の後は、スティグマがビルドに関わってきます。進行は「覚醒ゲージを満たす → 声を聞く者 → スティグマを設定する」の順がおすすめです。通常の地域クエストよりも覚醒を優先してください。

レベル30台は敵が強くなるため、スティグマを設定せずに進むより、主力スキルと組み合わせたほうが戦闘時間を短縮できます。

根拠：[S01] [S05]

## Lv45の覚醒

Lv45の覚醒クエストは、覚醒ゲージが満タンであることに加えて、メインストーリーの「Draupnir」（天族）または「Forgotten Commander」（魔族）をアビスで引き渡している必要があります。アビスはアイテムレベル1,000が必要です。引き渡しで、自陣営の地域クエストも22件（魔族は23件）開きます。アジア版では、このクエストで翼・ブレスレット・アミュレットが貰えます。

詳細な手順は [[story-locks-and-abyss-handin]] と [[what-to-do-at-45]] を参照してください。

根拠：[S03]
