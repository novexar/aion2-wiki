ヒドゥンキューブ（Hidden Cube）は、フィールドの各地に現れる隠し宝箱です。1回開けると消えて、同じグループの別の場所に新しいキューブが現れます。グローバル版のベルテロン／アルトガルドでは、開けるのに「鍵：ヒドゥンキューブ」が1個必要で、1個ごとに魂結晶1,000個が必ず貰えます。

根拠：[S01] [S02]

## 基本情報

| 項目 | 内容 |
| --- | --- |
| 開け方 | 鍵：ヒドゥンキューブを1個持った状態でキューブを調べる。鍵がないと開かない |
| 鍵の扱い | 拘束アイテム。キャラクター自身の倉庫（サーバーストレージには入れられない）。取引不可 |
| 出現 | 1か所に常時固定ではなく、複数の候補地点の中から出現する |
| 確定報酬 | 魂結晶1,000個 |
| 数 | クライアント全体で206個。ベルテロン95、アルトガルド59、エルトネン26、モルヘイム26。エルトネンとモルヘイムはLv46以降の地域のため、グローバル版で回れるのは154個 |
| 出現候補地点 | 3,722か所 |

根拠：[S01] [S02] [S03]

## 場所の探し方

- マップの攻略サイトで示される地点に行っても、必ずあるとは限りません。不具合ではなく、候補地点の中から出現するためです。
- 1か所だけ探し続けず、周囲の候補地点を順番に回ってください。
- 崖の上下、建物や遺跡の裏、川や湖の中も確認してください。水中に出るものがあります。
- 近くにある時は、音が手掛かりになります。

天族のベルテロンでは、エルン川中流の周辺をはじめ各地に候補があります。魔族のアルトガルドでは、ドレドギオン墜落地、浄化の森などに広く候補があります。

根拠：[S02] [S03]

## 1個のキューブから出るもの

| 報酬 | 1個あたり |
| --- | --- |
| 魂結晶（Soul Crystal） | 1,000（確定） |
| Silentium | 10個＋50%ごとに1個を2回 |
| 魂の書（Soul Codex） | 5 |
| Power Shards / Superior Power Shards | 100〜200 |
| Mana Potion / Life Crystal | 50% |
| 復活の精霊石 | 50% |
| 小オード エネルギー（10） | 50% |
| 状態異常耐性スクロール | 40% |
| Lucky Aura（スキン合成用） | 20% |
| Shugo Transformation Candy | 20%（2個） |
| 魂の書：初期化 | 10% |
| ヘルム／イヤリング／ネックレスのスキン（14種） | 1% |
| Radiant Love Wings | 1% |
| エモート「Kurukuru」 | 0.1% |
| Seed of Detection | 1 |

翼、スキン、エモートは取引できます。クリスタル、Silentium、魂の書は拘束です。Silentiumは店で1個5,000拘束ギーナで売れるほか、補給依頼に納めてアビスポイントに換えられます（[[supply-requests]]）。

根拠：[S01]

## 鍵の入手元

| 入手元 | 鍵の数 |
| --- | --- |
| キャッシュショップ | 1個50 Quna、1キャラクター1日3個まで |
| シーズンショップ（シーズン1） | 1個3,000Oath Coins、10個まで |
| 実績 | 26個、実績の節目でさらに4個（各1回） |
| モノリス | 12個（天族はベルテロン、魔族はアルトガルド）（[[monoliths-and-empyrean-traces]]） |
| 14日間のログインボード | 4個 |
| クエスト | Lv10で2個 |
| 使命クエスト・指令 | 5つのランダム報酬のうちどれかが鍵（各2%）。1つ目は必ず貰え、2〜5つ目は50・33・25・10% |
| AION 2 Season 1 Starter（ショップ、キャラクターごとに1回） | 10個 |

ディーヴァパスは鍵を出しません。

> **注意**：キャッシュショップやシーズンショップでの購入は、無課金でも進められます。鍵は実績・モノリス・使命などで手に入ります。

根拠：[S01] [S02] [S04]

## クリスタルの使い道

魂結晶（Soul Crystal）は、ペット「Genus」の解析（Analyze）に使います。解析1回は魂結晶4個とギーナ1,000なので、キューブ1個で250回分です（[[pet-genus]]）。ほかの安定した入手元は小さめです。Wind Breeze Merchantsは週1,000個をサーバー単位で売り（会員のみ、500ギーナ/個）、シューゴフェスタのショップは月3,000個、シーズン1のディーヴァパスは無料220個または有料550個です。

根拠：[S01]

## 回収の進め方

| 時期 | 動き |
| --- | --- |
| Lv1〜45 | 鍵があれば、通り道で見つけたものを開ける。探し回らない |
| Lv45後 | 神の痕跡の回収と合わせて、鍵のある限り回す |

モノリスを共鳴させると鍵が貰えるため、痕跡の回収とキューブ探しは同じ周回で進められます（[[what-to-do-at-45]]）。
