グローバル版のサービス開始に合わせて、無料で貰える報酬がいくつかあります。期限があるものが多いので、まず期限の近いものから受け取ってください。ここでの日付はすべて太平洋時間（PDT）または日本時間の併記で、変更される可能性があります。

> **注意**：期限・内容は変わることがあります。ゲーム内とNCの公式告知を優先してください。

## 受け取りの期限一覧

| 報酬 | 受け取り方 | 期限 |
| --- | --- | --- |
| クーポン TAKEFLIGHTAION2 | ゲーム内で入力 | 10月13日 23:00 PDT（日本時間10月14日 15:00） |
| ローンチ報酬（ペット箱・ウィッシュリスト箱） | ゲーム内の郵便 | 12月1日のメンテナンス前にログイン。郵便の期限は12月8日 |
| Twitch Drops（Global Launch） | 対象配信を視聴 | 10月16日 |
| Twitch Drops の受け取り操作 | Twitchのドロップ画面で「受け取る」 | 10月30日 23:59 PDT |
| 出席の記念ボード2つ | Esc > アクティビティ > 出席 | 12月16日 |
| 超越のリーダーボード報酬 | 超越ダンジョンのランク | 11月2日 |
| 早期アクセス用の戦闘強化スクロール×5（刻印） | 郵便 | 早期アクセス終了まで |

根拠：[S01] [S02]

> **補足**：ローンチ報酬の期限は、Mapsの表では「12月1日 23:30 PT」、AION2 Timesでは「12月2日(水) 16:30（日本時間）」で書かれています。日本時間では12月2日の午後です。計算すると同じ時刻で、表現の違いです。

## クーポン「TAKEFLIGHTAION2」

| 項目 | 内容 |
| --- | --- |
| コード | TAKEFLIGHTAION2 |
| 中身 | オードエネルギー×4、復活の精霊石×5、戦闘強化スクロール×10（すべて拘束） |
| 使用 | 全サーバーで有効。1アカウントにつき1回 |

### 入力方法

1. ゲーム内で設定を開く。
2. その他 > アカウント > クーポン入力を開く。
3. コードを入力して決定を押す。

クーポン入力はLv9のクエストで解放されます（[[unlocks-by-level]]）。

根拠：[S02]

## ローンチ報酬（郵便）

12月1日のメンテナンス前にアカウントを作成してログインした全員に、事前登録とSteamウィッシュリストの報酬が郵便で届きます。1アカウント・1リージョンにつき1回です。

| 箱 | 中身 |
| --- | --- |
| ペット箱 | ペット「Pagati」＋次の1匹から選択：Papis、Silver Blade Rotan、Konutin Worker、Black Smoke Murute |
| ウィッシュリスト箱 | 復活の精霊石×10、Life Potion×100、Healing Potion×50、各種スクロール×50（帰還・勇気・疾走・加護）。すべて拘束 |

根拠：[S01] [S02] [S04]

## 早期アクセスの詫び

NCは、サービス開始の遅れと混雑に対して、次を配布しています。

- 9月30日の遅れた開始に対して：復活の精霊石×10
- 長い待ち行列に対して：外見変更券
- 早期アクセス終了まで、郵便に戦闘強化スクロール（刻印）×5
- 10月1日の緊急メンテナンスで影響を受けたサーバーで始めていた人への補填箱

| 累計視聴 | 報酬 |
| --- | --- |
| 1時間 | オードエネルギー×4 |
| 2時間 | Skin Chest×10 |
| 3時間 | 強化石×5,000 |
| 4時間 | Head Bow（ヘルムスキン） |

## アカウントの連携

ドロップは、Twitchを連携したアカウントに届きます。

| 遊んでいる環境 | 連携するアカウント |
| --- | --- |
| Steam版 | Steamアカウント（実際に遊んでいるもの） |
| PURPLE版 | NC（PURPLE）アカウント |

連携状況は、NCのウェブサイトの「マイページ > ログイン管理」で確認できます。

> **注意**：ドロップが届かないからといって、NCのウェブサイトでアカウントを再連携しないでください。NCは、既存の連携が解除されてキャラクターに入れなくなる恐れがあると警告しています。

根拠：[S02] [S03]
