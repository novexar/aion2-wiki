アイテムレベル（IL）1,400から2,100までは、新しい遠征が一つずつ開くたびに装備を更新していく道です。1,400で最初の本格的な更新先が開き、1,600から超越とアルカナが始まります。そして2,100で次の遠征が開きます。

ここで重要なのは、「今入れる一番新しいコンテンツに、オードエネルギーを使う」ことと、「足りない部位が出るほうを選ぶ」ことの2つです。強化は最後に回してください。

準備として [[guide-il-700-to-1400]] が済んでいると、この先が楽です。

## この段階のゴール

| IL | 開くもの | この段階の目標 |
| --- | --- | --- |
| 1,400 | バクロン空中島、ウルググ峡谷の征服 | 防具と、武器・アクセサリの両方の更新先を持つ |
| 1,500前後 | 覚醒戦の2段階目（Normal） | ブレスレット2つを+10にする |
| 1,600 | 超越の段階1 | アルカナの枠を埋め始める |
| 1,900 | 超越の段階2 | アルカナを一般から希少、伝承に上げる |
| 2,100 | 炎の神殿、獰猛な角岩窟の征服 | ここで次の段階（[[guide-il-2100-to-2800]]）へ |

根拠：[S01] [S02]

## やることリスト

> **注意**：所要時間はこのWikiの編集上の目安です。受け取り回数は、オードエネルギーの量とチームの集まりで決まります。

### 第1段階：IL1,400で更新先を決める（約30分）

1. **バクロン空中島とウルググ峡谷の違いを確認する。** バクロン空中島は防具とガーダー、ウルググ峡谷は武器とアクセサリの入手先です。足りない部位が出るほうから始めます。→ [[vakron-sky-island]]、[[urugugu-canyon]]
2. **まず、バクロン空中島の探険を3回受け取る。** 3回受け取ると、バクロンの防具7部位から1つ選べます（IL70、一度だけ）。ドロップしにくい胴か脚を選ぶのがお勧めです。→ [[expedition-reward-selection]]
3. **選択権はすぐ使い切る。** 使い切るまで、そのダンジョンには入れません。
4. **探険の次は、征服を回す。** 報酬キューブのコストは40です。征服では装備が唯一（金）で出ます。→ [[expeditions-and-odyle]]

根拠：[S01] [S01] [S03] [S04]

### 第2段階：受け取りの型を作る（毎日）

5. **オードエネルギーは1日120貯まる。** 3時間に15なので、1日に3回分（40×3）の受け取りが目安です。会員は、1つのキューブに2回注入できます。
6. **キューブはクリア後に開く。** 開かないまま退出すると、未受取の10回を1つ使います。0になると征服と超越に入れません。（サーバー内で共有）
7. **中ボスも倒す。** 中ボス分の報酬もキューブに入ります。注入コストは同じなので、飛ばすと損です。
8. **受け取り21回ごとに、選択権が貰える。** ウルググ峡谷ではアクセサリ、バクロン空中島では防具です。装備変更券を選ぶこともできます。→ [[gear-change-voucher]]

根拠：[S05] [S02] [S06] [S07] [S01]

### 第3段階：ブレスレットとベルトを仕上げる（IL1,500前後）

9. **ブレスレット2つを、+10にする。** 1つ目はLv45の覚醒クエスト「悪夢を見る者」で貰える覚醒のブレスレット、2つ目は伝承（青）のブレスレットで構いません。+10までは成功率100%で、レイドまで使えます。→ [[bracelets]]
10. **ベルトとアミュレットのユニーク+10は後回し。** ギーナ5,026,000がかかります。先に武器とガーダーへ回します。→ [[belt-and-amulet]]
11. **覚醒戦を、普通（Normal）で受ける。** IL1,500で入れます。週3回です。リセットの最終日に入ると、その週に開いている最高の難度で遊べます。→ [[ascension-trial]]

根拠：[S01] [S08] [S09] [S01] [S02] [S10]

### 第4段階：製作でアクセサリと武器を上げる（IL1,400〜）

12. **アクセサリを先に、次に武器を製作する。** 最初に直接作れるのは、トゥルー・ドラゴンロード（装備IL62）だけです。→ [[crafting-overview]]
13. **作り替え（アップクラフト）で、段階を1つずつ上げる。** IL62、70、78、86、94、102の順で、段階は飛ばせません。強化、突破、魂刻印は引き継がれます。魔石と霊石は引き継がれません。→ [[crafted-gear]]
14. **ドロップ品は+10までにして、強化は製作装備に集める。** +11以降はギーナの負担が大きいからです。→ [[upgrading-gear-priority]]
15. **製作は、装備するキャラクター本人で行う。** 作り替えた装備は、作ったキャラクターに帰属します。

根拠：[S11] [S12] [S08]

> **注意**：製作に失敗すると何も戻りません。製作中に攻撃を受けても失敗になります。安全な場所で行ってください。

根拠：[S11]

### 第5段階：IL1,600で超越を始める

16. **超越（Transcendence）に入る。** Lv45・IL1,600から入れます。デウス研究基地と砕けたアルカニスの2つです。2〜5人で、入場は無料です。→ [[transcendence-overview]]
17. **クリア後のキューブにオードエネルギー40を注入する。** 報酬はアルカナのカードと通常ギーナです。評価はクリア時間で決まります。
18. **アルカナの5つの枠を、順に埋める。** 聖杯は両方のダンジョンで出ます。羊皮紙とコンパスと鐘と鏡は、片方でしか出ないものがあるので、両方を攻略します。→ [[arcana]]、[[deus-research-base]]、[[shattered-arkanis]]
19. **オードエネルギーを、遠征だけで使い切らない。** 超越にも配分します。アルカナはILを伸ばす最大の単独要素の一つです。

根拠：[S01] [S13] [S14] [S15] [S16] [S07]

### 第6段階：IL1,900で超越を一段階上げる

20. **ILが1,900になったら、段階2に進む。** 一般カードに加えて、希少・伝承カードが出るようになります。
21. **一般のカードを、より良いカードに置き換えていく。** 唯一カードのILは最大85です。
22. **段階が上がると、敵の数と強さが増える。** 挑む前に、ILだけでなく戦闘力も確認してください。→ [[item-level-and-combat-power]]

根拠：[S13] [S14] [S15]

> **要確認**：redfreshetは、段階2以降を開くには前の段階でSランクが必要だと書いています。Maps、Wikirealmには同様の記載がなく、IL条件だけで説明しています。ゲーム内の表示を確認してください。

根拠：[S14]

### 第7段階：IL2,100で次の遠征が開く

23. **獰猛な角岩窟と炎の神殿の征服が開く。** 獰猛な角岩窟は防具とガーダー、炎の神殿は武器とアクセサリです。装備のILは86です。28回受け取るごとに、選択権が貰えます。
24. **ここから先は、次のガイドを読む。** → [[guide-il-2100-to-2800]]

根拠：[S01] [S17]

## オードエネルギーの優先順位

| 状況 | 使い先 |
| --- | --- |
| IL1,400〜1,599 | バクロン空中島またはウルググ峡谷。足りない部位が出るほう |
| IL1,600以降 | 遠征と超越に配分。アルカナが足りないなら超越を優先 |
| 上限（560、会員840）に近い | 入れる場所で今すぐ使う。あふれた分は消える |
| 欲しい報酬がない | キューブは開けずに温存してよい |

根拠：[S05] [S07]

## ギーナの稼ぎ方（簡単に）

- 征服の報酬キューブは、取引できる通常ギーナを出します。★2のバクロン空中島とウルググ峡谷は、1回の受取で約10万ギーナです。
- 取引できるギーナの1日の取得上限は100万です。
- サーバー全体で週84回までの征服受取は満額です。それ以降は減額されます。
- 探険のギーナ（刻印）は、取引できません。

詳しくは [[kina-farming]]、[[kina-and-bound-kina]] を見てください。

根拠：[S05] [S02] [S06]

## やってはいけないこと

- **足りない部位を確認せずに、遠征を選ばない。** 防具側と武器・装身具側の分担があります。
- **選択権を放置しない。** 使い切るまで、そのダンジョンに入れません。
- **突破（Amp）を急がない。** +15の後の段階です。5段階目だけで約1,310万ギーナかかります。武器とガーダーを先にします。→ [[amp-breakthrough]]
- **ルドラのためにオードエネルギーを貯めない。** ルドラはIL2,800が必要で、いま取り下げ中です。→ [[ludra-raid-suspension]]
- **IL条件ぎりぎりで超越に入らない。** 段階が上がるとキル数のノルマが増えます。
- **製作の途中で攻撃を受けない。** 失敗になり、戻りません。
- **未受取のキューブを溜めない。** 10回が0になると、征服と超越に入れません。

根拠：[S02] [S11] [S18]

## 次の段階へ進む条件

ILが2,100に届き、次の項目が済んでいれば、[[guide-il-2100-to-2800]] に進みます。

| 条件 | 確認方法 |
| --- | --- |
| IL2,100以上 | キャラクター画面 |
| アルカナの5枠が埋まっている | アルカナ画面 |
| ブレスレット2つが+10 | 装備欄 |
| 製作のアクセサリが86以上 | 装備欄 |
| 選択権を使い切った | 遠征に入れる |
