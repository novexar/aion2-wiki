クローゼット（Closet、他MMOの「幻化」「トランスモグ」に相当）は、装備の見た目を別のスキンに変える機能です。AION2では **スキンを解放した時点で永続のステータスボーナス** が付くため、見た目の趣味に関係なく、拾えるスキンは集めるほど得をします。着る必要はなく、解放するだけで効きます。

根拠：[S01] [S03]

## 収集ボーナス

| 項目 | 内容 |
| --- | --- |
| 武器スキン | その武器種の「攻撃力増加（%）」が上がる。自分のクラスの武器種だけが意味を持つ |
| 防具スキン | 防具側の同等の効果 |
| 収集ポイント | 初回解放時に 一般1／希少2／伝承3／唯一4 |
| 共有範囲 | 同じサーバーの全キャラクター |
| 等級 | 一般〜唯一＋スペシャル。英雄スキンは存在しない |

攻略者の式では、武器スキンの%は「（最小攻撃力＋最大攻撃力）÷2」に掛かり、結果は **純粋攻撃力**（武器ダメージ増幅が直接掛かる最も価値の高い攻撃力）に加算されます。見た目以上に火力に効く理由です。

根拠：[S01]

## スキンの入手方法

| 方法 | 内容 |
| --- | --- |
| 装備の抽出（分解） | ギーナを払って抽出すると、確率でスキンがクローゼットに入る。クエスト装備は100%、フィールド・アビスのドロップ25%、ボス・遠征・レイドのドロップ10%、製作装備10〜20% |
| 黒雲商人 | ランダム品揃えのギーナ商店。884種のスキン・スキン箱が候補 |
| ショップ／ディーヴァパス | 課金スキン・パス報酬 |
| 合成 | 同じ等級の余ったスキン4個→同等級以上のランダムスキン1個。等級が上がる確率は一般25%、希少20%、伝承15%。唯一は唯一のまま。武器の結果は自分のクラスの武器種 |

モノリスの報酬にスキンは含まれません。

根拠：[S01] [S02]

## 課金スキンとの違い

- NCSOFTは「ショップの外見アイテムはゲームプレイや戦闘で有利にならない」と明言しています。グローバル版の正式開始時点のスキン告知でも、ショップスキンは **収集ポイントを与えない** とされています。
- ファウンダーズパックの外見品も「外見のみ、追加ステータスなし」です。
- 2026-09-30〜10-28のメンテナンスまでのグローバル版ショップには、衣装セット5種（US$29.99 ×3、2,200クァイナ ×2）、クラス専用の武器スキン箱（US$11.99）、ペット・翼スキン（US$19.99）などが並びました。US$29.99のセットは購入したサーバーのキャラクターで使え、クァイナのセットは購入キャラクター専用です。

根拠：[S02]

## 操作のポイント

1. 不要になった装備は売る前に **抽出** する。強化石が戻り、スキンが入る可能性がある。
2. クローゼット画面で、各部位に解放済みスキンを適用する。素材・模様・色を変えられる。
3. 同じスキンが4個余ったら合成で上の等級を狙う。

根拠：[S01] [S02]

## 称号との関係

クローゼット関連の称号には装備効果があります。

| 称号 | 装備効果 |
| --- | --- |
| 空のクローゼット | 戦闘速度3.5%、クールタイム減少3.5%、HP自然回復42 |
| アルトガルドの守護者／ベルテロンの守護者 | PvEダメージ増幅3%、貫通210 |
| 完璧主義者 | ダメージ増幅1.9% |

根拠：[S01]
