グローバル版のシーズン1では、**製作で作る「ドラゴンロード」系の装備が、最上位のPvE装備**です。どの階級のドロップ品よりも強く、装備IL（アイテムレベル）は最大102です。製作の基本は [[crafting-overview]] を参照してください。

根拠：[S01] [S03] [S04]

## ドラゴンロードの段階（作り替えの梯子）

直接作れる唯一装備は「トゥルー・ドラゴンロード（IL62）」だけです。それより上は、**1つ下の段階の装備を素材にして作り替え（アップクラフト）**ます。段階を飛ばすことはできません。

| IL | 段階 | 作り方 |
| --- | --- | --- |
| 62 | トゥルー・ドラゴンロード | 製作。職人のスプレンディッド・オリハルコン装備（唯一44）＋ドラゴン素材 |
| 70 | スプレンディッド・トゥルー・ドラゴンロード | 62をアップクラフト（素材） |
| 78 | ホワイト・ドラゴンロード | 70をアップクラフト。職人のスプレンディッド装備1つと素材 |
| 86 | スプレンディッド・ホワイト・ドラゴンロード | 78をアップクラフト（素材） |
| 94 | ワイズ・ドラゴンロード | 86をアップクラフト。職人のスプレンディッド装備1つと素材 |
| 102 | スプレンディッド・ワイズ・ドラゴンロード | 94をアップクラフト（素材） |

- 陣営によって名前が違うだけで、同じ装備です（トゥルー／スター、ホワイト／ダーク、ワイズ／エボニーなど）。名前ではなく段階で見てください。
- スプレンディッドへの作り替えは、ギーナではなく素材で行います。
- **アップクラフトは必ず成功**します。熟練度も要求されます（作り替えの画面に必要な熟練度が出て、足りないと警告されます）。
- 武器・ガーダー・防具7部位・イヤリング・ネックレス・リングにドラゴンロードのレシピがあります。ブレスレット、アミュレット、ベルト、ルーンにはありません。

根拠：[S01]

## 引き継がれるもの

| アップクラフトで引き継がれる | 引き継がれない |
| --- | --- |
| 強化段階 | 魔石・霊石 |
| 突破（Amp）の段階 | |
| 魂刻印（ステータスライン） | |

そのため、**ドロップ品は+10まで、ギーナは製作装備に**、という進め方が勧められています。[[upgrading-gear-priority]]

根拠：[S01]

## 装備の特徴

| 項目 | 内容 |
| --- | --- |
| ステータスライン | ドラゴンロード装備は5本（唯一のドロップ品は4本） |
| PvEの固定ライン | なし（グローバル版の製作装備には、固定のPvEダメージ増幅・耐性はない） |
| 潜在能力 | 他の唯一装備と同様にPvPの潜在能力が付く。[[potential]] |
| 突破の段階 | スプレンディッドは1つ下の帯。IL70で1、86で3、102で5。[[amp-breakthrough]] |
| 装着 | 装着すると魂刻印が付き、取引できなくなる。売るなら装着前に |
| 製作者 | アップクラフトした装備は、作ったキャラクターに帰属する。**装備するキャラクター本人で作る** |

根拠：[S01] [S02]

## 製作の成功率とCOMBO

- 通常の製作は失敗することがあり、失敗すると何も戻りません。成功率は熟練度で上がります（トゥルー・ドラゴンロードは必要熟練度で67.5%、熟練度100で94%）。
- 成功したとき、25%の確率で「ラッキー（COMBO）クラフト」が判定され、成功すると通常の結果が上位品に置き換わります。ラッキーに失敗すると何も出ません。
- 62の製作で70が出ることがあります（熟練度55で約14%、100で約23%）。78と94へのアップクラフトは必ず成功し、86か102が25%の確率で出ます。
- 基礎になる職人のスプレンディッド装備は、オリハルコン(18)、熟練者(28)、職人(39)の製作のラッキーを連ねて作ります。熟練度を上げてから回すと、必要な回数が大きく減ります。

根拠：[S01]

## 必要な熟練度

| 装備 | 必要熟練度 |
| --- | --- |
| トゥルー・ドラゴンロードの武器・リング・胸・ズボン・ヘルム・ショルダー | 55 |
| ガーダー・グローブ・ブーツ・マント・ネックレス・イヤリング | 60 |
| 上位のアップクラフトに使う硬いバラウルの部品 | 65、80 |

50を超えるには、その製作の専門昇級（クエスト）が必要です。

根拠：[S01]

## 素材

- ドラゴン素材はドロップで、取引できます。ただしマーケットで買うにはメンバーシップが必要です。
- NPCの商人で買えるのは、オリハルコンの溶剤（400ギーナ）とジルコンのハンマー（4,650ギーナ）の2つだけです。
- すべてのドラゴンロード装備に「バラウルのエッセンス」が必要です。1回の製作でエッセンス2個がバラウルの部品に変わります。リングで16個、胸で30個、弓や長剣で44個です。
- 製作に出る素材は、鉱石、宝石、木材、オードなど（[[gathering]]）。
- 売れるのは、バラウルのエッセンス、精錬石、採集した鉱石とオード、ポーション、食べ物などです。スプレンディッド装備とトゥルー・ドラゴンロード装備も出品できます。

根拠：[S01]

## 注意

- 製作の失敗は、サポートでも元に戻せません。また、製作は途中で止められず、攻撃を受けると失敗になります。
- 製作装備は、IL上限が102です。ほかの上位（英雄・神話）はありません。[[equipment-slots-and-grades]]
