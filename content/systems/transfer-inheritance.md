継承（Transfer）は、育てた装備を新しい装備に乗り換えるときに、**強化の積み上げを引き継ぐ**仕組みです。引き継ぎ先に同じ部位の唯一装備を用意すれば、強化をゼロからやり直さずに済みます。

根拠：[S01] [S02]

## 条件と費用

| 項目 | 仕様 |
| --- | --- |
| 対象の等級 | 唯一（Unique）のみ。希少・伝承は継承できない |
| 組み合わせ | 同じ部位どうし。武器は同じクラスの武器どうしだけ（ロングソード→グレートソードは不可） |
| 等級をまたぐ継承 | 不可（上の等級への継承はない） |
| 費用 | 継承石（唯一）。第1・第2帯は1個、第3帯は2個。ギーナは不要 |
| 成功率 | 常に100%（何回目でも） |

継承は装備ILの3つの帯で分かれます。

| 帯 | 新しい装備のIL |
| --- | --- |
| 第1帯 | 36〜70 |
| 第2帯 | 70〜86 |
| 第3帯 | 86〜102 |

第3帯へ継承する場合は、**どの帯の元装備でも**使えます。

根拠：[S01] [S02]

## 引き継がれるもの・引き継がれないもの

| 引き継がれる | 引き継がれない |
| --- | --- |
| ステータスライン（魂刻印のライン） | 魂融合（Soul Fuse）の追加ライン |
| 強化段階（+N） | 魔石・霊石 |
| 突破（Amp）の段階 | 神石（テオストーン） |
| | 潜在能力（Potential） |

- 製作装備のアップクラフト（上位の段階への作り替え）でも、強化・突破・魂刻印が次の段階へ引き継がれます。魔石は引き継がれません。[[crafted-gear]]
- 魔石・神石・潜在能力は移らないため、**長く使う装備にだけ**投資します。[[manastones-and-soulstones]] [[potential]]

根拠：[S01] [S04]

## 継承石の入手

物質変換（Substance Morph）で、ドロップした唯一装備（IL36〜102）1つが継承石（唯一）1個になります。そのため、使わない唯一装備は捨てずに取っておくと、継承の材料になります。[[substance-morph]]

根拠：[S01]

## 手順

1. 新しい唯一装備（同じ部位）を入手する。
2. 統合強化画面（Nキー）の「継承」を開く。
3. 元の装備と新しい装備を選び、継承石の必要数を確認する。
4. 実行する。強化段階・突破・ステータスラインが新しい装備へ移る。

> **注意**：画面の表示が優先です。表示される継承石の数や対象の帯は、ゲーム内で確認してください。

根拠：[S01] [S02]

## よくある質問

**Q. 希少・伝承の装備は？**
A. 継承できません。乗り換えたら抽出して強化石を取り戻します。[[extraction]]

**Q. 乗り換え先の方が弱く見える。**
A. 未強化の新装備は、強化済みの現装備より低く見えることがあります。装備IL・基礎性能・強化後の伸びしろで比べます。[[upgrading-gear-priority]]

根拠：[S02] [S03]
