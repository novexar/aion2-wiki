翼（Wings）は飛行に使う装備であると同時に、集めるほど強くなるコレクション要素です。**装備効果** はその翼を着けている間だけ、**所持効果** は一度手に入れれば着けていなくても永続します。見た目は別の翼に変えられるので、「性能で1枚選び、残りは所持効果のために集める」のが基本です。

根拠：[S01] [S02] [S03]

## 効果の仕組み

| 種類 | いつ効く | 内容 |
| --- | --- | --- |
| 装備効果（Equip Effect） | 装備中のみ | 攻撃力・クリティカル・ボスダメージ増幅など、翼ごとに固定 |
| 所持効果（Owned Effect） | 所持していれば常時 | 小さめのステータス＋飛行力（どの翼も飛行力200、ディーヴァの翼は500） |

所持効果は持っている翼すべての分が加算されるため、使わない翼も捨てずに集める価値があります。翼を25種類集めると能力が上がる称号がもらえます。

根拠：[S01] [S02]

## グローバル版では強化できない

> **注意**：グローバル版の正式開始時点では、翼の強化は実装されていません。すべての翼の所持効果は固定値です。

> **韓国版のみ**：韓国版では翼を+0〜+10まで強化でき（希少・伝承は必ず成功、唯一は+4以降に失敗あり）、所持効果が上昇します。日本語Wikiの一部にこの仕様が載っていますが、グローバル版には当てはまりません。

根拠：[S01] [S02] [S04]

## 入手方法

| 入手先 | 翼 |
| --- | --- |
| 序盤のクエスト（推奨Lv5前後） | 下級ディーヴァの翼（最初の翼） |
| クエスト（推奨Lv30前後） | アウルラウの翼 |
| 征服（Conquest）ダンジョンのドロップ | 各ダンジョン固有の **封印された翼**（下表） |
| 封印ダンジョンの素材交換 | 封印の翼／栄光の翼（封印された翼の羽毛×70、純粋なオード×10） |
| 悪夢ショップ | 悪夢の翼／征服者の翼 |
| アビス・闘技場・戦場ショップ | 乱闘者の翼／戦士の翼 |
| シーズンショップ | タリスラの翼 |
| フェスタショップ | 春花蝶の翼／精霊の翼 など |
| ヒドゥンキューブ | 輝く愛の翼 |
| 覚醒 | 上級／究極ディーヴァの翼 |

ショップで買う翼（ファウンダーズパックの灼熱の太陽の翼など）は外見専用でステータスがありません。

根拠：[S01] [S02]

### 征服ダンジョンと封印された翼

| 征服ダンジョン | 封印された翼 |
| --- | --- |
| クラオ洞窟 | 黒い破片の翼 |
| ドラウプニル | 青い波の翼 |
| ウルググ峡谷 | 古代アウルラウの翼 |
| バクロンの空中島 | 森の精霊の翼 |
| 炎の神殿 | クロメデの翼 |
| 獰猛な角岩窟 | 暗い帳の翼 |

ドロップ率はクライアントデータの解析で **最終ボスの報酬1回あたり0.75%、中ボス報酬1回あたり0.25%**（征服のみ、天井なし）。1回の受取で3ボス分が抽選されるため、受取1回あたり約1.25%、平均約80回の受取が目安です。

封印された翼は取引可能ですが、完成した翼は帰属（取引不可）になります。売るか自分で使うかは変換前に決めてください。

根拠：[S01] [S04]

### 封印を解く（物質変換）

1. 物質変換（Alt+H）を開く。
2. 「封印された○○の翼」のレシピを選ぶ。
3. 材料 **光るオード×10** を用意して変換する（翼の代わりに強化石10,000個を使う別レシピも登録されています）。

光るオードは精気抽出で手に入る最上位グレードのオードです（[[essence-extraction]]）。

根拠：[S01] [S02]

## 翼ごとの効果（抜粋）

| 翼 | 所持効果 | 装備効果 |
| --- | --- | --- |
| 悪夢の翼 | ボス攻撃20、ボス防御300、PvEダメージ増幅1% | ボスダメージ増幅3.5%、追加攻撃力60、クリティカル35、追加命中35 |
| 暗い帳の翼 | ダメージ増幅1%、ボス防御300、PvE攻撃20 | ダメージ増幅2.5%、追加攻撃力60、ボス防御500、ボスダメージ耐性3.5% |
| 森の精霊の翼 | ダメージ耐性1%、ボス攻撃30、追加命中20 | ダメージ耐性2.5%、追加防御400、ボス攻撃95、ボスダメージ増幅3.5% |
| タリスラの翼 | 追加防御100、追加攻撃10、追加命中20 | 追加攻撃力60、追加命中35、クールタイム減少4%、追加防御400 |
| 乱闘者の翼 | 状態異常発動率2.5%、PvPダメージ増幅1%、PvP防御100 | 状態異常抵抗3%、状態異常発動率3%、HP500、追加防御400 |
| クロメデの翼 | HP50、HP自然回復50、追加攻撃10 | 追加攻撃力60、クリティカル35、HP500、HP自然回復250 |

所持効果にPvEダメージ増幅が付くのは悪夢の翼だけ、ダメージ増幅が付くのは暗い帳の翼だけです。前方／後方ダメージ増幅を持つ翼はありません。

根拠：[S01]

## 初心者向けのおすすめ

- PvEのボス戦なら悪夢の翼か森の精霊の翼、全体火力なら暗い帳の翼、PvPなら乱闘者の翼が候補です。
- 最初の翼は装備効果がHP+200だけですが、所持しているだけで飛行力が上がるので必ず入手しておきましょう。
- 征服の翼は低確率なので「狙って周回する」より「装備集めのついでに出たら嬉しい」程度に考えます。
