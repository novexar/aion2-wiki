採集は、フィールドの鉱石・宝石・木・草・食材・オードを集める生活スキルです。ゲーム内の正式名は **精気抽出（Essence Extraction）** で、空中にあるオードの採集は「オード抽出（Odyle Extraction）」と呼ばれます。集めた素材は [[crafting-overview]] の製作や、[[substance-morph]] の変換に使います。

根拠：[S01] [S04]

## 基本ルール

| 項目 | 内容 |
| --- | --- |
| 解放 | キャラクターLv10（レベル上げの途中から採集できる） |
| 操作 | 採集物に近づいてインタラクトする。成功ゲージと失敗ゲージが競い、先に満タンになったほうで結果が決まる |
| 試行回数 | 1つのノードにつき3回まで（成功でも失敗でも1回と数える）。使い切るとノードは消える |
| 費用・上限 | 無料。1日の上限もない |
| オード | 空中にあり、飛行して採集する。[[flight-and-glide]] |
| 熟練度 | 1〜100。50で昇級が必要。[[essence-extraction]] |

根拠：[S01] [S06]

> **要確認**：redfreshet は「精気抽出はLv45から」と説明しています。ゲームデータに基づく資料（Aion 2 Maps、wikirealm）はLv10解放としており、この記事は後者に従っています。

## 素材の等級

鉱石とオードは、1つのノードからどの等級も出ます。

| 等級 | 呼び名 |
| --- | --- |
| 一般 | （無印） |
| 希少 | Fine |
| 伝承 | Pure |
| 唯一 | Radiant |

パッシブの「鉱石鑑定」「オード鑑定」は高い等級が出る確率を上げ、「豊作」は取れる量を増やします。

根拠：[S01] [S04]

## 素材の種類と場所

陣営によって地域が分かれます。天族はベルテロンとエルテネン、魔族はアルトガルドとモルヘイムが対象です。

| 系統 | 天族側（ベルテロン、エルテネン） | 魔族側（アルトガルド、モルヘイム） | ノード数 |
| --- | --- | --- | --- |
| 鉱石 | Orichalcum（オリハルコン） | 同左 | 1,632 |
| 宝石 | Diamond、Ruby、Sapphire | 同左 | 各579〜591 |
| 木材 | Yggdrasil（ユグドラシル） | Asvata（アスバタ） | 196／226 |
| 薬草 | Aria、Targena | Azpha、Calendula | 169〜241 |
| 野菜 | Coriolus、Kukuru | Morfa、Ohkra | 141〜152 |
| 果実 | Mela | Raydam | 144／150 |
| 水生生物 | Cypri、Inina | Conide、Pujery | 141〜162 |
| オード | Odyle（オード）。両陣営の全地域と混沌の下層レシャンタ | 同左 | 2,354 |

- 木材・薬草・野菜・果実・水生生物は、陣営ごとに別の素材が割り当てられています。鉱石・宝石・オードは共通です。
- ノード数は、数字が2つあるものは天族側/魔族側の順です。範囲で書いたものは、その系統の素材ごとの最小〜最大です。
- エルテネンとモルヘイムは、ノードのデータはあるものの、グローバル版の開始時点では地域が開放されていません。実際に回れるのはベルテロンとアルトガルドが中心です。
- ノードの正確な位置は、Aion 2 Maps の3Dマップで確認できます。

根拠：[S02] [S03] [S04]

## 専門技術のスキル

- 採集の専門は最大2つまで上げられます。熟練度100までに14ポイントが得られます。
- 素材の系統（鉱石・宝石・木材・薬草・食材・オード）ごとに、7ポイントで最大まで振れます。
  - 探索者（Seeker）：1ポイント
  - 豊作（Plentiful Harvest）：3ポイント。最大30%の確率で2倍
  - 鑑定（Appraiser）：3ポイント。最大30%の確率で等級を引き直し
- レベル2・3のスキルは熟練度51以上が必要です。振り直しは50,000ギーナです。

根拠：[S01]

## オードの使い道

オードは製作の全ての段階で使います。また、物質変換で鉱石・宝石・木材・薬草・オードエネルギーに変えられます。オードと「オードエネルギー」は別物です。[[odyle-energy]]

根拠：[S01] [S05]
