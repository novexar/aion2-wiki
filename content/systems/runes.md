ルーン（Rune）は、装備欄の一番下にある **2つの特殊枠** に付ける装備です。グローバル版で入るのは「激突のルーン（Clash Rune）」だけです。ほかの装備と違い、**強化に失敗するとルーンそのものが消える**ので、扱いに注意が必要です。

根拠：[S01] [S02] [S03]

## 激突のルーンの基本

- アイテムレベル40のスペシャル等級のルーンです。
- 未強化（+0）の状態でも、次のPvE向け能力値が付きます。

| 能力値 | +0のとき |
| --- | --- |
| PvEダメージ耐性 | 0.5% |
| PvEダメージ増幅 | 0.5% |
| 貫通 | 100 |
| 戦闘速度 | 1% |
| 多段ヒット的中 | 1% |

- 枠は2つあるので、まず **2個とも装備する** のが先です。1個だけ高く強化するより、空き枠をなくすほうが序盤の育成に効きます。

根拠：[S01]

## 入手方法

最初のルーンは地域クエストで **無料で最大4個** もらえます。報酬の「激突のルーン箱（刻印）」を開くと、ルーン1個と「激突のルーン強化スクロール（刻印）」9枚が出ます。

### 天族（ベルテロン）

| 推奨Lv | クエスト |
| --- | --- |
| 30 | 呪われた青い鉱物 |
| 37 | ズミオンの呼びかけ：後編 |
| 45 | クラカ池の厄介者 |
| 45 | このままでは皆大変なことになる |

### 魔族（アルトガルド）

| 推奨Lv | クエスト |
| --- | --- |
| 30 | 現在は過去の未来 |
| 32 | ヒューゴ傭兵団：あの時の約束 |
| 45 | 始まる後暴風 |
| 45 | 別の生存者 |

- Lv30台で2個、Lv45付近まで進めるとさらに2個もらえます。
- Lv45のクエストには前提クエストがあり、エピソードや地域クエストの進行状況で表示されないことがあります。見つからないときは、残っている地域クエストを先に進めてください。[[regional-quests]]
- 4個とも取得済みで追加が必要なときは、悪夢の商店で夢幻の破片500個と交換できます。シーズン商店（誓いのコイン）でも入手できます。[[phantasmal-fragments-nightmare-shop]] [[oath-coins-season-shop]]

根拠：[S01]

## 強化の成功率と費用

強化には、強化石、ギーナ、ルーン専用のスクロール（1回につき1枚）が必要です。

| 強化 | 成功率 | 強化石 | ギーナ |
| --- | --- | --- | --- |
| +0→+1 | 100% | 200 | 5,000 |
| +1→+2 | 80% | 290 | 9,070 |
| +2→+3 | 66% | 520 | 19,700 |
| +3→+4 | 50% | 800 | 40,000 |
| +4→+5 | 33% | 1,120 | 84,900 |
| +5→+6 | 25% | 1,470 | 147,000 |
| +6→+7 | 20% | 1,860 | 233,000 |
| +7→+8 | 15% | 2,270 | 379,000 |
| +8→+9 | 12% | 2,700 | 563,000 |
| +9→+10 | 10% | 3,170 | 793,000 |

- **+2以降は、失敗するとルーンが消えます。** 救済（失敗のたびに確率が上がる仕組み）もありません。装備の強化とは別のルールです。
- 失敗で消えたルーンの分も含めた平均で、+7まで上げるには約230個、+8までは約1,530個のルーンが必要になります。上位のプレイヤーの多くは両方を+7で止めています。

根拠：[S01] [S02] [S03] [S04]

## おすすめの進め方

1. 地域クエストでルーンを2個入手し、両方に装備する。
2. 2個とも +1 にする（合計：強化石400個、ギーナ10,000、スクロール2枚。必ず成功）。
3. +2以降は、3個目・4個目のルーンとスクロールを確保してから検討する。
4. 高強化は、武器・防具・ベルト・アミュレットが整ってから、余裕のあるときだけにする。[[upgrading-gear-priority]]

> **注意**：装備中の2個しか持っていない段階で+2に挑戦するのは、リスクのわりに得が小さいです。グローバル版では、+2以降の強化失敗でルーンを失ったという報告があります。

根拠：[S01] [S02] [S03]

## よくある質問

**Q. ルーンが消えた。バグ？**
A. 仕様です。+2以降の強化に失敗するとルーンは消えます。

**Q. ルーンが消えてもキャラの作り直しは必要？**
A. 不要です。未クリアの地域クエストがないか確認し、すべて取得済みなら悪夢の商店で交換します。
