錬金（Alchemy）は、**魔導書・オーブ、ポーション、スクロール、魔石・霊石**を作る専門技術です。スピリットマスターとソーサラーの武器を自作でき、消耗品の自作にも使えます。全体の仕組みは [[crafting-overview]] を参照してください。

根拠：[S01] [S02] [S05]

## 作れるもの

| 区分 | 内容 |
| --- | --- |
| 武器 | 魔導書（スペルブック）、オーブ |
| 消耗品 | ポーション・エリクサー、スクロール。[[consumables-and-scrolls]] |
| 石 | 魔石・霊石。中級と上級は錬金でしか手に入らない。[[manastones-and-soulstones]] |
| 素材 | 魔法の結晶、紙、精霊石の粉、宝石の粉、強化したバラウルの鱗 |

- レシピ数は約87です。
- 刻印済みの石も、錬金のレシピに使えます。

根拠：[S02] [S03] [S04]

## 熟練度の上げ方

| 熟練度 | 作るもの | 材料 |
| --- | --- | --- |
| 1〜5 | 魔法の結晶（Magic Crystal） | Spiritstone ×2、Catalyst（刻印）×1（商人で400ギーナ） |
| 1〜 | 生命の血清（Life Serum） | 新鮮なアリア（薬草）、ガラス瓶 |
| 5〜 | 紙、精霊石の粉 | 加工素材など |
| 20〜 | 宝石の粉 | 宝石など |
| 50 | 昇級用「Novice Alchemist's Scale（刻印）」 | Magic Crystal ×6、Spiritstone Powder ×2、Odyle ×3 |

- 成功率は熟練度1で95.2%、48で最大99.15%です。
- 1〜5の区間に必要な経験値は合計120です。最初はこの素材から始めます。
- 魔石は、熟練度が上がってから作れるようになります。

根拠：[S01] [S04]

## ドラゴンロード装備

錬金でも「バラウルの鱗」を作れます。スピリットマスターとソーサラーの武器（魔導書・オーブ）のドラゴンロード装備は、錬金の熟練度が必要です。段階の上げ方は [[crafted-gear]] を参照してください。

根拠：[S02]

## 集めたい素材

精霊石、薬草、宝石、オード、ガラス瓶などの商人素材です。ポーションやスクロールにも素材を大量に使うので、日頃から薬草や精霊石を残しておくと進めやすくなります。

オードを薬草に変える物質変換にも、錬金の熟練度が必要です（上位の等級は30以上）。[[substance-morph]]

根拠：[S02] [S05]
