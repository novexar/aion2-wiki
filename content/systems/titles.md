タイトル（Title、称号）は、実績・クエスト・探索・フィールドボスなどで手に入る「肩書き」です。見た目だけではなく、**取得しただけで常時効く「所持効果」** と、**装着しているときだけ効く「装着効果」** の2種類のステータスを持つものが多く、戦闘力に大きく影響します。Lv6 前後のクエストで解放されます。

根拠：[S01] [S05]

## 仕組み

| 項目 | 内容 |
| --- | --- |
| 所持効果 | 取得した時点で永続。装着していなくても効く |
| 装着効果 | 装着中だけ効く。**攻撃・防御・その他** の3枠に1つずつ装着 |
| アイテムレベル | 上がらない。戦闘力（Combat Power）には大きく反映される |
| 分類（DB） | 一代記・成長・挑戦・探険・激突・資源 |
| 等級 | 一般・希少・伝承・唯一・スペシャル |

根拠：[S01] [S03]

> **注意**：グローバル版では、タイトルの **約半数が非表示** で、表示されるタイトルの効果も韓国版より弱く、強打（Smite）を与えるタイトルは1つもありません。韓国版の「強打タイトル一覧」はグローバル版には当てはまりません。根拠：[S02]

## 入手先の例

| 入手先 | 例 |
| --- | --- |
| メインクエスト・覚醒の進行（一代記） | 「アーリーアダプター」など |
| 地域の探索・地域クエスト完了（成長） | 「ベルテロン地域に詳しい」「ベルテロン地域の解決士」 |
| フィールドボス初討伐 | ボスごとに1つ |
| アビスのランク（挑戦） | 「アビス[シーズン1]一等兵」〜「三星将校」など |
| 製作・採集（資源） | 「★★★料理人」など |
| モノリスの共鳴段階 | 段階ごとの称号 |

AION2 Hub のデータベースではクライアント上の 1,494 タイトル（うち 994 がステータス付き）をステータス別に絞り込めます。グローバル版で実際に取れるかは、ゲーム内のタイトル画面で「取得条件」を確認してください。

根拠：[S01] [S03] [S04]

## 戦闘力への影響

タイトルはアイテムレベルを上げませんが、所持効果が積み重なるため戦闘力の差になります。グローバル版の上位500人は約200個のタイトルを所持しているというデータがあります。フィールドボスを1回殴る、地域のクエストを全部終える、といった「ついで」で集まるものから拾っていきます。

根拠：[S01]

## やること

1. タイトル画面を開き、攻撃・防御・その他の3枠に、装着効果が自分のビルドに合うものを付ける。
2. 新しいタイトルを取ったら所持効果を確認する（装着しなくても効く）。
3. 通りかかったフィールドボスは1回でも攻撃してタイトルと参加報酬を取る。[[field-bosses]]

根拠：[S01]
