主神ステータス（Pantheon stats。「神ステ」とも呼ばれます）は、AION の主神の名を冠した10種類の特別なステータスです。1種類につき **2つの効果** を持ち、1ポイントで両方の効果が **0.1%** ずつ上がります（10ポイント＝1%）。ブレスレット、アルカナ、パンテオン画面の装飾、モノリスから得られます。

根拠：[S01] [S02]

> **韓国版のみ**：韓国版は1ポイント 0.2% です。グローバル版は **半分の 0.1%** に調整されています。韓国の数値例をそのまま使わないでください。根拠：[S01] [S03]

## 10種類の主神ステータス

| 主神ステータス | 効果1 | 効果2 |
| --- | --- | --- |
| 知恵［ルミエル］ | MP消費減少 | 強打（Smite） |
| 時間［シエル］ | 戦闘速度 | 強打抵抗 |
| 破壊［ジケル］ | 攻撃力増加 | 完璧抵抗 |
| 幻想［カイジネル］ | 再使用時間減少 | 忍耐貫通 |
| 死［トリニエル］ | クリティカル | 再生貫通 |
| 正義［ネザカン］ | 防御力 | 完璧発動 |
| 自由［バイゼル］ | 命中 | 回避 |
| 空間［イズラフェル］ | 移動速度 | ブロック |
| 運命［マルクタン］ | MP | 忍耐発動 |
| 生命［ユスティエル］ | HP | 再生発動 |

用語の意味：
- **強打（Smite）**：PvE で 2倍（PvP で 1.5倍）のダメージが出る確率。英語クライアントでは Double Chance と表示。
- **完璧（Perfect）**：武器のダメージ幅の最大値で当たる確率。
- **忍耐（Endurance）**：被ダメージを半分にする確率。**再生（Regeneration）**：受けたダメージの20%を回復する確率。それぞれ対応する「貫通」でしか打ち消せない。
- **攻撃力増加** は固定値ではなく倍率（「威力」と同じ系統）。

根拠：[S01]

## 火力で重要なのは3つ

攻略で共通して優先されるのは次の3つです。

1. **知恵**（強打）：攻撃系で最も価値が高いとされる。
2. **破壊**（攻撃力増加）：攻撃力全体にかかる倍率。
3. **時間**（戦闘速度）：単体で最上位のステータスとして重ねたい。

死のクリティカルはクリティカル上限（ツールチップ上 50%）に含まれるので、上限に達していると意味がありません。

根拠：[S01] [S03]

## 入手先

| 入手先 | 内容 |
| --- | --- |
| ブレスレット（2枠） | オプションはすべて主神ステータス（10種それぞれ10%で抽選）。スキルLvは付かない |
| アルカナ | カード1枚につき主神ステータス1種。種類×セットで決まる（聖杯：活力＝時間／魔力＝空間 など） |
| パンテオン画面 | 神像4枠＋コロッサス1枠＋芸術品12枠。**飾っている間だけ** 効果がある |
| モノリス | 神の痕跡を納めると、マップごとに各主神ステータス5〜6 |

根拠：[S01] [S02] [S04]

### パンテオンの装飾の入手例

| 入手方法 | 装飾 | 効果 |
| --- | --- | --- |
| ドラウプニル征服 10回クリア（実績） | 神像：超越したバカルマ（唯一） | 死・自由・空間 +12 |
| 自マップのキベリスク全61か所登録（実績） | 神像：キベリスク | 自由・空間 +10 |
| 炎の神殿征服 10回クリア（実績） | 神像：欲望の鏡 | 自由・空間 +8 |
| ルドラ 3回クリア（実績） | 芸術品：深淵のルドラ | 運命・幻想・知恵 +5 |
| シューゴ フェスタ商店 | 芸術品10種（キャラごと各1） | 2,000証（アルドゥス神殿は10,000証） |
| 悪夢の交換商店 | 神像（ジケルの幻影のコロッサスなど） | 夢幻の破片 |

天族側のクライアント登録は コロッサス5・神像16・芸術品76 で、最上位コロッサスは「守護の君主ナーマ」とされています。

根拠：[S01] [S02]

## アルカナを選ぶ＝主神ステータスを選ぶ

アルカナはカードごとに主神ステータスが固定なので、どのセットのどのカードを装着するかで主神ステータスの構成が決まります。グローバル版の5枚構成では「聖杯（時間）、鐘（破壊）、鏡（知恵）」が火力の3つに対応します。詳しくは [[arcana]]。

根拠：[S01] [S04]
