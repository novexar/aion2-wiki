> **要確認**：アイテムの種類はデータベース（S01）で確認できており、毎日出席簿の戦闘強化スクロール（2日目・9日目に各10個）は Gamerch（S03）でも確認できました。一方、「5分間効果」「白は雑貨商人で約1,000ギーナ」「青は錬金や報酬で入手」は aion2.run（S02）の1資料のみで、独立した第2資料が見つかっていません。効果の数値（回復量、上昇率）は裏付けがないため書いていません。ゲーム内のアイテム説明を確認してください。

消耗品（Consumables）は、戦闘や移動を助ける使い捨てのアイテムです。ボス戦の前に使うことが多く、ローテーションの一部として扱われます。

根拠：[S02]

## 種類（データベースの分類と主なアイテム）

| 分類 | 主なアイテム |
| --- | --- |
| ポーション | 治癒のポーション、生命のポーション、精神のポーション（上級版もある） |
| スクロール（巻物） | 加護のスクロール、勇気のスクロール、疾走のスクロール、戦闘強化スクロール、状態異常抵抗スクロール（加護・勇気・疾走は上級版もある） |
| 料理／飲料 | 料理（[[crafting-cooking]]）で作る食べ物。ステーキなど |
| 移動 | 帰還スクロール、アジト帰還スクロール |
| 装備強化 | ベルト・アミュレット・ルーンの専用強化スクロール |
| その他 | 補給、クエスト用、図案・昇級用（製作の昇級に使う調味料など）、特殊 |

- 戦闘や移動を助ける消耗品は、5分間効果が続くものと説明されています。
- 状態異常抵抗スクロールは、名称のとおり状態異常への耐性に関するアイテムです。状態異常そのものは [[status-effects-and-cc]] を参照してください。

根拠：[S01] [S02]

## 入手先

| アイテム | 入手先 |
| --- | --- |
| 白（一般）の戦闘用消耗品 | 雑貨商人で購入（約1,000ギーナ） |
| 青（上位）の戦闘用消耗品 | 錬金（[[crafting-alchemy]]）や報酬 |
| 戦闘強化スクロール（刻印） | 毎日出席簿（14日間）の2日目と9日目に各10個 |
| 料理 | 料理で作る |

- 錬金は、ポーションやスクロールを作る専門技術です。薬草や精霊石を日頃から取っておくと進めやすくなります。
- 出席簿など、受け取れる報酬は [[attendance-and-growth-rewards]] を参照してください。

根拠：[S02] [S03]
