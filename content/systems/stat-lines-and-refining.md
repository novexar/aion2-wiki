> **要確認**：ラインの確率は、アジア版で公開された確率に基づく Aion 2 Maps の整理が主な根拠です（Gameplay.tips の表も、武器の最レアがダメージ増幅の約2%、戦闘速度・武器ダメージ増幅が約4%など、相対的な順位は一致します）。ただし防具の特殊ラインはグローバル版で重みが下げられており、数値は部位ごとの「目安」です。ラインの正確な確率や数値はゲーム内で装備ごとに確認してください。

ステータスライン（Stat lines）は、唯一装備に付く追加効果です。装備を初めて装着したときに付き、[[soul-binding]] で値を上げたり引き直したりできます。ラインの内容によって戦闘力が大きく変わるため、**長く使う装備のラインを厳選する**のがエンドゲームの楽しみ方の一つです。

根拠：[S01] [S04] [S05]

## ラインの基本ルール

| 項目 | 内容 |
| --- | --- |
| ラインの抽選 | 80%が一般ステータス、20%が自分のクラスのスキル。同じラインが1つの装備に2回付くことはない |
| ライン数 | 唯一ドロップ品は4、製作のドラゴンロード装備は5、ルドラの武器は3 |
| 値 | 最も低い値が最も出やすい。最初の抽選の値は範囲の下から約5分の1の位置が平均 |
| 継承 | ラインは継承で移る（魂融合のラインを除く） |
| ブレスレット | 主神ステータスのみで、スキルラインはない。[[bracelets]] |

- **先にラインを引き当て、その後に束縛で値を上げる**のが基本です。珍しいラインで最高値を同時に狙うのは非常に難しいです。
- 1本だけ引き直すときは、すでに付いているラインは出ません。表の確率よりも実際は少し有利です。

根拠：[S01] [S02]

## 武器・ガーダーのライン

全ての武器の種類が同じ表を使います。

| ライン | 1本あたりの確率 |
| --- | --- |
| ダメージ増幅 | 1.6% |
| 戦闘速度、武器ダメージ増幅、状態異常系 | 各3.2% |
| 威力（Might）、多段ヒット | 各4.8% |
| 精密（Precision）、攻撃力、クリティカル、ブロック、前後方攻撃系 | 各5.6% |
| 命中、HP、MP、クリティカル攻撃 | 各6.4% |
| 自分のクラスのスキル | 合計20%（均等に分配） |

最もレアなのはダメージ増幅で、5本全部を引き直したときに1本以上出る確率は約8%です。

根拠：[S01]

## 防具のライン

防具は共通の一般ライン（攻撃力など）とクラススキルに加え、**部位ごとの代表ライン1つ**と特殊ライン4つを持ちます。

| 部位 | 代表ライン | 攻撃系の特殊ライン |
| --- | --- | --- |
| ヘルム | 被治療量 | スマイト、攻撃力増加 |
| マント | クリティカルダメージ耐性 | スマイト、パーフェクト、攻撃力増加 |
| ショルダー | クリティカルダメージ増幅 | なし |
| 胸 | ダメージ増幅 | なし |
| ズボン | ダメージ耐性 | パーフェクト、攻撃力増加 |
| グローブ | 戦闘速度 | パーフェクト |
| ブーツ | 移動速度 | パーフェクト |

- スマイトは、ヘルムとマントにだけ出ます（1本あたり1.2%）。
- 製作の胸防具のダメージ増幅は、IL62で最大5.16%、IL102で6.58%です。
- グローバル版は特殊ラインの重みを、アジア版の公開確率より低くしています。

根拠：[S01]

## 装身具のライン

ネックレス・イヤリング・リングは、一般ステータス（攻撃力、クリティカル、命中、ブロック、HP、MPなど）とクラススキルが共通のプールです。全てに威力と精密が出る可能性があり、イヤリングは移動速度、ネックレスは戦闘速度も出ます。

根拠：[S01]

## 精錬石について

「精錬石（Refining Stone）」は、ステータスラインの厳選に使うものではなく、**製作の素材**です。製作の各段階（通常・専門・職人）で使い、フィールドや遠征、シューゴ フェスタ、ルドラで入手します。製作装備のルートは [[crafted-gear]] を参照してください。

根拠：[S03]

## 厳選の進め方

1. ラインは、継承で引き継げる唯一装備に対してのみ行う。
2. ストーリーの間は、付いたラインをそのまま使う。
3. 長く使う装備が揃ってから、主力スキルのレベルが上がるラインを狙う。
4. 引き直しの素材（魂の書、Sync Stone）は、エンド用にためておく。[[upgrading-gear-priority]]
