AION2 では、装備の強化と更新が戦力とコンテンツ解放の両方に関わります。素材（強化石とギーナ）は有限なので、「どの装備にどこまで使うか」の順番を知っておくと、後で後悔しにくくなります。結論は、**すぐ交換する装備には使いすぎず、長く使う装備に集中する**ことです。

根拠：[S01] [S02]

## 基本の考え方

- 強化は装備の能力値だけでなくアイテムレベル（IL）も上げます。ストーリーやコンテンツの入場条件のILが足りないときに、強化する意味があります。
- 序盤は入手した装備が頻繁に更新されます。「新しい装備を入手 → そのまま進めるか確認 → 不足したら強化 → 次が出たら交換」で十分です。
- 最大まで強化できることと、最大まで強化すべきことは別です。数レベル後に捨てる装備の強化石は、次の唯一装備に残したほうが得です。

根拠：[S01]

## 装備の種類ごとの目安

| 装備 | 方針 |
| --- | --- |
| ストーリー途中の希少 | 必要なときだけ強化。無理に上げない |
| すぐ交換する伝承 | +5前後を目安に必要分だけ |
| Lv45まで使いそうな伝承 | 装備ILが足りないときに追加で強化 |
| 長く使う唯一 | +10まで本格的に強化 |
| 唯一の+11以降 | 最終的に使う装備を優先。失敗で素材を失う |
| 魔石・霊石 | 高価なものは長く使う装備まで温存 |

根拠：[S01] [S05]

## Lv45以降の順番

1. **武器とガーダー**：ダメージへの影響が最も大きい。ガーダーも武器と同じ扱い。
2. **ベルトとアミュレット**：交換せずシーズンを通して育てる装備。+10まで失敗がなく、費用あたりのILが良い。[[belt-and-amulet]]
3. **ブレスレット2つ**：+10まで上げると、レイドまで使えます。
4. **IL が大きく遅れている部位**：武器だけ強くても、低ILの防具が残っているとコンテンツに入れません。弱い部位を交換したほうが安く済むことがあります。
5. **装身具（ネックレス・イヤリング・リング）**：リングはアクティブスキルのレベルが上がるため、早めに製作します。[[crafted-gear]]
6. **防具**：最後でかまいません。ただし +15 以降の突破では武器とガーダーを先にします。[[amp-breakthrough]]
7. **ルーン**：2個とも+1で止める。[[runes]]

根拠：[S01] [S02] [S03] [S04]

## 製作装備に強化を集める

ドロップ品は **+10まで** にとどめ、ギーナと素材は製作装備に回す方法が、クリエイターに勧められています。製作装備は上位の段階へ作り替えても、強化と突破と魂刻印が引き継がれるためです。[[crafted-gear]] [[transfer-inheritance]]

- 伝承は継承できません。乗り換えたら抽出して強化石を取り戻します。[[extraction]]
- 移行期の装備を+10より上に上げるのは割に合いません（+11〜+15は段階あたりのコストが重い）。+11〜+15は最終的な武器・ガーダーのために取っておきます。

根拠：[S02] [S05]

## ILの上げ方の流れ（目安）

| キャラクターIL | 取り組み |
| --- | --- |
| 〜1,000 | サイドクエスト、封印ダンジョン、駐屯地。ベルトとアミュレットを育てる |
| 1,400 | ヴァクロン空島などの遠征。征服で武器・防具・装身具を集める。アルカナを揃え始める |
| 1,600〜 | 超越の段階1・2でアルカナ5枠を埋める。カードはILを大きく伸ばす |
| 2,100〜 | 獰猛な角の巣、火の神殿の征服。超越の段階3・4でカードを入れ替える |
| 2,800〜 | ルドラ（レイド） |

- アルカナは単独で最も大きなIL源の一つです。[[arcana]]
- 征服の確定報酬や装備変更券で、足りない部位を補えます。[[gear-change-voucher]]
- 各段階の詳細は [[progression-path-700-to-2800]] を参照してください。

根拠：[S03] [S04]

## 装備を更新するときの判断

新しい装備を拾ったら、次の順に考えます。

1. 今の装備より上位か（等級とIL）を比べる。
2. 次の交換がいつになるかを考える。すぐ上位が取れるなら、現在の装備に素材を使わない。
3. 次のコンテンツ条件のILに、あと少しで届くなら強化する。
4. 唯一装備が揃い始めたら、均等に最大強化せず、重要な部位から伸ばす。

> **注意**：強化済みの装備を使っていると、未強化の新装備の数字が低く見えることがあります。比べるときは、等級、IL、基礎性能、強化後の伸びしろ、魔石スロットを見ます。高ILの唯一装備は、強化後に現在の装備を超えることがあります。

> 完璧な装備（最終装備）は、ローンチ直後には必要ありません。コンテンツの入場条件のILを満たし、手の届く範囲の戦闘力を確保すれば、PvEは進められます。根拠：[S03]
