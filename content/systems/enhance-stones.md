強化石（Enhance Stone）は、装備の [[enhancement]] や [[amp-breakthrough]] で毎回消費する素材です。ギーナと並んで育成の「燃料」で、段階が上がるほど必要な数が大きく増えます。入手先は多く、クライアントのデータ上では173種類の入手経路があります。

根拠：[S01] [S02]

## 主な入手先

| 入手先 | 内容 |
| --- | --- |
| デイリーダンジョン「ディーヴァ生体研究基地」 | Lv30から挑戦できる。スコアに応じて強化石が出て、高スコアほど多い。グローバル版では週14回（サーバー内で共有） |
| 遠征（探険・征服）の報酬キューブ | 装備やギーナと同時に出る。例：ウルググ峡谷の征服キューブは強化石2,000個が確定 |
| 不要な装備の抽出 | 使わない装備を分解すると戻る。強化済みなら注いだ分も戻る。[[extraction]] |
| アビス補給依頼 | 依頼の報酬として出ることがある |
| 物質変換 | 一部のアイテムを強化石へ変換できる。[[substance-morph]] |
| ほかの陣営の封印ダンジョン（亀裂経由） | 1か所約2,500個で、エネルギーを使わない入手先として評価されている |
| 昇天の試練・シーズンミッション | 週間の入手先 |

- デイリーダンジョンは強化石が目的なら最優先です。[[daily-dungeon]]
- 遠征の報酬受取にはオードエネルギーを使います。[[expeditions-and-odyle]]

根拠：[S01] [S03] [S05] [S06]

## 使い道

1. 装備の強化と突破に使う。必要数は装備のIL（アイテムレベル）と目標の段階で決まる。例：IL54の唯一装備を+0→+10にするには約19,440個。
2. 物質変換の材料にもなる（突破石を作るときなど）。
3. 継承は専用の継承石で行うため、強化石は使わない。

目標とする段階の費用は [[enhancement]] の表を参照してください。

根拠：[S01] [S03] [S04]

## 使い方のコツ

- 序盤は装備の更新が速いので、入手した装備をすべて最大まで上げる必要はありません。長く使う装備や、戦力不足の装備を優先します。
- 使い終わった装備は抽出して回収します。ギーナは戻りませんが、強化石は戻ります。
- 長く使う装備に集中させるために、不要な唯一装備を分解して強化石にするのは勧められていません。唯一装備は継承用の素材になるためです。[[transfer-inheritance]]

根拠：[S01] [S04]

## よくある質問

**Q. 強化石はいつから集めるべき？**
A. 強化はLv9から、デイリーダンジョンはLv30から使えます。Lv45までは足りない場面が少ないので、必要なときに強化します。

**Q. 強化石が余ったら？**
A. ためておき、Lv45以降の唯一装備や突破に回します。
