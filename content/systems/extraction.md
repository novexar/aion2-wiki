抽出（Extraction）は、使わなくなった装備を分解して素材に変える機能です。**強化に使った強化石が戻ってくる**ので、装備を乗り換えるときの無駄を減らせます。キャラクターLv10で解放されます。

根拠：[S01] [S04] [S05]

## 何が戻るか

| 抽出するもの | 戻るもの |
| --- | --- |
| 装備（未強化） | その装備の通常の分解素材（強化石など） |
| 強化済みの装備 | 通常の分解素材＋強化に使った強化石のすべて（+11〜+15も含む） |
| 装備の外形（見た目） | クローゼットに外形が登録される |
| アルカナのカード | 神秘的な結晶のゲージ（等級に応じてたまり、100%で結晶1個） |

- 戻らないもの：**ギーナ**（強化に使った分は返りません）と、失敗した試行で使った強化石です。
- 抽出には少額のギーナがかかります。（根拠：[S07]）

根拠：[S01] [S02] [S03] [S06]

## 使い方

1. キューブ（インベントリ）右下のフラスコのアイコンを押す。
2. 抽出したい装備を選ぶ。
3. 左下の歯車で「簡易選択」の条件（等級や装着・使用レベル）を決めたり、「自動抽出」をオンにしたりできる。

根拠：[S01]

## 抽出したほうがよいとき・しないほうがよいとき

| 状況 | 判断 |
| --- | --- |
| 希少・伝承の装備を乗り換えた | 抽出する。継承できないので、強化石を取り戻す |
| 強化済みの唯一装備を乗り換える | 先に継承で強化を引き継ぐ。継承できるのは唯一のみ |
| 初めて見る外形の装備 | 抽出して外形を登録する（クローゼットのポイントになる） |
| 使わない唯一装備（IL36〜102） | 物質変換で継承石やSync Stoneにできるので、取っておく選択肢もある |
| 他クラスの武器 | 外形はポイントに入らない |

- 外形の収集は、部位ごとの追加能力値になります。[[closet-and-skins]]
- 唯一装備を強化石に分解するのは勧められていません。[[substance-morph]] [[transfer-inheritance]]

根拠：[S01] [S02] [S06]

## よくある質問

**Q. 強化済みの装備を抽出すると強化石は全部戻る？**
A. 強化に使った分は戻ります。ギーナは戻りません。

**Q. 抽出したらその装備の見た目は？**
A. 外形が手に入り、見た目を変える機能に使えます。装備の能力値は変わりません。
