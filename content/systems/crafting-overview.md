製作（Crafting）は、素材から装備・消耗品・加工素材を作る生活スキルです。グローバル版では **製作で作る装備がシーズン1のPvE装備の中心**になります。製作は **キャラクターLv10** で解放され、町の製作台で行います。

根拠：[S01] [S02] [S04] [S05]

## 5つの専門技術

| 専門技術 | 主に作るもの | 武器を作れるクラス |
| --- | --- | --- |
| 鍛冶（Blacksmithing） | 剣・大剣・短剣・メイス、ガーダー、金属素材 | グラディエーター、テンプラー、アサシン、クレリック |
| 防具製作（Armorsmithing） | 防具7部位（胸・ズボン・ヘルム・ショルダー・グローブ・ブーツ・マント）、革素材 | なし（全クラス共通） |
| 細工（Handicrafting） | 弓・杖・ネックレス・イヤリング・リング・ブレスレット、木材・宝石加工 | レンジャー、チャンター |
| 錬金（Alchemy） | 魔導書・オーブ、ポーション、スクロール、魔石・霊石 | スピリットマスター、ソーサラー |
| 料理（Cooking） | 料理（バフ系の消耗品） | なし（全クラス共通） |

- 最初に上げるなら、**自分のクラスの武器を作れる専門技術** が分かりやすいです。防具製作と料理はどのクラスにも役立ちます。
- 装身具をまとめて作りたいなら細工、ポーションなど消耗品も作りたいなら錬金が候補です。
- 各専門技術の詳細は [[crafting-blacksmithing]] [[crafting-armorsmithing]] [[crafting-handicrafting]] [[crafting-alchemy]] [[crafting-cooking]] を参照してください。

根拠：[S01] [S02] [S03]

## 熟練度（Proficiency）

| 区分 | 熟練度 | 内容 |
| --- | --- | --- |
| 入門 | 1〜50 | 50で止まる。昇級試験に合格するまで上がらない |
| 専門 | 51〜100 | 昇級後に解放。現在の上限は100 |

熟練度を上げるのに必要な経験値の目安（1から数えた累計）です。

| 熟練度 | 区間の経験値 | 累計 |
| --- | --- | --- |
| 1〜10 | 294 | 294 |
| 10〜20 | 530 | 824 |
| 20〜30 | 1,320 | 2,144 |
| 30〜40 | 2,343 | 4,487 |
| 40〜50 | 4,322 | 8,809 |
| 51〜60 | 6,138 | 14,947 |
| 60〜70 | 9,337 | 24,284 |
| 70〜80 | 13,849 | 38,133 |
| 80〜90 | 21,132 | 59,265 |
| 90〜100 | 32,224 | 91,489 |

- 1回の製作で得られる経験値はサーバーが決めるため、表は回数ではなく区間ごとの必要量です。
- **成功でも失敗でも熟練度は上がります**。失敗のほうが少なめです。
- 同じ材料なら、時間短縮用の「×10」「×30」レシピより、**1個ずつ作るほうが多く上がります**。
- 採集物やよく落ちる材料から作れる加工素材が熟練度上げの主役です。精錬石が必要な装備は、手に入ったときに作ります。
- 熟練度が上がるたびに製作スキルポイントが入りますが、現時点ではポイントを使うスキルがありません。

根拠：[S01] [S03]

### 昇級試験（熟練度50）

熟練度が50になると昇級試験のクエストが自動で始まります。昇級用の道具（刻印）を作るための材料を用意します。

| 専門技術 | 昇級に使う品（刻印・英語名） | 材料 |
| --- | --- | --- |
| 鍛冶 | Novice Blacksmith's Hammer | Orichalcum Ingot ×6、Odyle ×3 |
| 防具製作 | Novice Armorsmith's Fabric | Orichalcum Ingot ×6、Odyle ×3 |
| 細工 | Novice Handicrafter's Magnifying Glass | Yggdrasil Wood ×4、Sapphire Decoration ×2、Odyle ×3 |
| 錬金 | Novice Alchemist's Scale | Magic Crystal ×6、Spiritstone Powder ×2、Odyle ×3 |
| 料理 | Novice Chef's Seasoning | Fresh Raw Meat ×10、Fresh Fruit ×6、Inina ×4 |

材料はあらかじめ取っておくと、50になってすぐ昇級できます。

根拠：[S01] [S02]

## 成功率とCOMBO

- 製作は、レシピを選べば必ず完成するわけではなく、成功と失敗の判定があります。**熟練度がレシピの要求を上回るほど成功しやすく**なります。
- 例：オリハルコンのインゴットは熟練度1で95.2%、48で最大99.15%。料理は熟練度1で72.88%、48で最大90.89%です。
- 失敗すると材料を失います。希少な素材を使う高額レシピは、**必要熟練度に着いた直後に大量に作らない**でください。トゥルー・ドラゴンロードの装備は、必要熟練度で67.5%、熟練度100で94%です。
- 製作中に攻撃を受けると失敗として中断されます。製作管理（どこでも作れる）は戦闘経験値が減ります。
- 成功時に **COMBO** が発動することがあり、結果が「光る〜」の上位品に置き換わります。2段階目以降の装備は、1つ下の段階の光る品から作るので、売る前に取っておきます。

根拠：[S01] [S02] [S03]

## 素材の集め方

- 採集（精気抽出）：鉱石・宝石・木材・薬草・オードなど。[[gathering]] [[essence-extraction]]
- 取引：採集物とモンスタードロップは取引できます。ただしマーケットで買うにはメンバーシップが必要です。
- 商人：刻印の副材料（触媒、溶剤など）は各製作の商人からのみ。1回400ギーナ程度です。
- 物質変換：オードを他の採集素材に変換できます。[[substance-morph]]
- 売る前に：素材のまま売る価値と、完成品の価値を比べてください。作っても利益が出るとは限りません。

根拠：[S01] [S02] [S03]

## 装備を作る

装備は上位の段階を作り替える（アップクラフト）形で育てます。ルートの全体像は [[crafted-gear]] を参照してください。

> **注意**：製作のミスは、サポートでも元に戻せません。製作は途中で止められないので、実行前にレシピ画面の成功率と材料を確認してください。

根拠：[S02]

> **要確認**：redfreshet は採集の解放をLv45と説明しています。ゲームデータに基づく資料（Aion 2 Maps、データベース、wikirealm）は採集もLv10で解放されるとしており、この記事はそちらに従っています。
