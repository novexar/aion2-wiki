AION2 の戦闘は、敵をロックオンして攻撃する「タブターゲット」と、自分で動いて避ける「アクション」の中間にあります。公式は「ヒット確認式で自動戦闘なし」と説明しています。この記事では、最初の数日で知っておきたい基本攻撃、キャンセル、回避、ボスの無力化（スタッガー）をまとめます。

根拠：[S03]

## 戦闘の特徴

| 項目 | 内容 |
| --- | --- |
| 戦闘方式 | 手動、ヒット確認式。自動戦闘はない |
| ターゲット | ロックオン。向きが多少ずれても当たる |
| 操作モード | AION 1（カーソル・クリック）と AION 2（照準）。いつでも切替可 |
| 後方攻撃 | 背後からの攻撃は追加ダメージ。ボスには背面の表示も出る |
| 回避 | 回避ロールにはタイミング次第で無敵時間がある |
| MP | MP ポーションはなく、基本攻撃か待機で回復 |
| ping | 遅延の影響を受けやすい。長いスキルを予兆の直前に始めない |

操作モードの違いは [[controls-and-keybinds]] を参照してください。後方ダメージの扱いはクラスによって異なり、前方攻撃を重視するクラス（グラディエーター）もあります。

根拠：[S03]

> **注意**：背後ダメージ増加の有無はクラスごとの調整で変わります。詳しい計算は [[how-damage-works]] を見てください。

## 基本攻撃とMP

左クリックの基本攻撃は MP を回復し、強攻撃（右クリック）とほとんどのスキルは MP を消費します。ボタンを押し続けると連打になります。

根拠：[S01] [S03]

## 基本攻撃キャンセル

基本攻撃を挟むと、直前のスキルの後隙（リカバリー）が打ち切られ、次のスキルが早く出ます。手動なら次の手順です。

1. スキルを押す。
2. すぐに左クリックを押す（0.05〜0.1秒以内が目安）。
3. この2つを1セットとして繰り返す。

スキルと左クリックを同時に連打すると、基本攻撃の約半分がスキルに飲まれて無駄になります。スキルごとに最短のキャンセル時間があり、短縮できる量には上限があります。ゲーム内のスキル予約（初期オン）は、別スキルの再生中に押した入力を受け付ける設定です。マクロでのやり方は [[macros]] にあります。

根拠：[S04]

## 無力化（スタッガー）

ボスの体力バーの下にスタッガーゲージがあり、特定のスキルだけがこれを削れます。ゲージを空にすると、ボスは約5秒間行動も防御も回避もできなくなります。バフ（ダメージ反射など）も剥がれます。

| 項目 | 内容 |
| --- | --- |
| 無力化の長さ | 多くのボスで5秒。ハードのクラオ洞窟最終ボスで8秒、ルドラで10秒 |
| スタッガー量 | スキルごとに固定。ツールチップ最終行に「スタッガーゲージダメージ」と表示 |
| 量が増える場合 | スキル／スティグマのレベルでは増えない。チャージで増えるスキルがある |
| パーティ人数 | 1人増えるごとにゲージの基準量が加算され、4人でも5人でも1人あたりの負担は同じ |
| 灰色のゲージ | 削れない。超越では大きなパターンの開始時に灰色になる |

無力化中は、そのクラス専用の「無力化中のみ使えるスキル」（暴走／スキャッターショットなど）が使え、大ダメージを出す時間になります。

根拠：[S02] [S03]

### スタッガーチェック

一部のボスは、全滅攻撃の詠唱中にゲージが開き、詠唱が終わる前に空にしないとパーティが全滅します。

| 戦闘 | チェックの内容 |
| --- | --- |
| クラオ洞窟 最終ボス | 体力50%で、約9秒の詠唱（アジア版での記録） |
| ドラウプニル 最終ボス | 体力約70%と30%で、跳ぶ波の後（資料により差あり） |
| デウス研究基地 アティエル | 体力約20%で、回る床の斜め切り（資料により差あり） |

スタッガーの大きいスキルは、ゲージが開くまで温存します。開いた瞬間にパーティ全員で一斉に撃つのがコツです。

根拠：[S02]

### 各クラスのスタッガー最大のスティグマ

どのクラスも、スタッガー50のスティグマを1つ持っています。時間切れになりそうなパーティでは、これをセットします。

| クラス | スティグマ |
| --- | --- |
| グラディエーター | 怒りの波動（Wrath Wave） |
| テンプラー | 天上の主の懲罰（Empyrean Lord's Punishment） |
| アサシン | サベージファング（Savage Fang） |
| レンジャー | アローストーム（Arrow Storm） |
| ソーサラー | ディバインバースト（Divine Burst） |
| スピリットマスター | 関節打ち：破壊攻撃（Jointstrike: Destructive Attack） |
| クレリック | パワーバースト（Power Burst） |
| チャンター | オブリタレイト（Obliterate） |

スキル名は英語版からの訳で、日本語版の表記と異なる場合があります。ゲーム内の表示が優先です。

根拠：[S02]

## 予兆（テレグラフ）と回避

ボスの大技は、地面の範囲表示などの予兆が出てから当たります。予兆が出たら、長いスキルを新しく始めず、回避ロールのタイミングを合わせます。長い攻撃の途中は回避できない（アニメーションロック）ため、予兆の直前にスキルを始めないのがコツです。遅延が大きい環境では、少し早めに回避します。

根拠：[S03]
