サーバー移動（Server Transfer）は、キャラクターを同じリージョン内の別サーバーへ移す機能です。NC は「2026年10月14日から、同じ陣営のサーバー間で移動可能になる」と告知しており、開始当初は無料です。友人と別サーバーで始めてしまった場合の合流手段になりますが、陣営の変更やリージョンの変更には使えません。

根拠：[S01] [S02] [S03] [S04]

## 公式に発表されている条件

| 項目 | 内容 |
| --- | --- |
| 開始日 | 2026年10月14日（予定） |
| 移動範囲 | 同じリージョン内の、同じ陣営のサーバー間のみ |
| 陣営の変更 | 不可（天族→魔族、魔族→天族はできない） |
| アーリーアクセスサーバーのキャラ | アーリーアクセスサーバー間でのみ移動可。正式サービス開始時に追加されたサーバーへは移動不可 |
| 費用 | 開始当初は無料。将来の費用は未発表 |
| リージョンをまたぐ移動 | 不可（キャラクターはリージョン間を移動できない） |
| レベル条件・回数制限 | 未発表 |

根拠：[S01] [S02] [S03]

> **注意**：「とりあえずアーリーアクセスサーバーで始めて、あとから正式サービス側のサーバーへ移る」という使い方はできません。正式サービス側で遊ぶつもりなら、移動を待たずにそちらでキャラクターを作ってください。

根拠：[S02] [S03] [S05]

## 移動で持っていけるもの・残るもの（クライアント解析）

aion2maps がグローバル版クライアントから読み取った移動ルールです。実際の画面表示が優先されます。

| 区分 | 内容 |
| --- | --- |
| 移動するもの | キャラクター本体、クァイリン（Quna）とマイレージ、メンバーシップの残り期間（選択制。移動先サーバーの期間に加算）、クローゼット（外形）とペット（移動先サーバーの分と統合） |
| 残るもの | サーバー倉庫の中身、メール、取引所の出品、キャラクター枠 |
| 申請前に必要なこと | 進行中の使命（Duty）を完了または放棄する。移動先サーバーに空きキャラクター枠を用意する |

根拠：[S01]

## 申請前のチェックリスト

1. 自分のキャラが天族か魔族か、移動先も同じ陣営か。
2. 今のサーバーがアーリーアクセスサーバーかどうか（アーリーアクセスサーバーのキャラは正式サービス側へ行けない）。
3. サーバー倉庫・メール・取引所の出品を空にしたか。
4. 進行中の使命を片付けたか。
5. 移動先にキャラクター枠の空きがあるか。

根拠：[S01] [S02]

## 韓国版での実施例（参考）

> **韓国版のみ**：韓国版では2026年7月22日〜28日と8月26日〜9月1日の2回、期間限定でサーバー移動を受け付けました。費用は基本料金 1,000 クァイリン＋キャラ1体につき 200 クァイリン、対象は Lv45 以上、申請は1アカウント1回、申請前に村へ移動・レギオン脱退・メールと出品の整理が必要で、移動後はキャラクター名の再設定が必要でした。サーバー倉庫のアイテムとギーナは持っていけませんでした。グローバル版が同じ条件になるかは未確定です。

根拠：[S02] [S03]
