> **要確認**：キー配置は、グローバル版クライアント（ローンチビルド）を解析した1つの攻略サイトの資料に基づきます。ゲーム内の「設定（O）→ キー設定」の表示が常に優先されます。

AION2 は、移動・ジャンプ・攻撃をキーボードとマウスで行うマニュアル戦闘の MMORPG です。自動戦闘はありません。最初に覚えるのは「WASD で移動、左クリックで基本攻撃、右クリックで強攻撃、Tab でターゲット切替」の4つです。この記事では初期キーと、2種類ある操作モードをまとめます。

根拠：[S01] [S02]

## 最初に覚えるキー

| 動作 | 初期キー |
| --- | --- |
| 移動 | W A S D（矢印キーも可） |
| 自動移動 | Num Lock |
| ジャンプ／滑空／無効化（Defiance） | Space |
| ダッシュ（走行中は回避） | 左 Shift |
| 飛行の開始／停止 | V |
| 上昇／下降 | Ctrl + R ／ Ctrl + F |
| 騎乗／下りる | C |
| 調べる・話す（インタラクト） | F |
| 休息（座る） | ,（カンマ） |
| 追跡中クエスト1〜9へ自動移動 | Alt + 1 〜 9 |
| カーソルを出す（AION 2 モード） | 左 Alt を押し続ける |
| 操作モード切替 | / |
| ズーム | マウスホイール、またはテンキーの + と − |

根拠：[S01]

## 戦闘のキー

| 動作 | 初期キー |
| --- | --- |
| 基本攻撃（スキルスロット1） | 左クリック、または R |
| 強攻撃（スキルスロット2） | 右クリック、または T |
| スキルスロット3〜6 | 1 2 3 4 |
| スキルスロット7〜8 | Q、E |
| スキルスロット9〜12 | 5 6 7 8 |
| 消耗品スロット1〜8 | F1 〜 F8 |
| 変身スキル1〜4 | Ctrl + 1 〜 4 |
| マクロ | 未設定 |
| ターゲット切替 | Tab |
| パーティリーダーのターゲットを選ぶ | Ctrl + Tab |
| パーティメンバー1〜4を選ぶ | Ctrl + F2 〜 F5 |
| パワーシャード オン／オフ | B |
| ポーション自動使用 オン／オフ | X |
| 戦闘分析（ゲーム内ダメージメーター） | Ctrl + X |
| ギアセット1／2／3へ切替 | Insert ／ Home ／ Page Up |
| ギア・スキルのプリセット | Alt + テンキー1〜3 ／ Alt + テンキー4〜6 |

基本攻撃やスキルのキーを押し続けると連打になります。基本攻撃は MP が回復し、強攻撃は MP を消費して地面に範囲が表示されます。

根拠：[S01]

> **注意**：マクロキーは初期状態で未設定です。使い方は [[macros]] を参照してください。

## ウィンドウのキー

| ウィンドウ | キー | ウィンドウ | キー |
| --- | --- | --- | --- |
| チャット | Enter | 強化 | N |
| キューブ（インベントリ） | I | ダエヴァニオン | U |
| ステータス情報 | P | アルカナ | Alt + V |
| スキル | K | 翼 | Alt + C |
| マップ | M | ペット | Alt + X |
| 透過マップ | Alt + M | クローゼット | Alt + O |
| ジャーナル | J | 称号 | Alt + T |
| レギオン | L | 製作 | Alt + G |
| 実績 | Y | 抽出 | Alt + F |
| 設定 | O | 物質変換 | Alt + H |
| ショップ | H | 補給要請 | Alt + J |
| サブスクリプション | G | UI を隠す | F12 |

Esc はキャスト中断、ウィンドウを閉じる、ターゲット解除、メニューを開く、を兼ねます。遠征・悪夢・超越・アビス・取引所・メールなど十数個のウィンドウには初期キーがなく、Esc メニューから開くか、自分で割り当てます。メニューの中身は [[ui-and-menus]] にまとめています。

根拠：[S01]

## 2つの操作モード

| 項目 | AION 2 モード（PC の初期値） | AION 1 モード |
| --- | --- | --- |
| カーソル | 隠れる。Alt を押す／ウィンドウを開くと表示 | 常に表示 |
| カメラ | マウスの動きに追従 | クリックしてドラッグ |
| 移動 | キーボード | キーボード、または地面クリック |
| ターゲット | 照準（レティクル）が近くの敵を選ぶ | 敵をクリック |
| マウスボタンへのスキル割り当て | 使える | 使えない |

AION 1 モードでは、マウスボタンに割り当てたスキルとマクロキーが動きません。基本攻撃と強攻撃は R と T で使えます。モードは「設定 → 戦闘 → 操作 → 操作モード」でも切り替えられます。

根拠：[S01]

どちらが良いかは好みです。前作経験者でも、速い戦闘は AION 2 モードのほうが反応が良いと感じて乗り換えた例があり、両方を試すことが勧められています。

根拠：[S02]

## チャットコマンド

チャット欄に先頭の「/」付きで入力します。1通は100文字まで、Ctrl + 左クリックでアイテムやマップピンを共有でき、1通に5個までです。

| コマンド | チャンネル | 条件 |
| --- | --- | --- |
| /s | 一般 | なし |
| /t | 陣営 | Lv30 |
| /w | 耳打ち | 相手が同じサーバーグループにいる |
| /h | 叫び | なし |
| /p | パーティ | パーティ所属 |
| /f | フォース | フォース所属 |
| /l | レギオン | レギオン所属 |
| /d | ダンジョン | ダンジョングループ所属 |
| /r | 直前の耳打ちに返信 | — |

フォース（Force）は、パーティを拡張して作る大きなグループです。

| コマンド | 内容 |
| --- | --- |
| /invite（/inv） | パーティに招待 |
| /pform ／ /fform | パーティ／フォースを作成 |
| /pquit ／ /fquit | 脱退 |
| /pkick ／ /fkick | 追放、または追放投票の開始 |
| /pleader ／ /fleader | リーダー委任 |
| /prally ／ /frally | 募集 |
| /fchange | パーティをフォースに変更 |
| /rest（/sit） | 座る（カンマキーと同じ） |

追放投票を始められるのは、パーティリーダー（フォースならリーダーか副リーダー）だけで、ボス戦中はできません。チャットの詳細は [[chat-and-social]] を参照してください。

根拠：[S01]

## 主なエモート

エモートは対象に向けて使えます。

| 例 | コマンド |
| --- | --- |
| 挨拶 | /greet、/wave |
| はい／いいえ | /yes、/no |
| 拍手 | /applaud |
| 笑う | /laugh |
| 翼を見せる | /wings |
| 武器を見せる | /weapon |
| 勝利ポーズ | /victory、/v |
| 踊る | /dance |

解放アイテムが必要なエモート（/deepbow、/kurukuru など）は、先にアイテムを使う必要があります。

根拠：[S01]

## レイドマーカー

| 動作 | キー |
| --- | --- |
| ターゲットにマーカー1〜9を付ける | テンキー 1〜9 |
| マーカー1〜9の敵を選ぶ | Ctrl + テンキー 1〜9 |
| ターゲットのマーカー／全マーカーを外す | テンキー . ／ Ctrl + テンキー . |

根拠：[S01]

## 設定で確認したい項目

| 設定 | 初期値 |
| --- | --- |
| スキル予約（別スキルの再生中に押した入力を予約） | オン |
| ライフポーション自動使用 | オン（HP 70%） |
| バフ自動使用 | 戦闘中または移動中 |
| 無効化（Defiance）専用キー | オフ（Space と共用） |
| パーティ招待 | 全員から受ける |

HUD の配置は6つのプリセットに保存でき、コードやファイルで共有できます。ダンジョンを出るときは、ミニマップ左上付近の退出ボタンで入った場所に戻れます。グラフィックや FPS の設定は [[recommended-settings]]、ゲームパッドは [[controller-and-steam-deck]] を見てください。

根拠：[S01]
