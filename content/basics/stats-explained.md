ステータス（Stats）は、キャラクター画面（既定キー P）に並ぶ「攻撃力」「命中」「クリティカル」「強打」などの数値です。装備・ディーヴァニオン・アルカナ・翼・称号などの合計がここに表示され、ダメージと生存力を決めます。初心者がまず知るべきなのは「似た名前でも役割が違う」ことと「上限がある項目は上限で止める」ことの2点です。

> **注意**：数値の重み付け（どの項目が何%の火力に相当するか）は、韓国・台湾版のエンドゲーム環境で測定されたものが大半です。グローバル版はディーヴァニオンや主神ステータスが弱められているため（[[global-vs-korea]] 参照）、順位は参考値として扱ってください。

## 2つの系統：主神ステータスと主要ステータス

ステータスには「主神ステータス（Deity / Pantheon stats）」と「主要ステータス（Primary attributes）」があります。

| 系統 | 項目 | 何に効くか |
| --- | --- | --- |
| 主神ステータス（10種） | 正義・自由・幻想・生命・時間（天族側の名前）／破壊・死・知恵・運命・空間（魔族側の名前） | 1ポイントにつき 0.1% の効果が2つ付く。どちらの陣営でも10種すべて使える |
| 主要ステータス | 威力（Might）、体力（Constitution）、敏捷（Dexterity）、知識（Intelligence）、正確（Precision）、意志（Willpower） | 1ポイントにつき 0.1% で、主に「〜増加」の乗算値を上げる |

グローバル版の主神ステータスは韓国版の半分（韓国版は 0.2%／ポイント）です。韓国の攻略で「破壊10で攻撃力+2%」と書かれていても、グローバル版では +1% と読み替えてください。

根拠：[S01] [S03] [S04]

### 主要ステータスが上げるもの

| 主要ステータス | 上がるもの |
| --- | --- |
| 威力 | 攻撃力増加（%） |
| 体力 | HP増加（%） |
| 敏捷 | 回避増加、ガード増加、クリティカル抵抗増加 |
| 知識 | 状態異常発動率 |
| 正確 | 命中増加、クリティカル増加（命中・クリティカルの「ポイント」に掛かる乗算） |
| 意志 | 状態異常抵抗 |

「正確」はクリティカル発動率そのものではなく、クリティカルのポイントを増やす乗算です。

根拠：[S01]

## 名前の読み方：「増加」が付くかどうか

- 「攻撃力増加（%）」のように **「増加」が付く項目は乗算**（基礎値にパーセントを掛ける）です。
- 「追加攻撃力」「追加命中」のように **「追加」が付く項目は固定値の加算**です。
- 計算は「固定値を全部足してから、パーセントを掛ける」順なので、固定値が多いほどパーセントの価値が上がります。
- 魔石・霊石に書かれた「増幅 100」は、キャラクター画面上の 1% に相当します。

根拠：[S01]

## 攻撃系ステータス一覧

| ステータス | ゲーム内の説明 | 補足 |
| --- | --- | --- |
| 攻撃力（Attack） | 高いほどダメージが増える | ダメージと回復の両方の土台。装備の攻撃力には武器ダメージ増幅が掛かる |
| 最大攻撃力（Max Attack） | 武器のダメージ幅の上限。「完璧」が参照する | 上限が上がると平均も上がる |
| 追加攻撃力（Attack Bonus） | ダメージに影響 | 武器ダメージ増幅の後に足され、攻撃力増加%は掛かる |
| 攻撃力増加（Attack Increase %） | 攻撃力を乗算で増やす | 威力・破壊から得られる |
| PvE攻撃力／ボス攻撃力／種族攻撃力／前方攻撃力／後方攻撃力／クリティカル攻撃力 | 条件を満たした場面でダメージ増加 | すべての乗算の後に足される固定値。優先度は低め |
| パワーシャードダメージ | パワーシャード使用時のダメージ増加 | 弾薬のような消耗品「パワーシャード」に関係 |

根拠：[S01]

## ダメージ倍率系（火力の中心）

| ステータス | ゲーム内の説明 | 補足 |
| --- | --- | --- |
| 強打（Smite／英語クライアントでは Double Chance） | 最終ダメージが大きく増える確率。相手の強打抵抗で下がる | PvE では 2倍、PvP では 1.5倍。PvE 最重要級の項目 |
| 武器ダメージ増幅（Weapon Damage Boost） | 武器ダメージを増幅。相手の武器ダメージ耐性で下がる | 装備由来の攻撃力すべてに掛かる独立した倍率 |
| クリティカルダメージ増幅（Critical Damage Boost） | クリティカル時のダメージを増幅 | 基礎の 1.5倍に加算される |
| 前方ダメージ増幅／後方ダメージ増幅 | 正面から／背後から当てたときのダメージ増加。後方はガードを無視 | クライアント上は2つの別ステータス |
| ダメージ増幅／PvE・ボス・種族ダメージ増幅 | それぞれ対応する耐性で相殺される | 同じ「山」に合算されるので、積むほど1ポイントの価値が下がる |
| 属性ダメージ増幅（火・水・風・地） | 対応する属性耐性で下がる | 属性付きスキルにだけ効く独立倍率 |
| 多段攻撃（Multi-Hit） | 最大4回の追加ヒット | すべての武器に隠れた基礎 20% がある |
| 完璧（Perfect） | 武器の最大攻撃力でヒットする確率 | 攻撃力が育つほど相対価値が下がる |
| 貫通（Penetration） | 相手の防御力を無視する（0未満にはならない） | PvE では防御力の 10% 分の価値。100貫通 ≒ 基礎ダメージ 10 |

根拠：[S01] [S04]

## 命中・速度系

| ステータス | 説明 | グローバル版の上限 |
| --- | --- | --- |
| クリティカル（Critical Hit） | クリティカル発生率。相手のクリティカル抵抗で下がる | **50%**（ツールチップ表示） |
| 命中（Accuracy） | ミス・ガード・パリィを防ぐ。相手の回避・ガードと差し引き | 上限あり（クリティカルと同じ仕組み） |
| ガード貫通（Block Penetration） | 相手のガード率を無視 | — |
| 戦闘速度（Combat Speed） | 攻撃速度と詠唱モーション速度を上げる | 回線や FPS の影響が大きい |
| 再使用時間減少（Cooldown Reduction） | スキルの再使用時間を短縮 | **60%** |
| 移動速度 | 移動の速さ | 上限値は出典で確認できず（要確認。ゲーム内の表示を優先） |
| 状態異常発動率 | 状態異常を付与できる確率 | スキル基礎確率 ×（1＋自分の発動率−相手の抵抗）、下限 5% |

### 命中とクリティカルの「上限」の仕組み

命中とクリティカルは、相手のステータスとの **差** で決まります。自分の値から相手の対応する値（ガード／クリティカル抵抗）を引いた差が約 1,200 で上限に達し、100 ポイントの差ごとに約 6〜7% 上がる計算です。上限を超えた分は何の効果もないので、積みすぎは無駄になります。

> **注意**：グローバル版のツールチップは「クリティカル最大 50%」「回避最大 30%」と表示します。韓国・台湾版は同じ文言のまま実測で 80% 近くまで上がった記録があり、グローバル版で本当に 50% で止まるかは検証途中です。安全側として、まずは 50% を目安にしてください。

根拠：[S02] [S03]

## 防御・回復系

| ステータス | 説明 | 補足 |
| --- | --- | --- |
| 防御力（Defense） | 受けるダメージを減らす | PvE では防御力の 10%、PvP では 1% が固定で引かれる |
| ダメージ耐性（Damage Tolerance） | 受けるダメージを弱める | 相手のダメージ増幅を相殺。PvE で意味があるのは通常・ボス・PvE の3種 |
| 回避（Evasion） | 攻撃を回避する | 上限 30%（ツールチップ） |
| ガード（Block） | パリィと盾ガードの確率 | 盾を持つのはクレリックとテンプラーだけ。他クラスはパリィ |
| 忍耐（Endurance） | ダメージを半減する確率 | ボスは忍耐貫通を持たないので、表示値がそのまま実効値 |
| 再生（Regeneration） | 受けたダメージの一部を HP として回復する確率 | 回復量は受けたダメージの 20% |
| 回復増幅／被回復増幅 | 自分が行う回復／自分が受ける回復を増幅 | 別々の倍率 |

被弾時の判定順は「回避 → ガード／パリィ → 忍耐 → 再生」です。

根拠：[S01]

## PvE で無駄になる耐性

ボスは「前方／後方ダメージ増幅」「武器ダメージ増幅」「クリティカル」「多段攻撃」を持っていません。したがって、それらに対する **抵抗・耐性を PvE 用に積む価値はありません**。PvP 用の項目と割り切ってください。

根拠：[S01]

## 初心者向けの優先順位

韓国版の定説と、グローバル版の解析を合わせると、PvE では次の順が目安になります。

1. 攻撃力（固定値）と戦闘速度
2. 強打と再使用時間減少
3. 完璧、クリティカル（上限まで）、命中（不足しない程度）
4. 防御系（HP・意志など）は序盤の PvE では後回し

ただし「配布装備とストーリー報酬をそのまま使えば命中は自然と足りる」というのが新規向けの一般的な助言です。序盤からステータスを細かくいじる必要はなく、画面が読めることをまず目指してください。

根拠：[S04] [S01]

## 参考：エンドゲーム測定による 1% あたりの価値

韓国・台湾版での測定値です。グローバル版の序盤キャラクターは総ステータスが少ないので、順位がそのまま当てはまるとは限りません。

| ステータス 1% | ダメージ増加の目安 |
| --- | --- |
| 強打 | 0.6〜0.65% |
| 前方／後方ダメージ増幅 | 0.57〜0.65%（位置取り維持率 75% 想定） |
| 武器ダメージ増幅 | 0.5〜0.55% |
| クリティカルダメージ増幅 | 0.4〜0.6% |
| ダメージ増幅 | 0.35〜0.53%（ボスの耐性が高いほど価値が上がる） |
| 多段攻撃 | 約 0.33% |
| 完璧 | 約 0.1% |
| 攻撃力 10 | 約 0.17〜0.23% |
