AION2 の情報は更新が速く、サイトによってグローバル版のデータとアジア版（韓国・台湾）のデータが混ざっています。調べ物をするときは、公式サイトで確認し、数値はデータベースで裏取りし、足りない部分を攻略サイトで補うのが基本です。この記事では、目的別に見るべきサイトをまとめます。

根拠：[S01]

## 公式の情報源

グローバル版の事実は、まず NC 自身のチャンネルで確認します。

| 情報源 | 用途 |
| --- | --- |
| NC 公式サイト（aion2.plaync.com/en-us） | グローバル版の告知、FAQ |
| Steam のストアページとニュース（アプリID 3393110） | 対応環境、日程、ファウンダーズパック、メンバーシップの特典、テスト告知 |
| 公式 Discord（discord.gg/aion2official） | NC が公式サイトと Steam からリンクする、グローバル版のコミュニティ |
| warforatreia.com と twitch.tv/aion2official | NC の War for Atreia クリエイターイベントと配信 |
| NC Japan の YouTube（@AION2_JP） | グローバル版向けの日本語の初心者・強化チュートリアル、ローンチ時の遠征紹介 |

NC Japan の公式サイトは https://aion2.ncsoft.jp/ です。日本語のゲーム内の表示とお知らせは、これらが最優先です。

根拠：[S01]

## 確率公示

probability.plaync.com/aion2 は、アジア版の確率を公開する NC の公式ページです。強化、突破、継承、魂刻印、魔石、アルカナ、ペットのジーナス、製作、隠しキューブ、オードエネルギーキューブなど37分類の確率、天井、失敗時のペナルティ、費用、素材が載っています。グローバル版に独自の公示はありません。グローバル版の起動時クライアントは強化と製作の確率がアジア版と同じなので、この2つについては公示の数字が使えます。攻略サイトと食い違う場合は公示が優先されます。

根拠：[S01]

## データベースとプランナー

| サイト | 内容 |
| --- | --- |
| AION 2 グローバル版データベース（aion2.gaming.tools/ja） | 日本語で使える。アイテム、製作、NPC、クエスト、スキル、ダンジョン、ペット、マップなどの情報。ビルド（/ja/builds）とアイテム（/ja/items）のページがある |
| aion2hub.com | グローバルのテストクライアントのデータを地域ラベル付きで載せるアイテムDB。ステータス計算機などのツールも多い |
| questlog.gg（Aion 2 のページ） | グローバルのテストクライアントのデータ。スキル、装備、アルカナ、翼、ペット。ディーヴァニオンのプランナー、スキルプランナー、製作計算機 |
| aion2.app（旧 aion2t.com） | スキル、アイテム、ダンジョン。クライアントの日付付き |

aion2hub のツールには、時空の亀裂タイマー、ビルドプランナー、ステータス計算機、製作計算機、DPSメーター、フィールドボスのタイマー、シーズンカレンダー、アビスランキングなどが並びます。

データベースには、グローバルのテストクライアント、アジア版、またはその両方のデータが入っています。ページがどちらを示しているか確認してから使ってください。

根拠：[S01] [S02] [S03]

## 注意

- AION 1（前作）の攻略が検索に混ざります。たとえば「AION2 レギオン ルール」と検索しても、前作の記事が出ることがあります。
- 数値（必要アイテムレベル、費用、確率など）は、ゲーム内の表示が最終判断です。
- 規約と信頼ステータスは [[rules-and-policies]]、用語は [[glossary]] を参照してください。
