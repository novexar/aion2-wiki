AION2 のキャラクターは **天族（Elyos）** か **魔族（Asmodian）** のどちらかに所属します。両者に戦闘性能の差はなく、使えるクラスも同じ8種です。違うのは「ストーリー」「冒険する地域」「所属するサーバー」「アビスなどでの敵味方」で、後から種族を変える手段は確認されていません。友人と遊ぶなら、同じ種族・同じサーバーを事前に合わせることが最優先です。

根拠：[S01] [S02] [S03]

## 比較表

| 比較項目 | 天族 | 魔族 |
| --- | --- | --- |
| 戦闘性能 | 大きな差なし（スキルは同等になるよう設計） | 同左 |
| 選べるクラス | 全8クラス | 全8クラス |
| 序盤の地域 | ポエタ → ベルテロン | イスハルゲン → アルトガルド |
| 物語の軸 | 混沌の時代を終わらせるための冒険（「約束の地」を目指す） | 崩壊した世界で生き残った者たちの、生存と復讐の物語 |
| 所属サーバー | 天族サーバー | 魔族サーバー |
| 敵対陣営 | 魔族 | 天族 |
| 後からの種族変更 | 現在確認できず | 現在確認できず |

根拠：[S01] [S02] [S03]

## 性能差はない

「天族だから火力が高い」「魔族だから PvP で有利」といった性能差を基準に選ぶゲームではありません。前作 AION では種族によって外見やスキルに違いがありましたが、AION2 ではその差を小さくする方向に変更されました。実際の強さを左右するのは種族ではなく、クラス・装備・育成・スキル構成です。クラス選びは [[classes-overview]] を参照してください。

根拠：[S01] [S03]

> **要確認**：MeinMMO は「天族は光と速度、魔族は影と力に寄ったスキル演出」「魔族は青白い肌や爪などの外見的特徴」があると書いています。日本語資料は「外見差は前作より大幅に小さく、キャラクター作成で種族による大きな制限はない」としており、演出面の違いはあっても性能差はない、という点で各資料は一致しています。

根拠：[S01] [S04]

## ストーリーと地域は大きく違う

同じ出来事を別視点から見るだけではなく、それぞれ異なる地域・人物・出来事を通して物語が進みます。天族はポエタからベルテロンへ、魔族はイスハルゲンからアルトガルドへ進み、普段の冒険でもう一方の種族に会うことはありません。ストーリーを重視する人にとって種族選びはかなり重要で、片方を遊んだ後にもう一方の物語を見る価値もあります。物語の背景は [[story-and-lore]] にまとめています。

根拠：[S01] [S02] [S03]

## サーバーは種族ごとに分かれている

- 1つのサーバーには天族か魔族のどちらか一方しかいません。
- 天族サーバーと魔族サーバーが1対1でペアになり、時空の亀裂やアビスではペア先のサーバーのプレイヤーと敵として戦います。ペアは勢力バランスに応じて定期的に変わります。
- キャラクター作成時は「リージョン → 陣営 → サーバー」の順に選びます。サーバーの一覧と選び方は [[regions-and-servers]] を参照してください。

根拠：[S01] [S03] [S05]

## 種族をまたいでできること・できないこと

| できること | できないこと |
| --- | --- |
| 遠征・超越などのダンジョンは、同じリージョンならサーバーや種族が違ってもパーティで一緒に行ける（部屋の設定で「同陣営のみ」にもできる） | 同じ通常フィールドで一緒にストーリーを進める |
| ダンジョン内でのみ、相手陣営をパーティに招待できる | レギオン（ギルド）に相手陣営を入れる（同サーバー・同種族のみ） |
| Lv45 で解放される「時空の亀裂」から、相手陣営のマップへ一定時間移動できる | フレンド登録（同じ陣営のみ） |

ダンジョンパーティの外では、相手陣営のチャットは読めない言語として表示されます。

根拠：[S02] [S03] [S05]

## どちらを選ぶべきか

1. **友人と遊ぶなら同じ種族**。種族が違うとサーバーも違い、フィールドやレギオンで一緒に遊べません。サーバー移動（[[server-transfer]]）でも種族は変えられません。
2. **ソロならストーリー・世界観・フィールドの雰囲気の好み** で選んで構いません。性能目的で片方を選ぶメリットはありません。
3. **PvP 目的でも性能だけで決める必要はありません**。クラス・装備・操作のほうが影響します。
4. 両方の種族を遊びたいときは、もう片方の種族のサーバーに別キャラクターを作ります。

根拠：[S01] [S02] [S03]

> **要確認**：gamerch は「韓国の先行サーバーでもグローバル版でも魔族の人口が多い傾向がある」としていますが、公式の人口データはありません。人口の多さが一方的な有利につながるわけでもない、と同記事は注記しています。

根拠：[S02]

## 後から変更できる？

2026年10月5日の正式サービス開始時点で、既存キャラクターの種族を切り替える機能は確認できません。10月14日開始のサーバー移動も同じ種族のサーバー間が対象です。将来追加される可能性はありますが、「変更できる前提」で選ばないほうが安全です。

根拠：[S01] [S02] [S03]
