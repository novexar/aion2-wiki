AION2 には、NC 自身が実装した「スキルマクロ」があります。フルオートの戦闘ではなく、マクロキーを押している間だけ、登録したスキルを順番に試す機能です。基本攻撃のキャンセルを簡単にするために作られたと説明されています。ほとんどのプレイヤーが、この機能を使ってスキル回しをしています。

根拠：[S01] [S02]

## 仕組み

| 項目 | 内容 |
| --- | --- |
| 動作 | キーを押している間、リスト上のホットキーを遅延を挟みながら順に試す |
| 登録するもの | スキルではなくクイックスロット（ホットキー）。スティグマのスロットも登録可能 |
| ステップ数 | 最大20ステップ |
| 遅延 | ステップごとに10〜9,900ms。多くのプレイヤーは10ms |
| 数 | マクロキーは1つ。マクロはスキルプリセットごとに1つ保存される |
| 順番 | 固定のスキル回しではない。条件を満たしたスキルを試す優先順位リスト |
| 同じキーに重ねるスキル | 最大4つ。一番下のスキルが使用可能なら優先され、上のスキルが隙間を埋める |

遅延を短くしても、スキルのクールタイムや詠唱時間は短くなりません。

根拠：[S01] [S02]

## 設定の手順

1. 「設定 → キー設定 → 一般 → ゲームプレイ → マクロ」でマクロキーを割り当てる。初期状態は未設定（キーボード・ゲームパッドとも）。マウスボタンも使えるが、AION 1 の操作モードではマウスボタンのマクロキーは動かない。
2. スキル画面（K）のクイックスロットに、連打するスキルを重ねて登録する。主力スキルを一番下に置く。
3. スキル画面の「マクロ」（右上）を開く。
4. 「マクロ追加」でステップを足し、ホットキーを選ぶ。新しいステップは最初「基本攻撃」になっているので、変更する。
5. 各ステップの遅延を設定する。まず10msから始める。PCが重いなら少し増やす。トレーニング用の案山子で確認する。
6. 「設定 → 戦闘 → 操作 → スキル予約」を確認する。初期値はオンで、オンのままにする。オフだと、別のスキルの再生中にマクロが入力したステップが失われることがある。

設定後は、左クリックとマクロキーを同時に押し続けます。基本攻撃がスキルの合間に挟まり、キャンセルが成功するたびにキャラクターの黒いシルエットが出ます。

根拠：[S01] [S02]

## マクロに入れるもの・入れないもの

| 場所 | 内容 | 理由 |
| --- | --- | --- |
| マクロの中 | 連打する1〜2個のホットキー | ステップを増やすと命中回数が減る |
| 一緒に押し続ける | 基本攻撃（左クリック） | マクロのステップにすると1周に1回しか出ない。押し続ければスキルの後ごとにキャンセルされる |
| 手動 | バフ、スティグマのバフ、移動、バースト | バフをマクロに入れると雑魚戦でも発動する。手動の入力はマクロより優先される |
| 単独で押し続ける | チャージスキル（ヘルファイア、パニッシュメント等） | マクロは最初の段階で撃つ。押し続けるとフルチャージになる |

マクロキーを離す必要はありません。マクロを押しながらスキルを押すと、そのスキルはすぐに出ます。同じクールタイムの主力スキルを同じキーに重ねると、互いに邪魔をします。1つのステップを2回登録すると、2倍の頻度で出ます。

根拠：[S01] [S02]

## うまく動かないとき

| 症状 | 原因 | 対処 |
| --- | --- | --- |
| マクロキーが反応しない | AION 1 モードでマウスボタンを割り当てている | キーボードのキーにするか、/ キーで操作モードを切り替える |
| プリセットを変えたらマクロが止まった | プリセットごとにマクロがあり、変更で実行中のマクロが止まる | 使う全プリセットで設定し、もう一度マクロキーを押す |
| 雑魚戦でバフが発動する | バフがマクロに入っている | マクロから外して手動で押す |
| ダメージが低い | ステップが多い、バフが入っている、遅延が合わない | 1〜2ステップにする。遅延を数ms上げる（15〜20msが合う人もいる） |
| チャージスキルが弱い | マクロが最初の段階で撃っている | マクロから外し、単独で押し続ける |
| 基本攻撃ばかりで回転が悪い | 新規ステップの初期値が基本攻撃のまま | そのステップを変更・削除する |
| 基本攻撃が止まる | Alt や Alt の組み合わせを押している | スキルに Alt の組み合わせを割り当てない |

根拠：[S01] [S02]

## 手動の基本攻撃キャンセル

マクロを使わない場合は、スキルを押してすぐに左クリックを押します。0.05〜0.1秒以内が目安で、この2つを1セットとして扱います。両方を連打すると基本攻撃の約半分が無駄になります。詳しくは [[combat-basics]] を参照してください。

根拠：[S01]

## 規約上の扱い

| 項目 | 内容 |
| --- | --- |
| ゲーム内マクロ | NC 自身の機能。グローバルの運営ポリシーにも行動規範にも記載がない |
| 外部のマクロソフト | 不正プログラム・機器の禁止に含まれるおそれ。BANのリスクがあるため、使わない |

アジア版の資料の多くはマウスソフトのマクロを併用していますが、このwikiでは扱いません。ゲーム内マクロ（NC の機能）と、外部ツールは別物です。規約の詳細は [[rules-and-policies]]、操作全般は [[controls-and-keybinds]] を参照してください。

根拠：[S02] [S03]
