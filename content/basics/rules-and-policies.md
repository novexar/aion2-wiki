グローバル版には独自のゲーム運営ポリシー（Operation Policy）と行動規範（Code of Conduct）があり、2026年9月17日から適用されています。違反の処罰は重く、外部プログラムの使用は初回から統合アカウント停止です。この記事は NC の規約を言い換えたもので、細かい条文は公式サイトで確認してください。

根拠：[S01]

## 主な処罰

| 違反 | 処罰 |
| --- | --- |
| 外部プログラム・機器、ゴールド稼ぎ、ボット、不正プログラムの作成・配布 | 初回から統合アカウント停止（NC の全ゲーム） |
| 有償の代行（Carry）の実施・仲介・常習的な購入。例：遠征、超越、聖域、悪夢 | 7日、30日、永久の順。組織的な運営は即永久も。購入者の別基準はなし |
| リアルマネー取引（有償ブースティング、他サーバーのプレイヤーとのアイテム取引を含む） | 30日、90日。未遂は3日、7日、30日。アカウント売買は7日、30日、90日 |
| 事前に合意したレイドの戦利品分配を破る | 7日から永久 |
| PvPの勝敗操作 | 7日から永久 |
| 取引所の登録・決済・キャンセルの悪用 | 統合アカウント停止 |
| アカウントの共有・盗難（所有者の過失） | 双方の処罰対象 |

NC 以外からギーナや Quna を買うことは利用規約違反です。ゲームにアクセスできなくなるおそれがあると警告されており、NC は処分内容を公表することがあります。

根拠：[S01] [S02]

## RMT（リアルマネー取引）の警告

NC は2026年10月4日（グローバル版開始の前日）に、公式お知らせ「Warning About Purchasing Illicit Currency」を出しました。NC 以外の第三者からギーナまたは Quna を買うことは利用規約に厳しく反し、ゲームへのアクセス停止までの措置が取られると明記しています。NC はこれを「最初で最後の警告」とし、処分内容を公開する権利を留保しています。検知方法や具体的な処分内容は、お知らせには書かれていません。

通貨を得る正規の方法は、ゲームのプレイと NC の公式ストアだけです。グローバル版ではプレイヤー同士の直接取引が、ボット対策として無効化されており、取引は取引所を通します。取引の仕組みは [[trading-rules]] を参照してください。

根拠：[S01] [S02] [S03]

## 信頼ステータス（Trust Status）

NC はアカウントごとに信頼ステータスを付けています。ステータスがないアカウントは、取引所や交換所などの機能を制限されることがあります。

| 項目 | 内容 |
| --- | --- |
| 取り消しの理由の例 | 不審な活動やソフト、リアルマネー取引、ボット、サポート外の地域からのプレイ、VPN の使用 |
| 見直し | NC が定期的に見直す。理由なく失った場合は再評価を申請できる |

根拠：[S01]

## マクロとダメージメーター

| 項目 | 内容 |
| --- | --- |
| ゲーム内マクロ | NC 自身の機能。運営ポリシーにも行動規範にも記載がない |
| 行動規範の「マクロやボット」 | 「ユーザーの操作なしに」動く外部プログラムを指す |
| マウス・キーボードのマクロソフト | 名指しはされないが、「機器・装備」を含む不正プログラム禁止の対象。アジア版では NC が使用を推奨していない |
| DPSメーター | パケット解析式のメーターについて、NC はどの地域でも見解を出していない。アンチチートは NCGUARD |

ゲーム内マクロの使い方は [[macros]] を参照してください。

根拠：[S01]

## サポートと期限

| 内容 | 扱い |
| --- | --- |
| 誤って削除したキャラクター | アカウントにつき1回復元 |
| 誤って NPC に売却・削除・抽出・変換したアイテム | アカウントにつき年1回復元 |
| 復元しないもの | 製作の失敗、強化失敗による損失、取引所・補給依頼の間違い、ペットの親密度の振り直し、解散したレギオン、翼とアルカナの抽出 |
| 期限 | 復元の依頼、アカウント盗難の報告、異議申し立ては15日以内 |

ゲーム内での復旧は [[storage-and-cube]] を参照してください。

根拠：[S01]

## 非アクティブのアカウントと名前

| 対象 | 扱い |
| --- | --- |
| キャラクターデータ | 6か月ログインがなく、有料サービスも終了した場合、告知のうえ削除されることがある |
| キャラクター名 | 課金履歴のないアカウントで30日ログインがないと、リセットされることがある |
| レギオン名 | メンバーが誰も30日ログインしないと、リセットされることがある |
| 軍団長 | 30日間不在、または90日以上の停止で、メンバーが権限の移譲を申請できる |

レギオンの詳細は [[legion]] を参照してください。プレイヤーの報告は、対象を選んで「報告」から行えます。累積した報告の結果は、チャット禁止から停止までさまざまです。

根拠：[S01]

> **注意**：処罰の日数や期限は NC が変更する場合があります。最新の規約は NC 公式サイトを確認してください。
