AION2 のグローバル版には、クーポンコードとゲーム内メールで受け取れる無料報酬があります。受け取りには期限があるので、早めに済ませましょう。コードの入力はゲーム内の設定画面から行い、報酬は入力時に操作しているキャラクターのキューブに入ります。

根拠：[S01] [S02]

## クーポン「TAKEFLIGHTAION2」

| 項目 | 内容 |
| --- | --- |
| コード | TAKEFLIGHTAION2 |
| 報酬 | オードエネルギー×4、復活の精霊石×5、戦闘強化スクロール×10（すべて帰属） |
| 期限 | 2026年10月13日 23:00（米太平洋時間）。日本時間では10月14日 15:00 |
| 回数 | アカウントで1回。全サーバーで使えるが、キャラごとに繰り返し受け取ることはできない |
| 由来 | Steam の世界売上ランキング1位を記念した公式のコード |

入力手順は次のとおりです。

1. ゲーム内の「設定」を開く。
2. 「その他 → アカウント → クーポン入力」を選ぶ。
3. コードを入力して「確認」を押す。

報酬は入力時のキャラクターに入るため、メインにしたいキャラにログインしてから入力してください。サブキャラで先に入力すると、メインではもう受け取れません。使えないときは、期限、入力ミス（コードは大文字）、すでに使っていないか、の順に確認します。

## ローンチ報酬（メール）

事前登録と Steam ウィッシュリストの報酬は、12月1日のメンテナンスまでにログインしたアカウントへメールで届きます。受け取りはメールを開いて行います。

| 箱 | 中身 |
| --- | --- |
| 事前登録のペット箱 | ペット「Pagati」と、好きなペット1匹（Papis、Silver Blade Rotan、Konutin Worker、Black Smoke Murute から選択） |
| ウィッシュリスト箱 | 復活の霊石×10、ライフポーション×100、治療ポーション×50、帰還・勇気・速度・祝福のスクロール各×50（すべて帰属） |

期限は、ログインが12月1日 23:30（米太平洋時間）まで、メールの失効が12月8日 23:30 とされていますが、資料にも「他の資料と食い違いあり」と注記があります。ゲーム内のメールの期限表示を確認してください。

## Twitch Drops

対象の配信を見ると報酬がもらえます。グローバルサーバーのプレイヤーが対象です。報酬は Twitch を連携したアカウントに紐づきます。

| プレイ方法 | 連携するアカウント |
| --- | --- |
| Steam で遊ぶ | Steam アカウント |
| PURPLE で遊ぶ | NC アカウント |

連携は NC 公式サイトの「マイページ → ログイン管理」で確認できます。ドロップを取り損ねたからといって、公式サイトでアカウントを再連携しないでください。既存の連携が外れ、キャラクターに入れなくなるおそれがあると NC が警告しています。

| 期間 | 例 |
| --- | --- |
| 9月30日〜10月4日 | 15分でサイバーグラス、30分でカスタマイズ券、1時間で魂の書（Soul Codex）×3、8時間でホワイトヘッドセット |
| 10月5日〜16日 | 1時間でオードエネルギー×4、2時間でスキン箱×10、4時間でヘッドボウ（スキン）、10時間で「Adorable Young Elim」 |

ドロップの受け取り期限は10月30日 23:59（PDT）です。

根拠：[S01]

> **注意**：報酬の中身と期限は更新されるため、最新はゲーム内と公式告知で確認してください。キャラ・サーバー・アカウントのどれに紐づくかは [[whats-bound]] にまとめています。
