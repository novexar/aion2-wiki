レギオン（Legion）は、AION2 のギルドにあたるプレイヤー組織です。入らなくても報酬に差はなく、加入は自由ですが、パーティを組む仲間を集めやすくなり、アジト（拠点）や共有倉庫も使えます。レギオンはサーバーごと、種族ごとに分かれていて、天族と魔族が同じレギオンに入ることはできません。

根拠：[S02] [S03]

## 基本情報

| 項目 | 内容 |
| --- | --- |
| 最大人数 | 128人。レギオンレベルを上げても枠は増えない |
| 解放条件 | メインクエスト（天族「Renewed Resolve」、魔族「Buried Atrocities」）のクリア。受注はLv10、目安はLv16前後 |
| 創設費用 | 100,000ギーナ |
| 加入費用 | 無料 |
| 名前 | 1〜12文字。空白・特殊文字は不可で、後から変更できない |
| 紹介文 | 48文字まで |
| 加入設定 | 即時加入／承認加入／パスワード加入 |
| 脱退後 | 24時間は別のレギオンに加入・創設できない |
| レギオンレベル | 20段階。各段階でメンバーに常時バフ |

根拠：[S01] [S02] [S03]

> **注意**：解放のクエスト名は英語名で、日本語版の表記とは異なる場合があります。資料間でLv10とLv16の表記差がありますが、「クエストの受注がLv10、クリアが目安Lv16前後」と読み取れます。ゲーム内の表示が優先されます。

## 加入する手順

1. メインクエストを進めてレギオンを解放する。
2. レギオンメニュー（初期キーは L）を開く。
3. おすすめ一覧（最大100件）または名前検索で探す。名前検索は、入力した文字で始まるレギオンが対象。
4. 紹介文と活動時間帯を確認し、加入申請を送る（承認制の場合は待つ）。招待を受けて入る方法もある。
5. 申請は一覧で確認・取り消しができる。

人数より活動しているかを重視するのが勧められています。活動時間帯、PvE中心かPvP中心か、ボイスチャットの有無を確認しましょう。ソロ中心なら急いで探す必要はなく、開発側もレギオン向けコンテンツは現時点で最小限にしている、と説明しています。

根拠：[S02] [S03]

## 階級

| 階級 | 人数 | できること |
| --- | --- | --- |
| 軍団長（Legion Master） | 1人 | すべての権限。階級の任命、軍団長の委任 |
| エリート将校（Elite Officer） | 4人 | 紋章の変更、加入設定、紹介文・お知らせの修正、追放など |
| 軍団兵（Member） | 残り全員 | アジトの飾り付け、倉庫への預入・引出 |

階級ごとの権限は編集できます。レギオンの記録メニューには、創設、加入・脱退、権限変更、アジトのレンタル・期限切れが30日分（最大300件）残ります。階級名は仮訳です。

根拠：[S01] [S02]

## レギオンレベルのバフ

レベルを上げる目的は戦力ではなく経験値ボーナスです。必要な累計経験値は、レベル1の1,000からレベル20の合計767,500まで増えます。ゲーム内では貢献度（Contribution）と表示され、メンバーには別に名声（Reputation）も入ります。

| レベル | 経験値獲得 | HP | MP | 回避・命中・攻撃・防御 |
| --- | --- | --- | --- | --- |
| 1 | +1% | — | — | — |
| 3 | +1% | +8 | +8 | 回避+1（資料の表記による） |
| 10 | +3% | +36 | +36 | 各+2 |
| 15 | +3% | +56 | +56 | 回避・命中+4、攻撃・防御+3 |
| 20 | +3% | +80 | +70 | 回避・命中+5、攻撃・防御+4 |

上限は経験値+3%と小さな固定値のみです。紋章10種類はレベル1から全部使えます。

根拠：[S01]

## アジト（レギオンホール）

アジトは、軍団長が1,000,000ギーナを支払って30日間レンタルするレギオンの拠点で、期間中は全員が使えます。借りる権限を持つ階級なら操作できます。期限が切れると、中にいる全員が外へ出されます。

| 項目 | 内容 |
| --- | --- |
| 場所 | 天族はベルテロン、魔族はアルトガルド。ほかの地域にもある |
| 入り方 | 飛行艇、「全体メニュー → レギオン → アジト」、またはアジト帰還スクロール（雑貨商店で販売） |
| 設備 | 製作商人と作業台5種（鍛冶・防具・細工・錬金・料理）、倉庫管理人、物質変換商人、案山子（ダメージ計測用） |
| 他機能 | アジト内で決闘ができる。アジトからダンジョンへ入ると、出たときにアジトへ戻る |
| 延長 | 期限の最後の3日間だけ可能（推測を含む） |
| 地域間移動 | 内部のポータルで移動。別地域のアジトへ行くには Lv45、アイテムレベル3,300以上、戦闘力270,000以上が必要 |

1回のレンタルは、延長も含めて全地域のアジトに適用されます。入るのは、そのとき自分がいる地域のアジトです。

根拠：[S01] [S02] [S03]

## レギオン倉庫

レギオン倉庫は、レギオン倉庫管理人が運営する共有倉庫です。預入は無料です。

| 項目 | 内容 |
| --- | --- |
| 初期枠 | 20 |
| 拡張 | 31回、1回につき10枠。1,000ギーナから最後の8,400,000ギーナまで。合計約31,700,000ギーナ |
| 最大 | 330枠 |
| 権限 | 階級ごとに預入・引出・両方を設定。履歴に誰が取ったか残る |
| 入れられる物 | アイテムのツールチップで可否が分かる |

自分専用の倉庫は [[storage-and-cube]] を参照してください。

根拠：[S01]

## その他の注意

- パーティ（最大5人）やフォース（最大20人）とは別の仕組みで、ダンジョンでは他サーバー・他種族とも部屋を作って遊べます（[[party-and-matchmaking]]）。
- レギオン同士のPvPや、レギオン専用の製作を追加する予定はないとされています。
- 活動していないレギオンや軍団長不在の扱いは NC のグローバル規約に従います（[[rules-and-policies]]）。
- チャットは /l でレギオン専用チャンネルに入れます（[[controls-and-keybinds]]）。
