AION2 は設定項目が多く、最初に開くとどこを触ればよいか迷います。重いと感じたときは、すべての画質を最低まで下げるのではなく、アップスケーラー（DLSS / FSR）から順に調整するのが近道です。この記事では、グラフィックの優先順位と、チャット・HUD・操作の見やすさ設定をまとめます。必要スペックは [[platforms-and-requirements]] を参照してください。

根拠：[S01] [S02]

## 設定画面の構成

設定画面（初期キー O）は、グラフィック、戦闘、キー設定など8つのタブに分かれています。画質はグラフィックのタブにあり、中は「最適化」と「カメラ/演出」に分かれます。

| 場所 | 内容 |
| --- | --- |
| 最適化の最初の5項目 | ディスプレイモード、解像度、Vertical Sync、リフレッシュレート、解像度スケール |
| グラフィック品質 – 基本 | 簡易設定（6段階）とテクスチャ、エフェクト、大規模戦闘、モデル、視野距離、植生、影、陰影、グローバルイルミネーション、反射、雲、ポストプロセス、アンチエイリアシング（各5段階） |
| グラフィック品質 – 高級 | アップスケーラー、フレーム生成、プレイヤーパーティクル表示、ボリュームライト、ボリュメトリックフォグなど |

ディスプレイモードがボーダーレスウィンドウのときは、解像度・Vertical Sync・リフレッシュレートが灰色で触れません。

根拠：[S02]

## 最初の推奨設定

| 項目 | 標準 | 重い場合 |
| --- | --- | --- |
| グラフィック簡易設定 | 普通〜低い | 低い〜非常に低い |
| アップスケーラー | RTX は DLSS、Radeon は FSR | 同じ |
| 解像度スケール（アップスケーラー品質） | 品質 | バランス〜パフォーマンス |
| フレーム生成 | 対応GPUなら2X | カクつくならオフ |
| NVIDIA Reflex | オン | オン |

画面サイズ別の目安は、フルHDが「品質」、WQHDと4Kが「品質〜バランス」、それでも重ければ「パフォーマンス」です。

根拠：[S01]

## FPSを上げる順番

1つか2つずつ変えて、同じ場所でFPSを確認します。一度に全部変えると、原因が分かりません。

1. DLSS または FSR を有効にする。
2. 解像度スケールを「品質」にする。足りなければ「バランス」に下げる。
3. 大規模戦闘品質を下げる。
4. エフェクト品質を下げる。
5. 他プレイヤーのエフェクト表示を減らす。
6. 影、グローバルイルミネーション、反射を下げる。
7. ボリュメトリックフォグをオフにする。
8. 視野距離と植生を下げる。
9. 対応GPUならフレーム生成を試す。

FPSに特に影響するのは、解像度スケール、大規模戦闘品質、エフェクト品質、影、グローバルイルミネーション、反射です。テクスチャ品質は、VRAM に余裕があれば下げてもFPSがあまり伸びません。人が多い場所で重いときは、「情報表示」タブの「一般」で「他のプレイヤーのペット表示」をオフにすると軽くなります。

根拠：[S01] [S02]

## アップスケーラーとフレーム生成

| 機能 | 内容 |
| --- | --- |
| アップスケーラー | TAA・TSR・DLSS・FSR から選ぶ。低い解像度で描いた映像を引き上げてFPSを稼ぐ |
| DLSS | GeForce RTX 向け。グローバル版は DLSS 4.5 に対応して始まった。GeForce Game Ready ドライバーを最新にする |
| FSR | AMD Radeon 向けの同じ役割の機能 |
| TSR | Unreal Engine 5 が持つ方式 |
| フレーム生成 | 描いたフレームの間に生成フレームを挟んで滑らかに見せる。RTX 40/50 シリーズ向け |
| Multi Frame Generation | RTX 50 シリーズで利用可。最初は2X程度から。倍率を上げても入力遅延は改善しない |
| NVIDIA Reflex | ボタンを押してから画面に映るまでの遅れを縮める。3段階 |

フレーム生成は、元のFPSが十分出ているときに効果があります。元のFPSが30前後だと根本的な処理落ちは解決しません。元のFPSが低い、カメラ操作が遅れて感じる、PvPで入力の反応を重視する、かえってカクつく、といった場合はオフを試してください。一部のノートPCでは、G-SYNC を有効にしたまま DLSS のフレーム生成を使うと異常終了することがあります。アップスケーラーを変えたときは、次の起動時に反映されます。

根拠：[S01] [S02]

> **韓国版のみ**：RTX 50 シリーズで最大6倍までのフレーム生成が使える、という記述は韓国版の公式アップデートノートに基づきます。

## チャットとHUDの設定

| 設定 | 内容 |
| --- | --- |
| チャット設定 | 「基本設定」と「ブロックリスト」の2つ。一般・種族・パーティ・レギオンなど11種類のチャットを、種類ごとに表示するか選べる |
| 戦闘ログ | ダメージ・回復・バフ/デバフのログとシステム通知も同じ画面で切替 |
| 時刻表示 | 現地時刻[LT]とサーバー時刻[ST]を選べる |
| 自動翻訳 | 同じ画面でオン／オフ。オンにすると外国語の書き込みも日本語になって流れ、チャット量が増える |
| HUD編集 | プリセット6枠。取り込み・書き出し対応。グリッド表示とスナップで配置。外郭余白、チャット文字サイズ、UI比率も調整 |

グローバル版のテストではUIの文字が小さいという声が目立ったため、始めた日に一度、HUD編集でUI比率を確認するのがおすすめです。チャットコマンドは [[controls-and-keybinds]]、チャットの仕組みは [[chat-and-social]] を参照してください。

根拠：[S02] [S03]

## 戦闘と見やすさの設定

| 困りごと | 変える設定 |
| --- | --- |
| スキルを使うたびに画面が揺れて酔う | グラフィックの「カメラ/演出」で「戦闘時にカメラ揺れ演出」をOFFにする |
| Tab で目の前の敵に切り替わらない | 「戦闘」タブの「対象探索」で基準をカメラの前方にする |
| 画面全体がぼやけて見える | 「最適化」で「ポストプロセス品質」を「低い」以下にする |
| テレポートの白い光がまぶしい | 「カメラ/演出」で「テレポート演出の色」を「暗く」にする |

操作モード（AION 2 / AION 1）は「設定 → 戦闘 → 操作 → 操作モード」で切り替えられ、スキル予約は同じ場所の初期値がオンです。ゲームパッドの使い方は [[controller-and-steam-deck]] を参照してください。
