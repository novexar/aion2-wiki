> **要確認**：ウィンドウのショートカットキーは DefKey と Space4Games の一覧でも確認でき、実績は Aion 2 Maps の Y ではなく両サイトの Z に合わせています。Esc メニューの3グループ構成、機能が開くレベル、HUD プリセットの数は Aion 2 Maps のみの記述で、第2の資料がありません。メニュー名の日本語表記は攻略サイトの表記を使っているため、ゲーム内の表示と違う場合はゲーム内を優先してください。

AION2 では、多くの機能が Esc メニューか、キーボードのショートカットから開きます。ところが、遠征、悪夢、超越、アビス、取引所、メールなど十数個のウィンドウには、初期キーがありません。この記事では、日本語と英語のメニュー名、開き方、解放レベルを対応させます。

根拠：[S01] [S02]

## Escメニューの構成

Esc は、キャスト中断、ウィンドウを閉じる、ターゲット解除、メニューを開く、を兼ねます。メニューは3つのグループに分かれています。

| グループ | 含まれる機能（英語名） |
| --- | --- |
| コンテンツ（Content） | 遠征（Expedition）、デイリーダンジョン（Daily Dungeon）、聖域（Sanctuary）、シューゴフェスタ（Shugo Festival）、戦場（Battlefield）、製作（Crafting）、戦闘分析（Combat Analysis）ほか |
| シーズン（Season） | 超越（Transcendence）、悪夢（Nightmare）、覚醒戦（Ascension Trial）、アビス（Abyss）、闘技場（Arena） |
| アクティビティ（Activity） | 出席（Attendance）、メール（Mail）、フレンド管理（Manage Friends）、取引所（Market）、カスタマイズ（Customization）、ランク（Rank） |

メニューの「アクティビティ → 出席」は、ローンチ記念の出席ボードを受け取る場所です。メールの受け取りは [[mail-and-coupon]] を参照してください。

根拠：[S01]

## 画面のよく使う場所

| 場所 | 内容 |
| --- | --- |
| ミニマップの左上付近 | ダンジョンの退出ボタン。入った場所に戻れる |
| ミニマップの脇の人型アイコン | Alt を押したままクリックすると倉庫管理人に歩いて向かう（[[storage-and-cube]]） |
| クエストトラッカー右上の矢印 | クエストへ直接移動 |
| キューブ右下の「遠隔倉庫」 | メンバーシップ限定の倉庫アクセス |

HUD の配置は、HUD 編集で変えられます。プリセットは6枠あり、コードやファイルで共有できます（[[recommended-settings]]）。

## 機能が開くレベル

メインクエストが機能を解放します。レベルは「クエストの推奨レベル」で、厳密な制限ではありません。

| レベル | 開く機能 |
| --- | --- |
| 1〜4 | メール、チャット、パーティ、フレンド、マップ、HUD編集、戦闘分析、キャラクター切替。ジャーナルと外見のカスタマイズはLv2、ステータス画面はLv3、スキルはLv4 |
| 約5 | 翼と飛行（最初の覚醒クエストと同時） |
| 約6 | 称号 |
| 9 | 強化、実績 |
| 10 | 製作、物質変換、採集、ディーヴァパス、出席、ナビゲーター、抽出。ペットはクエストで開く |
| 約12〜13 | ディーヴァニオン、シューゴフェスタ。ナビゲーターが地域クエストや封印ダンジョンを案内し始める |
| 16 | レギオン。モノリスがナビゲーターに出る |
| 20 | 遠征（探険）。クラオ洞窟 |
| 約22 | 最初のストーリーロック。覚醒ゲージを満たし、覚醒クエストでスティグマと万神殿が開く |
| 25 | 補給依頼 |
| 30 | デイリーダンジョン |
| 約32 | 次の覚醒クエスト（新しい翼、スティグマレベル上げ） |
| 45 | アビス、悪夢、超越、アルカナ、聖域、闘技場、戦場、覚醒戦、取引所、使命クエスト、ランキング、シーズン。PvPはすべて45から |

使命（デューティ）クエストは、45になる前にマップの「使命」タブを開かないでください。既知の不具合で、1日待たされるという注意があります。詳しい解放条件は [[unlocks-by-level]] を参照してください。

根拠：[S03]

## 日本語の主な用語

遠征、超越、聖域、悪夢、闘技場などの日英対照は、[[glossary]] にまとめています。たとえば、遠征（Expedition）は1〜5人のパーティダンジョン、超越（Transcendence）は2〜5人のダンジョン、聖域（Sanctuary）は10人のレイドです。キューブ（インベントリ）はギーナで5枠ずつ広げられます。
