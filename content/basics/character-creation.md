AION2 のキャラクター作成画面（キャラクリ）は、顔・髪・メイク・体型を細かく調整できることが特徴です。NC は調整項目を200以上としています。性別とクラスは独立していて、どのクラスも男女どちらでも選べます。この記事では、作成時の流れ、スロット数、後から見た目を変える方法をまとめます。

根拠：[S01]

## 作成画面でできること

| 項目 | 内容 |
| --- | --- |
| 調整項目 | 200以上（顔、髪、メイク・スタイリング、体型） |
| 性別 | 男女どちらも選べる。クラスとの紐づけなし |
| プリセット | 男女それぞれにプリセットがあり、選んだ後で色や形を変えられる |
| 作成時の補助 | 音声、衣装プレビュー、照明の種類・色・角度 |
| 顔 | 顔型プリセットの後に、あご、頬、額、目（大きさ・位置・回転）、鼻、口などのスライダー。尖り耳も選べる |
| 髪・メイク | 髪の単色／2トーン染色、メイク、そばかす、ほくろ、グリッター |
| タトゥー・傷 | 顔、胴体の前後、腕、脚に配置できる。ウォーペイントや傷もある |
| 体型 | 小柄から大柄までのプリセットと、身長・厚み・筋肉などのスライダー |
| 見た目の反映 | 作成画面の見た目がそのままゲーム内に出る |

作成後の見た目は、ゲーム内のクローゼット（Closet）で装備スロットごとに変えられます。

根拠：[S01]

## 作り方のコツ

1. 最初に性別を決める。作成中に性別を切り替えると、編集した項目がリセットされる。
2. 完成イメージに近いプリセットを選んでから調整する。全項目を一から変えるより、バランスを崩しにくい。
3. 輪郭（あご、頬、頬骨）から調整し、目、鼻、口の順に整える。
4. 正面だけでなく、横顔と斜めからも確認する。髪型で顔の印象が大きく変わるので、最後に髪型で再調整する。
5. 気に入った設定は全スライダーのスクリーンショットを残しておく。作り直しや再現に役立つ。

根拠：[S02]

## キャラクタースロット

| 項目 | 内容 |
| --- | --- |
| スロット数 | グローバル版は初期4つ。8つまで拡張できる（NC 配信、2026-08-07） |
| 名前 | 作成時に決める。天族・魔族は別サーバー。リージョンは初回ログイン時に選び、変更できない |
| 事前予約 | グローバル版でキャラ名の事前予約は発表されていない |
| テストのキャラ | 9月17〜18日のテストで作ったキャラは引き継がれない |
| サーバー移動 | キャラクタースロットは移動後も旧サーバーに残る |

サーバーやリージョンの選び方は [[regions-and-servers]]、天族と魔族の違いは [[races-elyos-asmodian]]、クラスは [[classes-overview]] を参照してください。

根拠：[S01] [S03]

## 見た目を後から変える

| 方法 | 内容 |
| --- | --- |
| 外見変更券（Appearance Change Voucher） | インベントリで右クリックすると作成画面が開く。9月30日に全員へ1枚配布された |
| スタイリング箱の券 | ファウンダーズパックの箱に入る。Lv10から使え、箱を開けてから7日間有効。キャラがLv10になるまで箱を開けない |
| Twitch Drops | 9月30日〜10月4日のドロップに外見変更用のカスタマイズ券が含まれていた |

外見変更券はクラスや種族の変更には使えません。クラスや陣営を変えるなら新しいキャラを作ります。キャラの削除と作り直しは [[character-deletion-and-redo]] を参照してください。

根拠：[S01] [S03] [S04]

## スタイルショップ（キャラクリの共有）

公式サイトには「スタイルショップ」があり、他のプレイヤーが作ったキャラクリの閲覧、ダウンロード、お気に入り登録、自分の作品の登録ができます。

1. 公式スタイルショップで気に入ったキャラクリを探す。
2. スタイル詳細からデータをダウンロードする（無料）。
3. ゲーム内の「カスタマイズ」を開く。
4. 登録データ一覧からダウンロードしたデータを選ぶ。
5. 見た目を確認して適用する。適用には600 Quna が必要。

適用前にゲーム内で必要な Quna の表示を確認してください。

根拠：[S02]

> **注意**：スタイルショップの機能と費用の記述は日本語の攻略サイト1件に基づきます。ゲーム内の表示が優先されます。

## 注意点

- 外見変更券やスタイリング箱の券はキャラ単位の扱いです。詳しくは [[whats-bound]] を参照してください。
- 初日は作成画面が全サーバーで一時的にロックされるなどの混乱がありました。混雑時は NC が推奨サーバーを案内しています。
