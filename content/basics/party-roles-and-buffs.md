> **要確認**：パーティバフを出せるクラスがテンプラー、グラディエーター、チャンター、クレリックの4つである点は、AION2 Hub が翻訳した韓国版パッチノート（2026-08-26）でも確認できます。ただし、バフの重複・上書きの組み合わせ、タンクの挑発の数値、レイドのタンク人数は Aion 2 Maps 1件のみの資料で、第2の資料がありません。数値の多くはアジア版（韓国・台湾）のもので、韓国版では2026-08-26にこの4クラスのパーティバフが下方修正されているため、グローバル版で変わっている可能性があります。

AION2 のパーティは5人、レイドは10人です。回復やバフを出すクラスは限られ、同じ役割を重ねると効果が消えたり、ボスの標的が奪い合いになったりします。編成の前に、誰がパーティを強化し、誰がボスを抑えるのかを押さえておきましょう。

根拠：[S01] [S02]

## パーティバフを出すクラス

パーティ全体を強化するバフを出せるのは、テンプラー、グラディエーター、チャンター、クレリックの4クラスです。ほかのクラスは自分のダメージだけで評価されます。

| ルール | 内容 |
| --- | --- |
| 基本の編成 | パーティごとに各バフクラスを1人まで。2人目は別のパーティへ |
| テンプラーとグラディエーター | 1パーティに片方だけ。主力のパーティバフは重複しない（NC の説明） |
| 同じクラスが2人 | 後から使ったバフが先のバフを上書きする（コミュニティ報告） |
| 効果の範囲 | パーティバフは自分のパーティのみ。レイド全体のデバフは全員に有効 |
| 人数 | パーティ5人、レイド10人 |
| スティグマレベル | サポート系のバフはレベルに依存し、20で頭打ち |

根拠：[S01] [S03]

### 上書きされる効果

| 組み合わせ | 起きること |
| --- | --- |
| テンプラーの「激昂」とグラディエーターの「巧みな反撃」 | どちらも PvE のパーティ与ダメージ増加で、重複しない |
| チャンターの「大地の約束」とクレリックの「苦痛の連鎖」 | クレリックの効果中は、大地の約束のダメージ軽減が消える |
| チャンターの波動撃のデバフ | クレリックの「弱化の烙印」に上書きされる |
| チャンターの「不敗のマントラ」とクレリックの「保護の光」 | 同時に効かない。高いレベルが優先され、同じなら不敗のマントラ |
| チャンターの「疾風の権能」とクレリックの「大地の祝福」 | 疾風の権能の保持中、大地の祝福が1分間かからない（双方向） |

スキル名は [[chanter]]・[[cleric]]・[[templar]]・[[gladiator]] の各クラス記事（データベースの日本語名）に合わせています。ゲーム内の表示が優先されます。

根拠：[S01]

## タンク（ボスのヘイト管理）

ボスの標的を保つ「ヘイト（Enmity）」を稼げるのは、テンプラーとグラディエーターだけです。この2クラスのスキルにはヘイト増加が組み込まれており、装備や育成では選べません。

| クラス | ヘイトを増やすスキル | 強制挑発（ハードタウント） |
| --- | --- | --- |
| テンプラー | 9個 | あり（挑発） |
| グラディエーター | 8個 | なし |
| スピリットマスター | プレイヤー自身にはなし。精霊ペットのみ | なし |
| ほかのクラス | なし | なし |

根拠：[S02]

| 項目 | 内容 |
| --- | --- |
| 1レイドに入れるテンプラー | 1人。2人だとヘイトを奪い合い、片方が火力を犠牲にする |
| グラディエーター | 攻撃するだけでヘイトは溜まるが、奪われたら取り戻せない |
| テンプラーの挑発 | クールタイム30秒。ヘイトを一時的に大きく上げる。テンプラーの与ダメージに応じて強くなるため、火力装備が弱いと効果が落ちる |
| 挑発の副効果 | 20m以内の対象にダメージ、15秒の縮小、50%で3秒間自分を攻撃させる |
| テンプラーのMP | ヘイトスキルの多くはMPを100〜150回復するので、タンクの回しがそのまま MP 回復になる |
| ブロック装備 | レイドでは重視されない |

根拠：[S02]

## 初心者向けの目安

1. 野良パーティでは、タンクにテンプラーが1人いるかを確認する。
2. 自分がバフクラスなら、同じバフクラスが同じパーティにいないか確認する。
3. チャンターとクレリックの効果は一部重なる。ゲーム内で効果が消えていないか見る。
4. 仲間のマッチングと貢献度は [[party-and-matchmaking]]、クラスの個別説明は [[classes-overview]] を参照する。
5. ボスのスタッガーは役割に関係なく全員で狙う（[[combat-basics]]）。
