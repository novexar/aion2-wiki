AION2 のサーバーは「リージョン（地域）」→「陣営（天族／魔族）」→「サーバー」の順に選びます。日本からはアジアリージョン（サーバーは東京）が推奨です。各サーバーは天族か魔族のどちらか専用で、天族サーバーと魔族サーバーが1対1でペアになり、アビスや時空の亀裂ではペア先のプレイヤーと戦います。リージョンは最初のログインで決まり、後から変えられません。

根拠：[S01] [S02] [S06]

## リージョン

| リージョン | 所在地（クライアント解析） | 備考 |
| --- | --- | --- |
| アジア（Asia） | 東京（日本） | NC は「Japan」とも呼ぶ。日本・東南アジア・オセアニアからの推奨先 |
| 北米東部（NA East） | バージニア | |
| 北米西部（NA West） | フェニックス | |
| ヨーロッパ（Europe） | フランクフルト | サーバー数が最多 |
| 南米（Latin America） | サンパウロ | NC の一覧では「Latin America」表記 |

- リージョンロックはなく、日本から北米サーバーでも遊べます（公式配信ではアジアを推奨）。遅延だけがコストです。
- **リージョンの選択は最終的なもの** で、キャラクターをリージョン間で移動することはできません。ダンジョンのマッチングもリージョン内で完結します。別リージョンで遊ぶなら新しいキャラを作ります。
- 同じ名前のサーバーが別リージョンにもありますが、別のサーバーです。

根拠：[S01] [S02] [S03]

## 陣営とサーバーの仕組み

- 1サーバーに1陣営。天族サーバーには天族だけ、魔族サーバーには魔族だけがいます。
- 天族サーバーと魔族サーバーが1対1でペアになり、アビス・時空の亀裂などの対立コンテンツではペア先のプレイヤーと遭遇します。ペアは固定ではなく、勢力バランスを保つために NC が定期的に変更します。
- サーバー名は AION の神々や登場人物の名前で、名前が同じなら陣営も同じです（シエルは常に天族、イズラフェルは常に魔族）。

根拠：[S01] [S03] [S06]

## アーリーアクセスサーバーと正式サービスサーバーの違い

| 項目 | アーリーアクセスサーバー | 正式サービスサーバー |
| --- | --- | --- |
| 開始 | 2026年9月30日（ファウンダーズパック購入者） | 2026年10月5日 |
| 新規参加 | 正式サービス後は誰でも作成可（作成制限がかかっていなければ） | 誰でも作成可 |
| 進行度 | 5日早く始まっており、育成・サーバー経済が先行 | 全員同時スタート |
| サーバー移動 | アーリーアクセスサーバー間のみ | 正式サービスサーバー間（同陣営） |

「とりあえずアーリーアクセスサーバーで始めて、後から正式サービス側へ移る」ことはできません。特に理由がなければ正式サービス側から選び、友人やレギオンがアーリーアクセスサーバーにいる場合だけそちらを選ぶのが無難です。

根拠：[S01] [S02] [S05]

## サーバーが違ってもできること・できないこと

| コンテンツ | 別サーバーの友人と |
| --- | --- |
| 遠征・超越・聖域などインスタンスダンジョン | 一緒に行ける。同じリージョン内の全サーバーからマッチングされ、部屋のリーダーが「同陣営のみ」に設定しない限り両陣営が混ざる |
| 闘技場・バトルグラウンド | 一人でキュー。パーティでのキューはない |
| フレンド・ささやき | フレンドは同じ陣営のみ。別のサーバーグループのキャラにはフレンド申請・ささやき・パーティ招待が届かない |
| レギオン | サーバー単位。加入一覧には今いるサーバーのレギオンだけが出る |
| 取引所 | 自分のサーバーの取引所のみ。リージョン共通の統合取引所は開始時点では未開放（各サーバーの進行がそろった段階で開く予定） |
| アビス・時空の亀裂 | ペア先のサーバーの敵陣営と遭遇 |

根拠：[S01] [S06]

## サーバーの選び方

1. 日本から遊ぶなら **アジア** を選ぶ。
2. 友人・レギオンと遊ぶなら、**リージョン・陣営・サーバー名の3つ** を事前に合わせる。
3. 特に指定がなければ、ログイン画面で「推奨」と表示されるサーバー、または正式サービス側で現在キャラクターを作成できるサーバーを選ぶ。
4. 「シエルが日本人サーバー」「カイジネルが一番人気」といった噂だけで決めない。公式はサーバー別の人口や日本人比率を公開していません。
5. 「作成制限（Creation Restricted）」のサーバーは新規作成を受け付けていないので、別のサーバーを選ぶ。

根拠：[S02] [S05]

> **注意**：サーバーが満員のときは待機列に並びます。NC は「良好な状態のメンバー」を優先待機列に案内するとしていますが、「メンバー」の定義は告知に書かれていません。

根拠：[S01]

## キャラクター枠

アカウントごとに最初 4 枠で、8 枠まで拡張できます。キャラクター枠はサーバー移動で持ち越されません。
