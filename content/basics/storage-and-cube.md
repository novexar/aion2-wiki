> **要確認**：遠隔倉庫がメンバーシップの特典であることは、vi.ki と TimeSaver（NC のファウンダーズパック説明を引用）でも確認できます。一方、初期枠（40/25/25）、倉庫の拡張費用、キューブの拡張回数、アイテム復旧の回数とリセット日は、クライアント解析に基づく Aion 2 Maps 1件のみの資料で、第2の資料が見つかっていません。ゲーム内の表示が優先されます。

AION2 には、持ち歩く所持品の「キューブ（Cube）」と、2種類の倉庫があります。サーバー倉庫（Server Storage）は同じサーバー上の自分の全キャラクターで共有でき、キャラクター倉庫（Character Storage）はそのキャラ専用です。素材はキャラクター倉庫に置くと、製作・物質変換・補給要請・強化がそこから直接引き出して使えるので出し入れが不要です。

根拠：[S01]

## 3つの入れ物

| 入れ物 | 内容 | 初期枠 |
| --- | --- | --- |
| キューブ | 持ち歩くインベントリ（初期キー I） | 40 |
| サーバー倉庫 | サーバー上の全キャラで共有。キャラがサーバー移動しても残る | 25 |
| キャラクター倉庫 | そのキャラクター専用 | 25 |

サーバー倉庫には、帰属アイテムでも入れられるものが多く（ポーション、スクロール、パワーシャードなど）、復活の霊石、オードエネルギー、魂の書（Soul Codex）、見た目アイテムは入りません。キャラクター倉庫は、サーバー倉庫が拒否するキャラ帰属アイテムも受け付けます。入るかどうかはアイテムのツールチップで分かります。帰属の詳細は [[whats-bound]] を参照してください。

帰属ギーナ（Bound Kina）はどちらの倉庫にも入れられず、取引可能なギーナだけが入ります。

根拠：[S01] [S02]

## 倉庫へのアクセス

| 方法 | 手順 |
| --- | --- |
| 倉庫管理人 NPC（無料） | Alt を押したままミニマップ脇の人型アイコンをクリックし、倉庫管理人を選ぶとキャラが歩いて向かう |
| 遠隔倉庫（メンバーシップ限定） | キューブ右下の「遠隔倉庫」メニューから、サーバー倉庫とキャラクター倉庫を開く。「クイック保管」で一致する物を一括で預ける |

メンバーシップの内容は [[membership]] を参照してください。

根拠：[S01] [S03] [S04]

## 枠の拡張

倉庫は5枠（1ライン）ずつ、ギーナで拡張します。倉庫2種は同じ価格表で、それぞれ別に払います。最初は1〜5ラインが開いています。

| ライン | 1ラインあたり（ギーナ） | 累計 |
| --- | --- | --- |
| 6〜10 | 1,000 / 1,000 / 1,500 / 2,000 / 2,500 | 8,000 |
| 11〜15 | 3,500 / 5,000 / 6,500 / 9,000 / 15,000 | 47,000 |
| 16〜20 | 20,000 / 25,000 / 35,000 / 45,000 / 60,000 | 232,000 |
| 21〜25 | 80,000 / 150,000 / 150,000 / 200,000 / 300,000 | 1,112,000 |
| 26〜30 | 400,000 / 550,000 / 700,000 / 950,000 / 1,300,000 | 5,012,000 |
| 31〜36 | 1.8M / 2.5M / 3.3M / 4.5M / 6.2M / 8.4M | 31,712,000 |

キューブにはギーナによる拡張が10回あり、10,000〜1,000,000ギーナ、合計270万ギーナです。クライアント内の拡張チケットは1ラインずつ開き、各入れ物とも最大80ラインまで増やせます。資料では倉庫の上限が「180枠」「最大400」と表記が分かれており、ゲーム内の表示を確認してください。

根拠：[S01]

## アイテムの復旧（Recover Item）

売却や抽出を間違えたときは、メインメニューの「アイテム復旧」から戻せます。復旧したアイテムはキューブに入ります。

| 間違い | キャラクターごとの回数 |
| --- | --- |
| NPC商人に売却 | 年30回 |
| 抽出（ユニーク等級以上のみ） | 年1回 |
| ソウルシンクで消えた素材 | 年1回 |

回数は1月1日にリセットされます。スタック全体で1回と数え、期限付きアイテムは復旧できません。抽出を取り消すと、得た強化石とアビスポイントが戻り、ギーナは帰属ギーナで返金されます。スキンは残ります。復旧は取引後の間違いには効かないため、売る前に確認しましょう。
