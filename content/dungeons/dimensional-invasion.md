> **要確認**：次元侵攻はグローバル版の一次資料が少ないコンテンツです。毎時30分の開催、鍵が1日1個で上限7個という点は、独立した2つの攻略サイト（Wikirealm、MeinMMO）で一致しています。Lv45からの参加とサーバー共有は aion2maps の記述のみで、戦闘の中身（敵の種類や報酬の詳細）は確認できていないため書いていません。

次元侵攻（Dimensional Invasion）は、Lv45から参加できる、フィールドで行う防衛型のイベントです。毎時30分に始まり、参加すると報酬の鍵が使えるようになります。報酬を開けるには鍵が必要で、鍵は毎日少しずつ補充されます。

## 基本情報

| 項目 | 内容 |
| --- | --- |
| 解放 | Lv45 |
| 開催 | 毎時30分（Wikirealm）。1度に3種類の侵攻イベントがあると記載 |
| 報酬 | 「次元侵攻の報酬の鍵」で報酬キューブを開ける |
| 鍵の補充 | 1日1個（毎日のリセット時） |
| 鍵の上限 | 7個 |
| 共有単位 | サーバー（同じサーバーのキャラで共有） |

鍵は、使わなくても7個までたまり、それ以上は補充されません。1日1個なので、7日間まったく使わないと満タンになります。

根拠：[S01] [S02] [S03] [S05]

## 日課での扱い

ゲームカ（日本の攻略サイト）は、次元侵攻を毎日の日課のひとつに挙げています。「鍵が上限まで溜まる前に参加して消費する」のが基本です。

1. 毎時30分のイベントに、鍵が溜まっているときだけ参加する。
2. 毎日リセット（日本時間16:00）で鍵が1個増える。
3. 7個に達する前に使う。

同じ時間帯に [[shugo-festa]]（毎時0分）もあります。両方の鍵を一緒に管理すると楽です。

根拠：[S02] [S04]

## 注意

- 鍵はサーバー共有です。サブキャラが使うと、メインの分が減ります。[[server-shared-limits-and-alts]] を参照してください。
- aion2maps は、次元侵攻の数字に「アジア版の情報」と注記しています。グローバル版のゲーム内の鍵の表示を優先してください。
- 日課全体の一覧は [[daily-and-weekly-checklist]]、リセット時刻は [[reset-times]] です。
