獰猛な角岩窟（Ferocious Horn Den、別訳 Cave of the Savage Horn）は、アビスにある獰猛な角ライカン族の洞窟です。Lv45・アイテムレベル（IL）2,100で、探険にも征服にも入れる、遠征（Expedition）で最も高い段階の★3です。最終ボスはヌアクム（Nuakum）です。

共通ルールは [[expeditions-and-odyle]] を参照してください。

> **要照合の結果**：ある資料はこの遠征を「韓国版限定」としていますが、グローバル版のDB、aion2maps、そしてその資料自身の遠征一覧がいずれもグローバルの6遠征に含めています。グローバル版で遊べるものとして書いています。

## 最終ボス：ヌアクム

勝負を決めるのは、約75%・55%の「狩り」、約30%の「破壊の青い光」、終盤の「赤い玉」です。エンレイジは約5分です。

### 約75%（2回）と約55%（3回）：狩り

1. ヌアクムが端へ跳んで手が届かなくなります。
2. 1人が8秒間拘束され「狩りの印」が付き、分身がその人へ突進します。
3. 印の付いていない人が分身の前に立ち、ダッシュを受けます。
4. 拘束された人の足元の赤い円を読みます。
   - 小さい円（内向きの矢印）なら、ブロックした人以外は全員で入る。4〜5人なら1人10%ずつ。
   - 大きな円（矢印なし）なら、拘束された人以外は全員が出る。1人で受けて50%。全員が入ると500%ずつです。

75%では2回連続で、1回目にブロックした人は印が付いたままなので、2回目は別の人が受けます。55%では3回連続です。

根拠：[S01]

### 約30%：破壊の青い光（Blue Light of Destruction）

1. 中央に凝縮エネルギーの玉が現れ、34秒の詠唱が始まります。玉は近くの人を引き寄せ、6m以内の人を焼きます。
2. 印の付いた1人が、ボスとの間に玉が来る位置に立ちます。
3. ボスは4回投げ、3回が玉に当たると玉が壊れます。
4. 3回目の前に恐怖が全員にかかるので、玉の近く（焼かれない範囲）に立ちます。

壊せずに詠唱が終わると、全員に最大HPの500%です。

根拠：[S01]

### 終盤：赤い玉

ボスが1人を拘束して、赤い玉を2回投げます。別の2人が線の間に入り、1個ずつ受けます。1人が両方受けると、2発目が最大HPの85%で死にます。出現は残りHPが20%から最後の10%までの間と、資料により幅があります。

根拠：[S01]

### 出血と通常攻撃

| 攻撃 | 対処 |
| --- | --- |
| 出血3スタックで破裂し、足元に出血だまり | 端で置く。タンクは端へ引っぱる |
| 前方の連続引っかき（200度・9m、予兆なし） | 背後にいる。最も危険な通常攻撃 |
| 引き寄せ→スタン2秒 | 解けたら背後へ |
| 突進の幅14m・長さ30m | 帯から出る |
| 飛びつき（半径7.5m）→ノックダウン3秒 | 円から出る |
| 咆哮（30m以内に恐怖2.5秒） | 青い光の3投目の前に来る |

根拠：[S01]

## 中ボス2体

| 中ボス | 注意点 |
| --- | --- |
| Watchdog Kwapo | 約75%で標的不可になり、青い玉が落ちる。12.5秒の間に片側を集めて安全地帯を作る。拾うと移動が遅くなる。中央で吠えたら輪をジャンプ。赤い円は1人で受ける |
| Necromancer Duanka | 祭壇の宝玉を遠距離1人が取り、4体の魂を15秒以内に倒す（探険は2体）。6秒拘束＋赤い円は全員で入る。中央へ引き寄せられたら24m以上離れ、雷の魂に触れない |

根拠：[S01]

## ルート

1. 木のバリケードの前の箱から爆弾を投げて壊し、Kwapoへ。
2. 斜面を上り、左の壁を壊して滑空し、トーテムの間へ。
3. トーテムを起動すると雑魚が湧きます。タンクとヒーラーが中央で受け、アタッカーは左右の階段で爆弾を取って投げます。雑魚を倒すとトーテムを壊せて、扉が開きます。
4. Duankaを倒して外へ出て、上昇気流で上へ。ボス戦の前に最後のキベリスクで登録します。

根拠：[S01]
