聖域（Sanctuary）は、ボス戦を何人かで進める遠征や超越より上の、AION2で最も難しい種類のPvEコンテンツです。グローバル版では10人が2つのパーティー（5人ずつ）に分かれ、別々のボスと戦ってから最終ボスで合流します。ローンチ時点の聖域は「深淵の再錬：ルドラ」の1つだけで、2026年10月5日の正式開始と同時に一時削除されました。

## 基本情報

| 項目 | 内容 |
| --- | --- |
| 人数 | 10人（5人×2パーティー）。韓国版は当初8人で、2026年7月1日から10人 |
| 入場 | レベル45、IL（アイテムレベル）2,800（ルドラ） |
| 報酬の受取 | 報酬キューブにオードエネルギー40（アジア版は80） |
| 報酬付きの討伐 | 週1回（最終ボスの討伐回数を使う） |
| 復活制限 | 1人1ボス戦につき2回まで（DB。韓国版では復活スキルと復活石の合計） |
| マッチング | リージョン内のクロスサーバー。両陣営が一緒になる |
| 最高の等級 | 唯一（ユニーク）。英雄（ヒロイック）のドロップはなし |

根拠：[S01] [S02] [S03]

## 流れ（ルドラの例）

1. 全員で入口の反応炉を壊す。
2. 第1パーティーがボスのラフ、パーティーBがケトゥと、別々の場所で同時に戦う。
3. 両方を倒すと、全員が最終ボスのルドラの前に集合して戦う。

ラフとケトゥは中ボスで、討伐しても報酬はありません（受取はルドラを倒したときのキューブ）。パーティー2側はクレリックの生存が必須で、1人で魂の石を受けて残りを蘇生する作戦が一般的です。

根拠：[S01] [S03]

## 週制限と受取

- 入場は無料で、何度でも挑めます。
- 報酬付きの討伐は週1回です。最終ボスを倒した時だけ、その回数が消費されます。全滅や中ボスの討伐では消費されません。
- 4回目の受取ごとに、選択報酬が加わるとaion2mapsのゲームデータにあります。

根拠：[S03]

## 必要な構成

| 項目 | 内容 |
| --- | --- |
| クレリック | 各パーティーに1人が実質必須（チャンターが代わりになる例も） |
| チャンター | 防御と命中のバフを持つので、各パーティーに1人が理想 |
| 防御系 | ルドラの赤い玉用に、ブロックや無敵スキルを持つ職を1〜2人 |
| 命中・クリティカル | アジア版の目安は命中約1,450〜1,500、クリティカル約1,600。足りないと、ILが高くてもまともにダメージが入らない |

ある資料では、韓国・台湾版のトップ層は、クレリックとテンプラーを「ほぼ替えが利かない」、次いで剣闘士とチャンターと評価しています。

根拠：[S01] [S03]

## 現在の状況

ルドラは、アーリーアクセス期間中に、NCの想定より早く討伐されました。そのため、NCは調整のために正式開始時に削除しました。復帰日は10月16日までに案内される予定です。経緯は [[ludra-raid-suspension]]、戦い方は [[abyssal-forge-ludra]] を参照してください。
