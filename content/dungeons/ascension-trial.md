覚醒戦（Ascension Trial）は、Lv45から挑戦できる **1人用のタイムアタック型ダンジョン** です。小部屋のモンスターを順に倒して最後のボスを撃破し、クリアまでの速さと死亡回数でスコアが決まります。挑戦回数は **キャラクターごとに週3回** しかなく、入場した時点で1回消費されるため、「いつ・どの難易度で挑むか」が重要なコンテンツです。

日本語サイトによっては「昇天の試練」と呼ぶこともありますが、グローバル版のデータベース上の表記は「覚醒戦」です。Lv45の覚醒クエスト（Ascension）とは別物なので注意してください。

根拠：[S01] [S03] [S05]

## 基本データ

| 項目 | 内容 |
| --- | --- |
| 人数 | 1人（ソロ） |
| 解放 | Lv45 |
| 挑戦回数 | 週3回／キャラクターごと（サーバー共有ではない） |
| リセット | 毎週水曜 16:00（JST） |
| 難易度 | 簡単（Easy）／普通（Normal）／難しい（Hard）／極限（Challenge）の4段階 |
| 必要IL | 簡単 1,000／普通 1,500／難しい 2,000／極限 2,500 |
| 死亡制限 | 簡単 5回／普通 3回／難しい 2回／極限 2回 |
| 週間ローテーション | ダンジョンは週替わり |

根拠：[S01] [S02] [S04]

> **注意**：韓国版には「破滅（Doom）」などさらに上の難易度がありますが、グローバル版の現行データで選べるのは上の4段階です。海外動画で「7段階」と語られるのは韓国版の話です。根拠：[S05] [S07]

グローバル版データベースには、次の6種類の覚醒戦ダンジョンが登録されています（各4バリエーション）。

| ダンジョン名 | 備考 |
| --- | --- |
| 忘れられた保存庫 | 略奪者の地下倉庫。首長を倒す |
| 悪夢の祭壇 | |
| 憎悪の聖所 | |
| 暴君の隠れ家 | |
| 死者の寝室 | |

毎週このうち1つがローテーションで開放されます。入場画面で今週のダンジョンと難易度ごとの必要ILを確認してください。

根拠：[S03] [S04]

## 報酬

報酬はスコア（ポイント）に応じて段階的に増えます。装備やスティグマシャードは落ちません。以下は「忘れられた保存庫（簡単）」のデータベース値です。

| スコア | 強化石 | 成長のペット箱 | 突破石の欠片（唯一） | 覚醒の刻印箱 |
| --- | --- | --- | --- | --- |
| 7,000 | 3,500 | 20 | 14 | 10 |
| 5,000 | 2,500 | 17 | 12 | 9 |
| 3,000 | 2,000 | 14 | 10 | 8 |
| 1,000 | 700 | 8 | 6 | 6 |
| 100 | 300 | 2 | 3 | 4 |

- **強化石**：装備強化の基本素材。
- **成長のペット箱**：ペット育成用。
- **突破石の欠片（唯一）**：唯一等級装備の突破（Amp）用素材。
- **覚醒の刻印箱**：魔石（マナストーン）または霊石（ソウルストーン）が出る箱。

上位の難易度ほど基礎報酬が増えるため、同じ3回なら到達できる最高難易度で挑むのが有利です。

根拠：[S01] [S04]

## おすすめの使い方

1. **週の後半まで待つ**。週3回は入場した瞬間に消費されるので、週の前半で装備を更新し、リセット直前の火曜〜水曜昼に最も高い難易度へ挑むと報酬効率が良くなります。根拠：[S02]
2. **死亡制限を意識する**。難しい・極限は2回死ぬと失敗扱いになり、回数だけ減ります。初見のダンジョンは1段階下で練習してから上げると安全です。根拠：[S01]
3. **道中の任意目標を取る**。クリア途中にある任意目標を達成すると自分の強化やボス弱体のバフが入ることがあります。根拠：[S05]
4. **全難易度の実績**。各ダンジョンに実績（例「よくも覚醒させたな？」）があり、称号・報酬につながります。根拠：[S04]

## ランキング

覚醒戦はシーズンのランキング対象で、クラス別に順位がつき、シーズン1では順位に応じた称号が配られます。順位表から上位プレイヤーの装備やILを閲覧できます。詳細は [[seasons-and-chapters]] を参照してください。

根拠：[S05]

## よくある質問

**Q. 3回とも失敗したら？**
回数は戻りません。次の水曜16:00まで待つ必要があります。

**Q. サブキャラでも3回できる？**
できます。使命やデイリーダンジョンと違い、覚醒戦の回数はキャラクター単位です。根拠：[S02]

**Q. 回数は翌週に持ち越せる？**
持ち越せません。週3回を使い切るのが基本です。根拠：[S06]
