使命（Duty）は、Lv45になると使えるようになるデイリークエストです。メニューの「使命」タブには **任務（Duty Quest）** と **指令（Command）** の2種類があり、この記事は毎日5件こなす「任務」を扱います。AION2のエンドコンテンツはほとんどが週単位ですが、任務だけは **その日のうちに消化しないと消える** ため、「1日にこれだけはやる」コンテンツとして位置づけられています。

根拠：[S01] [S03] [S04]

## 基本データ

| 項目 | 内容 |
| --- | --- |
| 解放 | Lv45 |
| 件数 | 1日5件 |
| 共有範囲 | **サーバー内のキャラクター全員で共有**（サブでやるとメインの分が減る） |
| 持ち越し | 不可。その日に使わなかった分は消える |
| リセット | 毎日 16:00（JST） |
| 所要時間 | 5件で15〜20分程度 |

根拠：[S01] [S03] [S04]

## 報酬の仕組み（ここが重要）

各任務は **5枠のランダム報酬** を表示します。確率は左から順に下がり、**最初の枠だけが確定**、残りは 50%／33%／25%／10% です。

| 枠 | 入手確率 |
| --- | --- |
| 1枠目 | 100% |
| 2枠目 | 50% |
| 3枠目 | 33% |
| 4枠目 | 25% |
| 5枠目 | 10% |

報酬候補はギーナ、強化石、魂結晶（ペット用）のほか、ヒドゥンキューブの鍵、小さなオードエネルギー、悪夢・覚醒戦・未知の狭間のチケットなどです。**欲しい報酬が1枠目に来ている任務を選ぶ** のが基本戦略です。

根拠：[S01] [S04]

## 再抽選（リフレッシュ）の費用

欲しい報酬が1枠目にない場合、ギーナで任務を引き直せます。費用は回数ごとに上がります。

| 再抽選回数 | 費用（ギーナ） |
| --- | --- |
| 1回目 | 1,000 |
| 2回目 | 2,500 |
| 3回目 | 6,000 |
| 4回目 | 14,000 |
| 5回目 | 35,000 |
| 6回目 | 85,000 |
| 7回目 | 200,000 |

攻略サイトの目安は「85,000で止める」です。それ以上は報酬の価値に見合いません。

根拠：[S01]

## 進め方

1. Lv45になったら、画面のジャーナル（Esc→使命）を開く。
2. 5件の任務の報酬欄を見て、1枠目に欲しいもの（魂結晶・結晶・鍵など）があるものを選ぶ。
3. 1枠目が微妙なら数回だけ再抽選する。
4. 任務の内容は指定モンスターの討伐や採集など、主にベルテロン／アルトガルドのフィールドで完結します。
5. 5件終えたらその日の任務は完了。翌日16:00に更新されます。

根拠：[S01] [S02]

## 注意点

> **注意**：Lv45になる前にマップの「使命」タブを開くと、Lv45到達後も翌日まで任務がロックされたままになる既知の不具合が公式に案内されています。Lv45になるまで使命タブを開かないでください。根拠：[S01]

- 任務と指令は別物です。指令は週単位で、指令書を購入して受けます。詳しくは [[commands-and-command-scrolls]]。
- サーバー共有なので、サブキャラで任務を受けるとメインの5件が減ります。基本はメインで消化しましょう。根拠：[S01] [S04]
- 任務で出てくる「悪夢チケット」「覚醒戦チケット」は、各コンテンツの追加入場に使えます。根拠：[S01]

## どの報酬を狙うべきか

| 段階 | 狙う報酬 |
| --- | --- |
| Lv45直後（IL〜1,400） | ディーヴァニオン結晶、知恵の石、強化石 |
| 装備更新中 | 強化石、オードエネルギー |
| ペット育成中 | 魂結晶 |
| 余裕がある | ヒドゥンキューブの鍵、各種チケット |

迷ったら強化石かオードエネルギーで問題ありません。根拠：[S03] [S04]
