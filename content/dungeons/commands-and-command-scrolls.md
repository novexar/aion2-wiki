指令（Command）は、使命メニューのもう一つの柱で、**週単位** のクエストです。毎日の「任務」と違い、首都の **指令商人（Command Merchant）** から **指令書（Command Scroll）** を買って受注します。報酬の中心は **アビスポイント（Abyss Points）** で、スティグマ関連の購入に必要なため、PvPをしない人でも週に一度は消化したいコンテンツです。

根拠：[S01] [S03]

## 基本データ

| 項目 | 内容 |
| --- | --- |
| 解放 | Lv45 |
| 入手 | 首都の指令商人から指令書を購入 |
| 価格 | 1枚 15,000 ギーナ（首都） |
| 週の上限 | 12件（首都）。アビス下層の指令書を加えると最大 20件 |
| 共有範囲 | サーバー内のキャラクターで共有 |
| 未使用の指令書 | 週のリセットで消えない（持ち越し可） |
| リセット | 毎週水曜 16:00（JST） |

根拠：[S01] [S03]

## 2種類の指令書

| 入手先 | 価格 | 特徴 |
| --- | --- | --- |
| 首都（ベルテロン／アルトガルドの指令商人） | 15,000 ギーナ | 週12件。フィールドの討伐・掃討が中心 |
| アビス下層（混沌のエレシュランタ下層） | 等級ごとに5枚ずつ。上位等級は 150,000 ギーナ | 報酬が多い（平均で 15,000 ギーナの指令書が約2.2、150,000 のものが約3の報酬量） |

アビス下層の指令は「アビス中層：ガルシカン城砦のバーグ勢力を討伐」のように、アビスのエリア内で完結する内容です。PvPが有効なエリアなので、敵対勢力に注意してください。

根拠：[S01] [S02]

## 報酬の仕組み

任務と同じく、報酬は複数枠のランダム表示で、確率は左から下がります。欲しい報酬が1〜2枠目に来るまで再抽選する方法が一般的で、再抽選費用は 1,000〜300,000 ギーナまで段階的に上がります。

根拠：[S01] [S03]

## 指令とフィールドボス

Lv45フィールドボスの一部は指令の討伐対象になっています（例：「東のネイケルを討伐」「血の牙プニンを討伐」「総監督官ヌタを討伐」）。指令を受けた状態で該当ボスを倒すと、ボスのドロップとアビスポイントを同時に狙えます。フィールドボスの一覧は [[field-bosses]] を参照してください。

根拠：[S05]

## 進め方

1. Lv45で首都の指令商人を探し、指令書を必要枚数買う（最初は12枚でよい）。
2. 使命メニューの「指令」タブで内容と報酬枠を確認し、必要なら再抽選する。
3. 週の前半に受けておくと、フィールドボスやアビス滞在のついでに消化できます。
4. アビス下層へ行けるようになったら（目安IL1,000）、アビス版の指令書も検討する。

根拠：[S01] [S04]

## 注意点

- 任務（1日5件）と指令（週12件）は別カウントです。混同して「使命は週に12件」と覚えないようにしてください。根拠：[S04]
- 指令書は買っただけでは進みません。受注後にクエストを達成して報酬を受け取る必要があります。
- 指令の枠もサーバー共有なので、サブキャラで受けるとメインの分が減ります。根拠：[S01]
