砕けたアルカニス（Shattered Arkanis）は、ローンチ時点で遊べる2つ目の超越（Transcendence）です。中ボス2体、キル数ノルマ、最終ボスのTalisra of the Voidの順に進みます。出るアルカナは羊皮紙・鏡・聖杯です。段階とILの共通ルールは [[transcendence-overview]]、もう1つの超越は [[deus-research-base]] です。

根拠：[S01] [S03]

## 入場と報酬

| 項目 | 内容 |
| --- | --- |
| 必要IL | T1：1,600／T2：1,900／T3：2,200／T4：2,500 |
| 人数 | 2〜5人 |
| 報酬キューブ | 40オードエネルギー（全段階） |
| 最終ボスの確定報酬 | シーレンティウム（刻印）100%、魂の書（刻印）100% |
| 抽選 | 増幅石の欠片（唯一）20%、羊皮紙・鏡のアルカナ（魔力型／活力型） |
| 中ボス（Siliator、Ruthilis） | 魂の書40%、増幅石の欠片（唯一）20%、アルカナ |

アルカナの確率は段階が上がるほど高くなります。表の先頭に並ぶアルカナ1種は、最終ボスでT1が21.8%、T2が30.9%、中ボスでT1が7.5%、T2が11.3%です。聖杯は砕けたアルカニスと [[deus-research-base]] の両方で出ます。

## 道順

1. 入場直後に広場の敵30体ほどを倒します（資料により数は食い違う）。
2. 中ボス2体を倒して、残りのノルマを満たします。
3. 精鋭は最後に、群れから離れて倒します。床に残る場が、プレイヤーを傷つけ、敵を回復するためです。
4. 2体目の中ボスへ向かう途中に回転扉の罠があります。余計な敵を引かないでください。
5. 遠距離の敵が多いので、戦いながら横に動きます。

根拠：[S01]

## 最終ボス：Talisra of the Void

### 約2/3と約1/3：白黒の玉と色の盾

1. 「To me, shattered souls!」の声で、Talisraが中央へ行きます。白と黒（紫）の玉が外から流れてきます。
2. 戦闘前に色を決めておきます。各色に2人以上が必要です。近接が一色、遠距離がもう一色、が定番です。
3. 自分の色の玉だけを集めます。他の色には触れません。
4. ボスの近くで散開すると、自分の足元に半径4mの盾ができます。盾が重なると打ち消し合うので、離れます。
5. 武器が光る順（1回目は2回、2回目は3回）に、その色の盾へ入って爆発を受けます。

全員が同じ色を取ると、もう一方の爆発を受ける盾がなく、全滅します。2回目は赤い輪が縮んでくるので、集めながらジャンプします。

根拠：[S01]

### 奇数の槍を壊す

ボスの周囲12mに4本の槍が出ます。黒3本と淡い青（白と呼ばれる）1本です。6秒の表示が出ます。全員で淡い青の槍を殴ります。壊れるのは回数で、ダメージではありません。多段攻撃や通常攻撃が向きます。黒の槍は時間で消えます。

根拠：[S01]

### 屈折の槍（T3・T4）

1人が水晶に閉じ込められ、ほかの全員の後ろに槍が出て、オレンジの矢印が向きます。ボスが話したら、5mほど離れて広がります。槍の軌道が自分を通って水晶に届くように立ち、時間切れの直前に横へ回避します。命中するごとに閉じ込めが約3分の1ずつ短くなり、3回で解放されます。

根拠：[S01]

### 輪のジャンプ

床全体が光り、2秒後に青い輪が外へ、赤い輪が内へ戻ってきます。どちらも少し早めにジャンプします。赤い輪はスタンです。T4では動く火柱が重なります。

### そのほかの攻撃

| 攻撃 | 対処 |
| --- | --- |
| 足元の円→速い320度の薙ぎ払い | ボスの背後だけが安全 |
| 最も遠い人への追尾柱 | 対象は走り続けて離れる。ヒーラーが最遠に立って受ける方法もある |
| 1〜3発の弾、5本の槍の一斉射 | 横へ避ける。5本は近接に危険 |
| ランダムな人への突進（長さ32m、1.2秒予兆） | 経路から出るか背後へ |
| 扇→2連扇 | ブロックするか下がる |
