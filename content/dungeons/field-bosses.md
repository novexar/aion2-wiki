フィールドボスは、ベルテロン、アルトガルド、アビスの「混沌のエレシュランタ下層」といったオープンワールドに現れる強いボスです。誰でも参加でき、固有の装備や戦利品箱が出ます。ただしLv45以降は遠征からも唯一装備が出るので、全部を追う必要はありません。

アビスのボスだけを詳しく知りたい場合は [[abyss-field-bosses]] も参照してください。

## ボスの数

| 場所 | 枠の数 | レベル帯 |
| --- | --- | --- |
| ベルテロン（天族） | 24 | Lv45が20体、Lv48が3体、Lv51が1体 |
| アルトガルド（魔族） | 24 | 同上 |
| 混沌のエレシュランタ下層 | 8 | Lv65 |

合計56枠です。同じ種類のボスでも、天族と魔族で名前が違うものがあります（永遠のガルトゥア／不滅のガルトゥア）。

根拠：[S01]

根拠：[S01]

> **注意**：混沌のエレシュランタ下層はPvPが有効です。敵対陣営と戦闘になる可能性があります。

## アビスの出現スケジュール

通常のフィールドボスの再出現は、前回の討伐からの時間で決まり、サーバーごとにずれていきます。アビスの一部は固定スケジュールです。

| ボス | 出現時間 |
| --- | --- |
| 監視者カイラ（Lv65） | 毎日1:00から180分ごと |
| 守護神将ナフマ（Lv65） | 金曜・日曜の21:00 |
| 執行者タマサ／アグロ／カイラ（Lv65） | 月・木・土の21:30 |

時間は、ゲーム内に表示されるサーバー時間で確認してください。Wikirealm は、月・木・土の21:30に中層（Lv80）のボスも出るとしています。

根拠：[S01] [S03]

## 場所と出現状況の調べ方

1. ワールドマップを開き、探索一覧の「フィールドボス」タブを見る。
2. 出現中のボスと、残りのボスが出るまでの時間が確認できます。
3. 一度でも攻撃すると、そのボスの戦利品箱がもらえます（貢献度が関係）。
4. 取引できないドロップは、補給依頼でアビスポイントに換えられます。

通りがかりのボスは、とりあえず1回殴っておくと得です。

根拠：[S02] [S04]

## 報酬

| 内容 | 備考 |
| --- | --- |
| ボス固有の武器・防具・装身具 | ボスごとに違う。欲しい部位を落とすボスを選ぶ |
| 戦利品箱 | 一撃でも当てれば対象 |
| 名画の残痕、強化・製作の素材 | |
| 実績、タイトル | |
| アビスポイント | 指令や補給依頼の対象になっているボスで |

Lv45のボスの一部は、指令（[[commands-and-command-scrolls]]）の討伐対象です。たとえば東のネイケル、血の牙プニン、総監督官ヌタです。指令を受けてから倒すと、装備とアビスポイントを同時に狙えます。

根拠：[S01] [S02]

## ソロで挑める？

戦闘自体はソロでも参加できますが、報酬には貢献度が関係します。報酬を狙うなら、パーティーで参加するほうが安全です。

根拠：[S02]

## 使い分け

1. 今の装備で一番弱い部位を確認する。
2. その部位を落とすボスが近くに出ていれば参加する。
3. 出ていなければ、遠征や地域のクエストを進める。
4. 待ち続けるより、遭遇したボスを倒すほうが育成効率は良い。

根拠：[S01]
