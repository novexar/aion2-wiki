クラオ洞窟（Krao Cave）は、グローバル版で最初に解放される遠征（Expedition）です。外部の力をはね返す鉱物「クラオ」が埋まった洞窟で、レパル団が作った実験体ベルク（Berk）が最終ボスです。ここで遠征の基本、つまり「報酬キューブ」「スタッガー」「全員で避ける全体攻撃」を覚えられます。

遠征全体の仕組みは [[expeditions-and-odyle]]、消費するオードエネルギーは [[odyle-energy]] を参照してください。

## 入場条件とコスト

| 項目 | 探険（Exploration） | 征服（Conquest） |
| --- | --- | --- |
| 解放 | Lv20・IL200 | Lv45・IL700 |
| 人数 | 1〜5人 | 1〜5人 |
| 報酬キューブのコスト | オードエネルギー20 | オードエネルギー40 |
| 最終ボスの時間制限 | なし | 約5分で凶暴化（エンレイジ） |
| 難易度表示（DB） | 簡単 | 普通 |

入場そのものは無料で、キューブを開けるときだけオードエネルギーを消費します。DBでは受取回数は1回（メンバーシップ時の表記も1）です。週の初期化は水曜16:00（サーバー時間、日本時間と同じ）です。

根拠：[S02] [S03] [S04]

> **韓国版のみ**：韓国・台湾版にある「征服ハード」はグローバル版のローンチ時点では実装されていません。

## 報酬キューブの中身

DB上の最終ボスのキューブは次の通りです（確率が書かれていない項目は100%ではありません）。

| 内容 | 探険 | 征服 |
| --- | --- | --- |
| シーレンティウム（刻印） | 4個 | 7個 |
| ギーナ | 25,000（刻印＝取引不可） | 70,000（取引可） |
| 強化石 | 1,000 | 2,000 |
| 突破石の欠片（唯一） | なし | 1〜2個（20%） |
| 魂の書（刻印） | なし | 1個（確率不明） |
| 装備 | 赤鋼玉・大地・戦線の防具や武器から1つ抽選 | 「破裂」シリーズの武器、ベルクの装身具などを抽選（唯一装備、各1%前後以下） |

探険の防具は、確定報酬（天井）として「赤鋼玉」の防具7部位から選べます。征服の天井は、ベルクのネックレス・イヤリング・リングと装備変更券です。天井の仕組みは [[expedition-reward-selection]] にまとめています。

根拠：[S03] [S04]

## 最終ボス：ベルク

ボスの名札は「Ultimate Berk」です。ここでは4〜5人パーティー向けの要点だけを書きます。

### 50%：スタッガー確認（最重要）

ボスのHPが約50%になると、「Life will shatter, and merge with me!」と叫び、約9秒の詠唱バーが出ます。このとき、普段は効かないスタッガーゲージが開きます。

1. 全員が温存していたスタッガースキル／スティグマを一斉に使う。
2. 天井から落ちる石（オレンジ色の円で予告）から外れる。
3. 9秒以内にゲージを割れないと、パーティー全滅です。

スタッガーとは、ボスのHPバーの下にあるゲージを削って一時的に動きを止める仕組みです。どのクラスにもスタッガー値50ほどの大技が1つあるので、これは50%まで使わずに取っておきます。

根拠：[S01]

### 75%と約25%：石の陰に隠れる

ボスが中央へ跳び、4つの石が出ます。5秒の赤い詠唱の間に、石を挟んでボスの反対側の安全地帯へ入ってください。体が黄色く光れば守られています。石の外にいると即死です。2回目は約25%（25〜33%の幅）で来ます。

根拠：[S01]

### そのほかの攻撃

| 攻撃 | 対処 |
| --- | --- |
| 叩きつけ→右→左のコンボ | ボスの真後ろにいれば当たらない |
| つむじ風（赤い砂ぼこり→約6秒回転） | 狙われた人（多くはタンク）が端をぐるっと回って引き回す。他の人は離れる |
| 突進（往復） | 追わず、戻ってから攻撃 |
| 十字AoE（2連） | 1回目を避けたらすぐ動く |
| 50%以降の落石 | 動き続ける。当たると短くスタンする |

根拠：[S01]

## 中ボス2体

洞窟は途中で2つに分かれ、どちらから倒しても構いません。どちらにも全滅ギミックはありません。

| 中ボス | 注意点 |
| --- | --- |
| Neglected Gadioton（遠距離型） | 地面の大きな円や長い四角。歩くかダッシュで外へ |
| Enhanced Harcon（近接型） | 部屋を横切る狙撃兵の射線の隙間に立つ。投げ円は1回ごとに避ける |

中ボスを倒した分の報酬もキューブに入ります。飛ばすと、その分は受け取れません。

根拠：[S01] [S02]

## ルートと準備

- 最終ボスの手前は落下地帯です。着地前にグライドしないと落下死することがあります。
- 敵の中に混じる赤い玉は、近づくと爆発します。
- スタッガー用スティグマはスロットに入れておく。50%の確認で時間が足りないパーティーほど助かります。

根拠：[S01]

## 初心者向けの使い方

1. Lv20になったら探険で一度クリアして、ギミックに慣れる。
2. 報酬は、IL700になって征服に入れるまでは、オードエネルギーが上限近いとき以外は温存してよい。
3. Lv45でIL700に届いたら、征服の最初の行き先はクラオ洞窟か [[draupnir]] です。どちらも★1で、報酬のギーナや強化石は同じ量です。足りない装備部位が出るほうを選んでください。

根拠：[S02]
