Lv45になると、毎日と毎週のやることが一気に増えます。全部をこなす必要はありませんが、「上限にたまって無駄になる資源」を知っておくと、少ない時間で損をしにくくなります。リセット時刻は日本時間の16:00です。詳しくは [[reset-times]] を参照してください。

## 毎日やること

| やること | 補充 | ためられる量 | 共有単位 |
| --- | --- | --- | --- |
| オードエネルギーを遠征・超越・聖域で消費（1回40） | 3時間ごとに15 | 560（メンバーシップ840） | キャラクター |
| 使命の任務（[[duty-quests]]） | 1日5件 | ためられない | サーバー |
| 悪夢（[[nightmare]]、Lv45から） | 1日2回 | 14回 | キャラクター |
| シューゴフェスタ（[[shugo-festa]]） | 鍵が1日3個 | 12個（会員21個） | サーバー |
| 次元侵攻（[[dimensional-invasion]]） | 報酬の鍵が1日1個 | 7個 | サーバー |
| 出席報酬 | 毎日 | － | － |

オードエネルギー、シューゴフェスタの鍵、悪夢の回数は、上限に達すると補充が止まります。上限の前に使うのが一番の節約です。

使命の任務は、5件それぞれに5つの報酬候補が表示され、最初の枠は確定です。ほかの枠は50%、33%、25%、10%の確率です。欲しい報酬になるまで、ギーナを払って再抽選できます（1,000、2,500、6,000、14,000、35,000、85,000、200,000）。

根拠：[S01] [S02]

> **注意**：Lv45になる前にマップの「使命」タブを開かないでください。既知の不具合で、Lv45に到達した翌日まで使命が解放されなくなる場合があります（NC告知）。

根拠：[S01]

## 毎週やること

| やること | 回数・上限 | 共有単位 |
| --- | --- | --- |
| ルドラ（IL2,800から） | 受取付きの討伐は週1回 | キャラクター |
| 覚醒戦（[[ascension-trial]]） | 週3回 | キャラクター |
| デイリーダンジョン（[[daily-dungeon]]） | 週14回。最上位の報酬にはスコア10,000が必要 | サーバー |
| 遠征・超越の受取 | 週ごとの回数に上限（下記） | サーバー |
| 指令（[[commands-and-command-scrolls]]） | 首都から12件、アビス下層から最大20件 | サーバー |
| 物質変換（オードエネルギー） | キャラ4個、サーバー16個 | 両方 |
| アビスショップの石 | 下級アビス・マナストーン50個、ソウルストーン50個 | － |
| アビスショップの潜在石 | 潜在石：アビス（唯一）20個 | サーバー |
| 未受取のキューブ | 10回 | サーバー |

覚醒戦は、リセット直前の最終日に入ると、その週に自分のILで開いている最も高い難易度で遊べるというコツがあります。遠征・超越は、受け取らずに退出すると未受取の10回を消費し、0回になるとリセットまで征服と超越に入れません。

根拠：[S01] [S02]

## 優先順位の考え方

1. 毎日：使命の任務5件→オードエネルギーを上限の前に消費→鍵と悪夢の回数。
2. 毎週：水曜16:00の前に、遠征・超越の受取、覚醒戦3回、デイリーダンジョン14回を消化。
3. 日課を全部埋めるより、次の装備レベル（IL）条件に足りないものを確認することが重要です。

### Lv45直後の流れ

| 状態 | やること |
| --- | --- |
| 残りの要素あり | エピソード、地域クエスト、封印ダンジョン、駐屯地、神の痕跡を先に回収する |
| IL700〜 | 遠征の征服を始める |
| IL1,000〜 | アビスなどの新しい成長ルートが開く |
| IL1,400〜 | 上位の遠征へ |
| IL1,600〜 | [[transcendence-overview]]（アルカナ集め） |
| IL2,100〜 | 次の遠征段階 |
| IL2,800〜 | ルドラ |

根拠：[S03]

## 見落としやすい点

- 使命や、サーバー共有の回数は、サブキャラが使うとメインの分が減ります。[[server-shared-limits-and-alts]] を参照してください。
- 毎時のイベント（シューゴフェスタ、次元侵攻）は、鍵が上限に近いときだけ参加すれば十分です。
- フィールドボスの近くを通ったら、一度だけ殴っておくと戦利品箱がもらえます（[[field-bosses]]）。
- 通常ギーナは1日100万の取得上限があります。超えると通常モンスターのドロップが止まります。
