バクロンの空中島（Vakron Sky Island、英語版では Bakron とも表記）は、岩の君主バクロンが本拠地にした浮島の遠征（Expedition）です。Lv45でIL（アイテムレベル）1,400になると、探険・征服のどちらも入れます。ウルググ峡谷の次に進む、★2の防具向け遠征です。

共通ルールは [[expeditions-and-odyle]] を参照してください。

## 入場条件とコスト

| 項目 | 探険 | 征服 |
| --- | --- | --- |
| 解放 | Lv45・IL1,400 | Lv45・IL1,400 |
| 人数 | 2〜5人 | 2〜5人 |
| 報酬キューブのコスト | オードエネルギー40 | オードエネルギー40 |
| エンレイジ（凶暴化） | なし | 約5分 |
| 入場に必要なボス | 中ボス2体＋バクロン | バクロンのみ（中ボスは任意） |

週の初期化は水曜16:00（サーバー時間）です。

## 最終ボス：バクロン

名札は「Vakron, Boulder Lord」です。全滅の原因は、茨（Surging Thorn）と、ロードストーン牢獄（Lodestone Prison）の2つです。

### 約60%と約40%：茨の波（Surging Thorn）

1. ボスが中央へ移動し、床が赤くなって7.7秒の詠唱が始まります。
2. 1.7秒おきに輪が3回広がります。1回ごとに、輪が足元へ来る直前にジャンプします。
3. 3つ目のあと、もう一度ジャンプし、スペースをもう一度押してグライドします。空中にいる間に、部屋全体の爆風が通り過ぎます。

輪に当たると20秒間燃え、爆風を地上で受けると2.5秒スタンして、次の攻撃を受けます。テンプラーと剣闘士は無敵スキルで代用できます。

根拠：[S01]

### 約55%と約35%：ロードストーン牢獄

1. 50m以内の全員がボスの足元に引き寄せられ、約2秒拘束されます。
2. 周囲に岩が立ち、5.5秒の詠唱が始まります。岩のうち1つが赤く光ります。
3. 全員で赤い岩を攻撃して割ります（他の岩より少ない回数で壊れます）。
4. 開いたすき間から脱出し、爆発が終わるまで外にいます。

岩の中にいると、最大HPの500%の爆発で全滅します。遠距離でターゲットしづらいときは、設定の「攻撃時にターゲット変更」を使います。探険では、この爆発のダメージが最大HPの70%に下がります。

根拠：[S01]

### トゲの印（Metastasis Explosion）

1人に印が付き、爆発の2秒前に半径7mの円が出ます。印を受けた人は仲間から離れます。円の中にいる人も巻き込まれ、茨に拘束されます。拘束された人は、周りが叩いて解放します。HPが減り続け、次の攻撃も続くため、解放が遅れると死にます。

根拠：[S01]

### そのほかの攻撃

| 攻撃 | 対処 |
| --- | --- |
| 杖を上げて4つの小円が順に落下 | 動き続ける |
| 放射状の線（2連、2回目は1回目のすき間） | 線と線の間に立つ |
| 長さ110mの茨の線（最大HPの40%） | 線から出る |
| 円と輪の同時攻撃 | 円と輪の間に立つ |
| 左右の薙ぎ払い | 背後にいる |

根拠：[S01]

## 中ボス2体

### Tiere

征服では任意です。倒すと毒が取り除かれ、キューブに報酬が加わります。全員が毒（Isolation Zone）を持ち、近くの味方を傷つけるため、散開して戦います。約75%と25%で中央へ跳び、毒を撒きます。花（Detoxifying Rafflesia）をすぐ壊し、その場所に集まって毒を浄化したあと、4回落ちる毒だまりを、全員が同じ方向（時計回りが慣例）へ1歩ずつよけます。

根拠：[S01]

### Thamon

征服では任意です。赤い咆哮（Cry of Life）の間は物理職、紫の咆哮（Mysterious Roar）の間は魔法職が攻撃を止めます。当てるとボスが回復するためです。石化した味方は1回殴れば解放できるので、大技の前に助けます。

| 咆哮 | 止める職 |
| --- | --- |
| 赤 | テンプラー、剣闘士、レンジャー、アサシン |
| 紫 | ソーサラー、クレリック、チャンター、スピリットマスター |

根拠：[S01]

## ルートと準備

- 外では「バクロンの視線」が少しずつ積み重なり、3段階で茨に拘束されます。霧の精霊石を使うか、ボス部屋や風の流れに入ると解除されます。
- 道順は、スタートからまっすぐ進み、右の丘を登ってTiereへ。滑空して岩壁を壊し、風の流れに乗ります。オードの石の精霊を倒すと障壁が消え、Thamonの島へ向かいます。
- Thamonのあと、バクロンの障壁を開きます。空中で風・火・地・水の4属性を、1人1つずつ祭壇へ運びます。祭壇の場所は実行ごとに変わります。5人なら1人余ります。
- 中ボスを倒した分だけ、キューブに報酬が入ります。

根拠：[S01]
