ドラウプニル（Draupnir）は、Lv45になってから最初に挑む遠征（Expedition）です。クラオ洞窟のようなレベリング用の探険がなく、探険も征服もLv45・アイテムレベル（IL）700からです。最終ボスは、アビスをさまよって龍族を超える力を求めるヴォカルマ（名札は Transcendent Bakarma）です。

遠征の共通ルールは [[expeditions-and-odyle]]、★1仲間の [[krao-cave]] も合わせて読むと流れがつかめます。

## 入場条件とコスト

| 項目 | 探険 | 征服 |
| --- | --- | --- |
| 解放 | Lv45・IL700 | Lv45・IL700 |
| 人数 | 1〜5人 | 1〜5人 |
| 報酬キューブのコスト | オードエネルギー40 | オードエネルギー40 |
| 最終ボスの時間制限 | なし | 約5分で凶暴化 |
| 入口 | 自分の陣営の拠点マップ（ベルテロンまたはアルトガルド） | 同左 |

探険でも40オードかかる点が、クラオ洞窟の探険（20）と違います。入場は無料です。

根拠：[S01] [S02] [S03] [S04]

## 報酬キューブの中身

| 内容 | 探険 | 征服 |
| --- | --- | --- |
| ギーナ | 40,000（刻印） | 70,000（取引可） |
| 強化石 | 1,300 | 2,000 |
| シーレンティウム（刻印） | 4個 | 7個 |
| 突破石の欠片（唯一） | なし | 1〜2個（20%） |
| 魂の書（刻印） | 1個（確率不明） | 1個（確率不明） |
| 天井（確定報酬） | ヴォカルマの防具7部位から選択 | 装備変更券：ドラウプニル、ヴォカルマの防具 |

征服の装備抽選は、「ヴォカルマの」防具・武器から1つ引きます。防具は部位ごとに確率が違い、DBではプレート約0.6%、マント約1.3%などです。探険のキューブ3回受取で防具1部位を確定させる方法は [[expedition-reward-selection]] を参照してください。

根拠：[S03] [S04]

## 最終ボス：ヴォカルマ

HPが約70%と約30%のとき、「波を跳んで本体へ近づき、スタッガーを割る」チェックが入ります。割れないと全滅です。

### 70%と30%：波とスタッガー

1. ボスが遠くへ泳ぎ、中央へ戻ってくると画面が暗くなります。
2. 赤い輪（ボスの周囲15〜20m）の外から、水の輪が一定のリズムで広がります。
3. 輪が来るたびに、少し早めにジャンプして避けます。ジャンプ3回とダッシュ（戦闘を外れるとスプリントになる）で届く目安です。
4. 赤い輪の内側は波が届きません。ここで温存したスタッガースキルとスティグマを一斉に使い、制限時間（約16〜18秒）内にゲージを割ります。

波に当たると最大HPの45%を失い、移動が5秒遅くなります。3回当たると満タンでも倒れます。剣闘士（グラディエイター）とテンプラーは、無敵スキルで波を無視して突っ込めます。30%の2回目では、事前に出現する渦（水柱）に吸い込まれないよう、位置を覚えて迂回します。

根拠：[S01]

### そのほかの攻撃

| 攻撃 | 対処 |
| --- | --- |
| 前方ブレス（2〜3連、右→左） | タンクが正面で受け、他は背後 |
| 宝玉の放射（ボスから放射状） | 背後か、すき間が広い遠くへ |
| 跳躍→波（2回） | 波をジャンプ。1発なら耐えられる |
| 潜行 | 潜る直前の顔の向きに出てくる |
| スタッガー後の噴出（8連） | 散開して動き続け、他人とすれ違わない |
| 全周に近い横なぎ | 予兆なし。動作を覚える |

## 中ボス2体

| 中ボス | 注意点 |
| --- | --- |
| Predator Saraswati | 飛びついて青い毒だまりを残す。踏まない。小円で拘束されたあと、扇状に毒を吐き、当たると3秒虫になる |
| Phantasmal Lakshmi | ダメージ反射（約8秒）中は攻撃を止める。HP50%から侍女を呼ぶので先に倒す。スタッガーで反射が消える |

どちらも難しくありません。中ボスを飛ばすと、キューブには最終ボス分しか入りません。

根拠：[S01]

## ルートと準備

1. 入口の装置を使い、穴へ飛び降りてグライドで左へ。最初の中ボスのそばに着きます。
2. 復活地点を登録してから、上昇気流で2体目の中ボスへ進みます。
3. 2体目のあとで戻り、風の流れに乗って最終エリアへ。
4. ボス部屋の前で復活地点を登録します。ボスに倒されるとここで復活します。
5. Petty Officer Akvarを倒すとボスへのポータルが開きます。

スタッガー用のスティグマは、ボス戦まで使わずにとっておきます。
