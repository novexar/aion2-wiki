デイリーダンジョン（Daily Dungeon）は、Lv30から入れる短時間のソロ用インスタンスです。名前は「デイリー」ですが、グローバル版では **週14回** の枠を自由に消化する仕組みで、毎日1回ずつ入る必要はありません。報酬は装備強化に必須の **強化石** で、Lv45になった直後に不足しがちな素材をまとめて確保できます。

根拠：[S01] [S03] [S05]

## グローバル版で遊べるのは1種類

| ダンジョン | グローバル版 | 主な報酬 |
| --- | --- | --- |
| ディーヴァ生体研究基地（Daeva Bio-Research Base） | **あり** | 強化石 |
| オディウム貯蔵所（Odium Storage） | なし | ペット素材（韓国版） |
| クロパキンの秘密の保管所（Crobahki's Secret Depository） | なし | ギーナ（韓国版） |

グローバル版データベース（2.0.5.0）の「デイリー ダンジョン」カテゴリに登録されているのは「ディーヴァ生体研究基地」のみです。Aion 2 Maps も同じ結論で、Launch Scale Test の時点でも1種だけが確認されています。

> **韓国版のみ**：オディウム貯蔵所（2025年12月24日追加）とクロパキンの秘密の保管所（2026年5月13日追加）は韓国・台湾版のコンテンツです。日本語Wikiの一部には3種類すべてが記載されていますが、グローバル版では選べません。根拠：[S02] [S04] [S05]

## 基本データ

| 項目 | 内容 |
| --- | --- |
| 推奨レベル | 30 |
| 人数 | 1人 |
| 回数 | 週14回。**同じサーバーのキャラクター全員で共有** |
| リセット | 毎週水曜 16:00（JST） |
| 入場方法 | 「未知の狭間（Unknown Fissure）」から入場（チケット制） |
| 最高報酬の条件 | スコア 10,000 |

根拠：[S01] [S03] [S06]

## 報酬表（スコア別）

スコアが高いほど強化石が増えます。データベースの値は次のとおりです（天族・魔族とも同じ）。

| スコア | 強化石 |
| --- | --- |
| 10,000 | 10,000 |
| 9,000 | 9,000 |
| 8,000 | 8,200 |
| 7,000 | 7,600 |
| 6,000 | 7,000 |
| 5,000 | 6,400 |
| 4,000 | 5,800 |
| 3,000 | 5,200 |
| 2,000 | 4,600 |
| 1,000 | 4,000 |
| 500 | 3,800 |
| 100 | 3,000 |

最低の100点でも3,000個、満点で10,000個です。14回すべて満点なら週に140,000個の強化石になります。

根拠：[S01]

## 遊び方

1. Lv30以上で「未知の狭間」のポータル（またはメニューのデイリーダンジョン）を開く。
2. ディーヴァ生体研究基地を選んで入場する。
3. 制限時間内にモンスター（クラオ生体兵器・ドラナ生体兵器・修羅生体兵器など）を倒し、スコアを稼ぐ。赤い玉や精鋭モンスターを逃さないことが実績の条件にもなっています。
4. 終了後にスコアに応じた強化石を受け取る。

出現する敵は Lv30 なので、Lv45のキャラクターなら短時間で満点を狙えます。

根拠：[S01]

## 攻略のコツ

- **メインキャラで消化する**。回数はサーバー共有なので、サブで使うとメインの分が減ります。強化石は入手したキャラクターでしか使えない（刻印）ため、強化したいキャラで回るのが基本です。根拠：[S03] [S05]
- **週末にまとめても良い**。回数は週単位なので、平日に時間がなければ土日に14回まとめて消化できます。根拠：[S05]
- **週の初めに回す必要はない**が、水曜16:00のリセットまでに使い切らないと回数は消えます。根拠：[S07]

## 関連する実績

ディーヴァ生体研究基地には「毎日出席チェック」「毎日やっていれば強くなるよ」「未知の狭間の支配者」などの実績が設定されています。周回していれば自然に進みます。
