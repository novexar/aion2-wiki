> **要確認**：基本情報（最大128人、創設費用100,000ギーナ、レギオンLv1〜20、常時バフの数値、階級）は redfreshet と Aion 2 Maps の2資料で一致しています。創設できるレベルは資料で食い違い（redfreshet はLv16前後、Aion 2 Maps は「Lv10以上」でアジア版のクライアント由来）、実際の解放はゲーム内で確認してください。レギオン専用コンテンツの方針は AION2 Times（韓国版情報が中心）だけが根拠です。

レギオン（Legion）は、AION2のギルドにあたるプレイヤー組織です。入らなくても、ストーリーやダンジョンは進められ、もらえる報酬にも差はありません。ただし、長く遊ぶなら、活動時間の合う仲間を見つけやすくなるメリットがあります。

## 基本情報

| 項目 | 内容 |
| --- | --- |
| 解放 | Lv16前後。クエスト「新たな決意」の完了後 |
| 最大人数 | 128人 |
| 単位 | サーバー・陣営ごと。天族と魔族が同じレギオンに入ることはできない |
| 創設費用 | 100,000ギーナ（Aion 2 Maps も同額。創設可能レベルは「Lv10以上」と記載があり、資料により食い違う） |
| レギオンLv | 1〜20（グローバル版） |

遠征や超越などのダンジョンは、部屋を作ればほかのサーバーや別の種族とも入れます。レギオンは、サーバーと種族で分かれたままです。

根拠：[S01] [S02] [S04]

## 入り方・作り方

1. レギオンメニューを開く。
2. 「おすすめ」または名前の検索で探す（おすすめは最大100件）。
3. 人数、紹介文、加入条件を確認する。
4. 加入または加入申請を送る（承認制の場合は軍団長・管理メンバーの承認を待つ）。

自分で作る場合は、名前（1〜12文字、変更不可）、紹介文、加入方法を決めます。加入方法は「即時」「承認」「パスワード」から選べます。特にこだわりがなければ、最初に100,000ギーナを払って作る必要はありません。

階級は、軍団長（1名）、エリート将校（管理役、4名）、軍団兵（メンバー）の3つです（仮訳）。各階級の権限は変更できます。

根拠：[S01] [S02] [S04]

## 常時バフ（グローバル版）

| レギオンLv | 主なボーナス |
| --- | --- |
| 1 | 経験値獲得量+1% |
| 5 | 経験値+2%、HP+16、MP+16、回避・命中・攻撃力+1 |
| 10 | 経験値+3%、HP+36、MP+36、回避・命中・攻撃力+2、防御力+2 |
| 15 | 経験値+3%、HP+56、MP+56、回避・命中+4、攻撃力・防御力+3 |
| 20 | 経験値+3%、HP+80、MP+70、回避・命中+5、攻撃力・防御力+4 |

上昇量は大きくありません。バフだけで選ぶより、活動時間、募集しているコンテンツ、コミュニケーションの方針を優先するほうが失敗しにくいです。

根拠：[S01] [S04]

## ショップと寄付

レギオンショップには、基本的な回復系の消耗品が3種類（250、630、1,000ギーナ）しかありません。同系統の品は一般のショップでも買えます。毎日ギーナを寄付してレギオン通貨を稼ぐ、という旧作や韓国版の過去情報のような日課は、2026年10月7日時点のグローバル版では確認できません。

根拠：[S01]

## アジトと飛行艇

アジト（Agit、Hideout）は、レギオンのメンバーが集まる専用の拠点です。

| 項目 | 内容 |
| --- | --- |
| 設備 | 製作商人と製作台（鍛冶・防具・細工・錬金・料理）、倉庫管理人、物質変換商人、案山子（ダメージ計測用の的） |
| できること | 決闘、アジトの飾り付け、倉庫の預け・引き出し。アジトからダンジョンに入ると、出たときにアジトへ戻る |
| 行き方 | 飛行艇、または「全体メニュー」→「レギオン」→「アジト」。雑貨商店のアジト帰還スクロールでも入れる |
| レンタル | 100万ギーナで30日間。Aion 2 Maps のデータマインでは、レギオンLv1から借りられ、天族側はベルテロン、魔族側はアルトガルドにある。借りるには専用の権限が必要（韓国版の先行情報とも一致） |

データベースには、「ベルテロン／アルトガルド／エルテネン／モルヘイム レギオンの飛行艇」の4つが、レギオンのコンテンツとして登録されています。内容は書かれていません。エルテネンとモルヘイムは、グローバル版でまだ閉鎖されている地域です。

> **韓国版のみ**：エルテネン、モルヘイムのアジトと、そこへ行くための条件（Lv45・IL3,300以上・戦闘力27万以上）は、グローバル版には当てはまりません。[[content-not-in-global]] を参照してください。

根拠：[S02] [S03] [S04]

## レギオン向けコンテンツの現状

AION2 Times によると、開発側はレギオン向けのコンテンツを今は最小限にしています。集まりに参加しないといけない作りを負担に感じる人がいるためです。レギオン同士のPvPや、レギオン専用の製作を追加する計画はないとされています。

根拠：[S02]

## 選び方

初心者向けには、「初心者歓迎」「無言OK」「PvE中心」など、参加しやすい条件を優先して構いません。確認する点は次の通りです。

| 確認項目 | 見るポイント |
| --- | --- |
| 活動時間 | 自分のログイン時間と重なるか |
| 使用言語 | 日本語で話せるか |
| PvE/PvP | 遊びたい内容に合うか |
| 加入条件 | 戦闘力やログイン頻度の条件 |
| 雰囲気 | 無言OK、Discord必須など |
