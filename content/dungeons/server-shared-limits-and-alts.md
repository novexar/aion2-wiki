AION2では、サブキャラを増やしても報酬が単純に2倍、3倍にはなりません。「キャラクターごとの資源」と「同じサーバーのキャラで共有される制限」が混ざっているためです。サブを作る前に、どちらに当たるかを知っておくと、無駄な育成を避けられます。

## 共有か、キャラ別か

| 項目 | 単位 |
| --- | --- |
| オードエネルギー（自然回復） | キャラクター |
| 悪夢の挑戦回数 | キャラクター |
| 覚醒戦（週3回） | キャラクター |
| ルドラの受取（週1回） | キャラクター |
| 使命の任務（1日5件） | サーバー |
| シューゴフェスタの鍵 | サーバー |
| 次元侵攻の鍵 | サーバー |
| デイリーダンジョン（週14回） | サーバー |
| 指令（週12件） | サーバー |
| 遠征・超越の未受取回数（週10回） | サーバー |
| 物質変換 | キャラ4個、サーバー16個 |
| 倉庫 | サーバー倉庫を同サーバーのキャラで利用 |

つまり、サブが使命を5件こなすと、メインの使命は残りません。逆に、サブはオードエネルギーと悪夢の回数を、自分の分として持っています。

## 通常ギーナの減衰

遠征・超越の受取で出る「通常ギーナ」（取引可）は、サーバーの週の受取回数が増えるにつれ、減ります。

| 受取数（サーバー全体・週） | 支払い率 |
| --- | --- |
| 征服 最初の84回／超越 最初の56回 | 満額 |
| そのあと | 80%、60%、40%、20%と段階的に減る |
| 探険 最初の7回 | 満額。その次は60%、20%。22回目以降は0 |

1キャラが1週間にためられるオードエネルギーは約21回分の受取です。そのため、4キャラ目までは満額でも、5キャラ目から減るという目安になります。これは計算による推定です。取引できないギーナ（刻印）は減りません。ルドラのギーナは減衰しません。

根拠：[S01]

> **資料間の食い違い**：Wikirealm のクライアントのチケット表は、征服の受取を「1日2回、最大14回ためられる（ダンジョンごと）」としています。84回は6つの遠征の14回ずつの合計に相当し、aion2maps の数字と矛盾しません。ただし、この表にはグローバル版にない韓国版のダンジョンも混ざっているので、鵜呑みにしないでください。

根拠：[S01] [S04]

## サブキャラの使い道

サブキャラの最大のメリットは、キャラごとのオードエネルギーです。

1. メインでオードエネルギーを使い切る。
2. サブに切り替える。
3. サブのオードエネルギーで遠征や超越の受取を行う。

サブが稼げるのは、メインに渡せる取引可能なギーナと素材です。1回の征服の受取は、取引可能なギーナを次のように出します。

| 遠征 | 取引可能なギーナ（1回の受取） |
| --- | --- |
| クラオ洞窟・ドラウプニル（★1） | 200,000 |
| ウルググ峡谷・バクロンの空中島（★2） | 300,000 |
| 炎の神殿・獰猛な角岩窟（★3） | 400,000 |
| 超越 | 300,000〜480,000 |

（ボス3体分を合わせた数字です。）

根拠：[S01] [S03]

## メインへ渡せるもの、渡せないもの

| 渡せる | 渡せない |
| --- | --- |
| 取引可能なギーナ、素材（サーバー倉庫経由） | ダンジョン装備（拾った時点で帰属） |
| | 刻印（バウンド）のギーナ、ダエヴァニオンの結晶、知恵の石、購入したオードエネルギー、装備変更券 |

アカウントをまたぐ移動は、マーケットだけが経路です。マーケットでの取引にはメンバーシップが必要で、別サーバーとのアイテム取引は、NCが現金取引（RMT）として扱うと説明されています。

通常ギーナには、1日100万の取得上限があります。超えると、通常モンスターが落とすアイテムが出なくなります（野良フィールドのパーティーでは全員、ダンジョンのパーティーでは自分だけ）。

根拠：[S01] [S02]

## 何体作るべきか（目安）

| 状況 | 目安 |
| --- | --- |
| Lv45になったばかり | メインのみ〜サブ1体 |
| メインの日課・週課が安定した | メイン＋サブ1体 |
| サブ1体分の資源まで消化できる | サブ2体を検討 |
| 毎週かなり長く遊ぶ | サブ3体以上も候補 |

キャラクタースロットは、ローンチ時点で4つです。追加の4つは、1つにつき1,000クナ（Quna）です。重要なのは数ではなく、作ったキャラの資源を実際に使い切れるかです。

## 育て方

1. サブは、まずLv22前後まで進める。覚醒や遠征など主要システムが順に使えるようになります。
2. 本格的に使うサブは、最終的にLv45まで育てる。Lv45になると、サブ自身のオードエネルギーを使える場面が増えます。
3. サブの装備は、必要なコンテンツを回れるところで止める。メインと同じだけ強化にギーナと素材を入れると、サブのメリットが小さくなります。
