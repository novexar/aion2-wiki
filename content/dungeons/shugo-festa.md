> **注意**：鍵の補充数と上限は、資料によって数字が違います。複数の資料（aion2maps、aion2.run、Wikirealm のイベント表、NCの告知）が一致する「1日3個、上限12個（会員21個）」を採用し、ずれは本文に書いています。ゲーム内の鍵の表示を優先してください。

シューゴフェスタ（Shugo Festa、シューゴ・フェスティバルとも）は、毎時0分に始まる順位制のミニゲーム大会です。レースやかくれんぼなどから好きなゲームを選んで参加し、順位に応じて報酬が出ます。難しくありませんが、毎日の日課に組み込む価値があるコンテンツです。

## 基本情報

| 項目 | 内容 |
| --- | --- |
| 開催 | 毎時0分（1日24回） |
| 参加条件 | 報酬の鍵（Reward Key）を持っていること。終了後に鍵でカードを引き、順位が高いほど枚数が増える（aion2.run） |
| ゲーム数 | グローバル版では回転制の9種（資料により10種とも） |
| 鍵の補充 | 毎日、日次リセット時（日本時間16:00）に補充 |
| 共有単位 | サーバー（キャラクター別ではない） |

ゲームの例は、輪をくぐるレース、宝探し、どんどん高く跳ぶゲーム、風船撃ち、床のタイルの記憶ゲーム、罠を飛び越えるゲーム、変身するかくれんぼ、シューゴの商人を守る防衛戦です。

根拠：[S01] [S02] [S03]

## 鍵の数

| 項目 | 数 | 根拠 |
| --- | --- | --- |
| 1日の補充（無料） | 3個 | aion2maps のゲームデータ、aion2.run、Wikirealm のイベント表 |
| 所持上限 | 12個 | NCの告知（2026-09-28）、Wikirealm |
| 所持上限（メンバーシップ） | 21個 | NCの告知（2026-09-28）、Wikirealm |

上限に達すると補充が止まり、その分は無駄になります。上限が12個なら、4日休むと満タンです。aion2.run も、1日3個・12個保持（会員21個）と説明しています。

> **資料間の食い違い**：Wikirealm の別の表（チケット規則）は「1日4個、上限28個（会員32個）」と書いています。ある配信者のチェックリストは「1日2個、上限14個」としています。韓国版では「無料1個／会員2個、上限14個」でした。グローバル版のNC告知にある12／21を採用しています。

根拠：[S01] [S02] [S03] [S06]

## 報酬

| 報酬 | 内容 |
| --- | --- |
| 百年人参の証（Centuryroot Token） | フェスタ商店の通貨。ミニゲームで得る |
| 順位報酬 | 装備、素材など。順位が高いほど良い |
| アビスポイント | ミニゲームで得られる（配信者の報告） |
| デーヴァパスEXP | 参加するとパスEXPが入る。週の上限は1キャラ50,000 |

百年人参の証では、フェスタ商店（49品目）で次を交換できます。

- スティグマの欠片、Radiant Odyle、パンテオンの絵（テスト版の商店）
- 知恵の石、ペットの魂の結晶、ダエヴァニオンの結晶、魂の書、翼、ペット、パンテオン飾り、衣装（配信者の紹介）

百年人参の証は、イベントの期間のためだけの通貨で、期限があります。商店の品揃えがローンチ版で変わっていないかは、ゲーム内で確認してください。

根拠：[S01] [S03] [S04]

## 日課への組み込み方

1. 鍵が上限12個に近づく前に、参加して消費する。
2. 回数を稼ぐより、どのゲームでも一度ずつ遊んで実績を埋める。ある配信者は各ゲーム3回以上を勧めています。
3. 毎時0分は、手を止めて参加することになります。参加の事前予約はありません。
4. 鍵が少ないうちは、ルールを覚えやすいゲームを優先して選ぶ。

根拠：[S01]

## ローンチ関連

ローンチ記念の「シューゴ出席」（7日間）では、日ごとにギーナ、魂の結晶、百年人参の証（5,000個）、夢幻の破片、アビスポイントが出ます（すべて取引不可）。
