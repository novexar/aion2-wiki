シーズンは、ランキング付きコンテンツの開始日と終了日を決める期間です。ランクは期間中に積み上がり、終了時に報酬が出ます。グローバル版は2026年9月30日に始まったシーズン1の途中で、レベルや装備はシーズンが終わっても消えません。

## シーズン1の日程

| 項目 | 内容 |
| --- | --- |
| 開始 | 2026年9月30日（日次リセット時刻） |
| 終了 | 2026年12月16日の日次リセット時刻（07:00 UTC＝日本時間16:00） |
| 次のシーズン | シーズン2が12月16日〜3月10日と、クライアントのシーズン表にある（Wikirealm） |
| ディーヴァパス | 12月15日のメンテナンスまで（別の期限） |

太平洋時間では、12月15日の23:00に終わります。NCは、シーズンの長さを「約3か月」と説明しています。

> **注意**：ディーヴァパス（シーズン1）の終了は12月15日のメンテナンス、ランキングは12月16日のリセット時刻と、資料によって日付が違います。それぞれ別の期限として扱ってください。

根拠：[S01] [S02] [S03]

## ランキング対象

| コンテンツ | 備考 |
| --- | --- |
| 悪夢（[[nightmare]]） | ボス構成はシーズンごとに入れ替わる |
| 超越（[[transcendence-overview]]） | デウス研究基地と砕けたアルカニス |
| 覚醒戦（[[ascension-trial]]） | ダンジョンは毎週入れ替わる |
| アビス、両方の闘技場 | アビスは軍階級で表示 |

制圧（Subjugation）は、シーズン1ではランクされません。順位はクラスごとに、1時間ごとに更新されます。

根拠：[S01]

## ランクと報酬

等級は、クラス内の順位とポイントの両方で決まります。上から、チャレンジャー1〜3、グランドマスター、マスター、ダイヤモンド、プラチナ、ゴールド、シルバー、ブロンズ、アイアンです。悪夢では、チャレンジャー1が「クラス1位かつ115万ポイント以上」、ブロンズが「601〜1,000位かつ1万ポイント」で、アイアンには報酬がありません。

| コンテンツ | 等級ごとの報酬 | チャレンジャー1〜プラチナの追加 |
| --- | --- | --- |
| 悪夢 | シーズン1の称号 | ヘルムのスキン |
| 超越 | シーズン1の称号 | ヘルムのスキン |
| アビス、闘技場、覚醒戦 | シーズン1の称号 | なし |

報酬が出るのは各クラスの上位1,000人です。報酬は次のシーズンに入って、そのコンテンツを最初に開いたときに届きます。誓いのコイン、パンテオンの飾り、翼は、シーズン1の順位報酬には含まれません。アビスの順位バフは唯一のランキングバフで、最大でPvPダメージ5%増などです。

根拠：[S01]

## シーズン終了で消えるもの、続くもの

| 終了で消える・変わる | 続く |
| --- | --- |
| ランキング（先に報酬が出る） | レベル、装備、強化（推定） |
| 悪夢のボス構成 | アビスポイント |
| 誓いのコイン（シーズン商店の通貨） | 夢幻の破片（悪夢） |
| ディーヴァパス商店のコイン | 百年人参の証（シューゴフェスタ） |
| オードエネルギーと入場チケットが新しく配布（アジア版の事例） | |
| アルカナの変換が変わる、またはリセット | |

誓いのコインとディーヴァパスのコインは、シーズンの終了とともに削除されます。終了前に使ってください。オードエネルギーは、韓国・台湾版では終了時に失効して新しい分が配られます。グローバル版で実際にそうなるかは未確認です。

根拠：[S01]

## チャプターとは

チャプターは、シーズンと同じ仕組みの別名と、aion2mapsは説明しています。一方、NCは英語ではどちらも定義していません。韓国・台湾版では、2026年1月にシーズン2が始まり、7月1日の大型更新が「Chapter 1：砂と霜の地」と呼ばれました。クリエイターは、2026年4月8日をシーズン3、Chapter 1をシーズン4と数えます。

グローバル版は、韓国版より約1年遅れの内容で動き、NCは新しいシーズンを約3か月ごとにすると説明しています。韓国版のChapter 1の内容（レベル50、拳星など）が入る時期は未発表です。[[content-not-in-global]] を参照してください。

根拠：[S01] [S02]
