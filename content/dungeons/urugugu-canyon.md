ウルググ峡谷（Urugugu Canyon）は、ウルググ族が占領した峡谷にある遠征（Expedition）です。レベリング中にはLv28・IL300から探険で入れ、Lv45では征服の中級（★2）としてIL1,400から入ります。最終ボスは、聖なる鳥アウルドール（Divine Auldor）です。

共通ルールは [[expeditions-and-odyle]]、前後の段階は [[krao-cave]] と [[fire-temple]] を参照してください。

## 入場条件とコスト

| 項目 | 探険 | 征服 |
| --- | --- | --- |
| 解放 | Lv28・IL300 | Lv45・IL1,400 |
| 人数 | 2〜5人（征服のDB表記） | 2〜5人 |
| 報酬キューブのコスト | オードエネルギー20 | オードエネルギー40 |
| 最終ボスの時間制限 | なし | 約5分で凶暴化 |
| 受取回数（DB） | 1 | 1 |

週の初期化は水曜16:00（サーバー時間）です。入場は無料で、キューブを開けるときだけオードエネルギーを使います。

根拠：[S02] [S03] [S04]

## 報酬キューブの中身

| 内容 | 探険 | 征服 |
| --- | --- | --- |
| ギーナ | 30,000（刻印） | 100,000（取引可） |
| 強化石 | 1,100 | 2,000 |
| シーレンティウム（刻印） | 4個 | 7個 |
| 突破石の欠片（唯一） | なし | 1〜4個（20%） |
| 魂の書（刻印） | なし | 1個（確率不明） |
| 天井（確定報酬） | 「信仰」の防具7部位から選択 | 装備変更券：ウルググ峡谷、アウルラムスのネックレス／イヤリング／リング |
| 抽選される装備 | 「信仰」シリーズ | 「アウルラムス」シリーズ（唯一）ほか |
| 特別ドロップ | なし | 神聖なアウルドールの仮面（外形：ヘルム、2%） |

装備の抽選は、プールから1回引く方式です。アウルラムスの武器は1つ0.43%、装身具は1.0〜1.7%と低めで、確定報酬（天井）まで積み上げる考え方になります。仕組みは [[expedition-reward-selection]] を参照してください。

根拠：[S03] [S04]

## 最終ボス：アウルドール

最大の敗因は時間切れです。約5分でボスが凶暴化するため、竜巻に捕まって時間を失わない立ち回りが重要です。

### 約75%と約30%：ソーク（全員で受ける）

1. ボスが中央へ飛び、10秒の詠唱が始まります。竜巻が横切ります。
2. 最後の5秒、1人に赤い円と内向きの黄色い矢印が出ます。
3. 全員がその円に入り、ダメージを分け合います。
4. 竜巻に当たらないように円へ向かいます（竜巻に当たると拘束されます）。

マークされた人が1人で避けると、その人は死亡します。ダメージは人数で割られ、1人なら最大HPの5倍、2人で70%ずつ、3人で30%、4〜5人で10%ずつです。30%のときは、中央から20m以上離れた場所が燃える床になるので、中央で戦います。

根拠：[S01]

### 竜巻の掴み

オレンジの帯が出ると、1人を狙って3本、次に5本の竜巻が扇状に伸びます。近接はボスの背後に、遠距離は遠くに離れるとすき間が広がります。捕まったら、すぐにクラウドコントロール解除キー（PCではスペース）を押します。解除できないと、掴まれて叩きつけられ、周囲を巻き込む輪が広がります。

根拠：[S01]

### そのほかの攻撃

| 攻撃 | 対処 |
| --- | --- |
| 開幕の跳躍叩きつけ→太い帯 | 両方避ける |
| 25mの突進（タンクへ） | タンクが横へ避け、燃える跡からボスを移動 |
| 羽根を散らす回転 | 近接は回転より羽根を受けるほうがまし |

根拠：[S01]

## 中ボス2体

どちらから倒しても構いません。

| 中ボス | 注意点 |
| --- | --- |
| Guardian Captain Raur（盾型） | 盾を構える約4秒間は攻撃を止める。反射されて攻撃力が上がる（最大5回）。直後の大技から離れる。突進は予兆なしでスタン |
| Judge Urahum（毒型） | 攻撃を受けると3秒後に足元へ毒だまり。タンクが外へ引き出す。3段の踏みつけ（6・12・17m）に注意 |

根拠：[S01]

## ルートと準備

- 2体の中ボスのあと、風を操る敵を倒すと風の流れが開きます。乗ってボスへ進みます。
- ボス前のチェックポイントで復活地点を登録します。
- 攻撃スクロールと料理（食事バフ）を用意します。捕まるたびに与ダメージの時間を失います。
- 探険にはエンレイジがありません。ギミックを覚える練習に使えます。

根拠：[S01]
