日本から遊ぶ人が最初に迷うのがサーバー選びです。結論を先に書くと、**公式に「日本人向けサーバー」はありません**。リージョンはアジア（ASIA）を選び、あとは「誰と遊ぶか」で決めます。決め方の基本と、よくある勘違いをまとめます。

## 状況別の選び方

| あなたの状況 | 選び方 |
| --- | --- |
| 友人と遊ぶ | 友人と同じリージョン・陣営・サーバー |
| 入りたいレギオンがある | そのレギオンが活動しているサーバー |
| ソロ中心 | 今作成できる「推奨」表示のサーバー |
| 混雑を避けたい | 新しく追加されたサーバーも候補 |
| アーリーアクセスから遊んでいる | 今のサーバーを続ける |

根拠：[S01] [S02]

## 決める順番

1. リージョンはアジア（ASIA）を選ぶ。日本にサーバーがあるため、遅延が少ないと考えられます。
2. 天族か魔族かを決める。ここは後から変えられません。
3. その陣営のサーバーから、友人かレギオンの居場所、なければ「推奨」を選ぶ。

作成画面ではリージョン、種族、サーバーの順に選びます。友人に伝えるときは「ASIA・天族・カイジネル」のように3つを揃えて確認してください。サーバー名だけでは、別リージョンの同名サーバーと区別できません。

根拠：[S01] [S02]

→ [[races-elyos-asmodian]]

## 「日本人が多いサーバー」という情報は当てにしない

公式は、サーバーごとの人口や日本人比率を発表していません。「シエルが日本人サーバー」「カイジネルが一番人気」といった話だけで決めるのはおすすめできません。日本人同士で遊びたいなら、サーバー名よりも、入りたいレギオンやコミュニティの活動先を確認するほうが確実です。

根拠：[S01]

→ [[legion]]

## アジアのサーバー一覧（2026年10月7日時点）

天族と魔族のサーバーは1対1で組み合わされています。

| 天族 | 魔族 | 区分 |
| --- | --- | --- |
| シエル | イズラフェル | アーリーアクセス |
| ネザカン | ジケル | アーリーアクセス |
| バイゼル | トリニエル | アーリーアクセス |
| カイジネル | ルミエル | 正式サービス |
| ユスティエル | マルクタン | 正式サービス |
| アリエル | アスフェル | 正式サービス |
| フレギオン | エレスギガル | 正式（10月5日追加） |
| ミスランテイダ | ベリトラ | 正式（10月5日追加） |

アーリーアクセス側のサーバーも、正式サービス開始後は誰でも選べます。ただし、すでに育成とサーバー内の経済が進んでいます。特に理由がなければ正式サービス側から選び、友人やレギオンがアーリーアクセス側にいるならそちらを選ぶ、という判断で足ります。

根拠：[S01] [S02] [S03]

## 新規なら追加サーバーも候補

正式サービス開始直後に2組が追加されました。人口の多いサーバーは人を見つけやすい反面、待機列や作成制限が出ることがあります。ソロで始めるなら、人口最大のサーバーを探すより、ゲーム内で今入れるサーバーを選ぶほうが現実的です。

根拠：[S01] [S02]

> **注意**：サーバー一覧で「作成制限」と出たサーバーは、そこにキャラクターを持っていないと入れません。待てば入れるとは限りません。「おすすめ」と出たサーバーを選ぶのが確実です。根拠：[S03]

## 対になるサーバーとダンジョン

天族のサーバーと魔族のサーバーは対でマッチングされ、時空の亀裂やアビスで敵として会うのは、組み合わされた相手のサーバーです。この組み合わせは固定ではなく、勢力バランスに応じて定期的に変わる予定です。ですから「相手がこのサーバーだから」という理由で所属を決める必要はありません。

ダンジョンなどのインスタンス系コンテンツはクロスサーバーに対応しています。同じリージョンなら、サーバーや種族が違ってもパーティを組めます。

根拠：[S01] [S02] [S03]

→ [[party-and-matchmaking]]

## サーバー移動の制限

2026年10月14日から、同じ陣営のサーバー間で移動できる予定です。開始当初は無料の予定ですが、次の制限があります。

- 陣営は変えられない。
- アーリーアクセスのキャラクターは、アーリーアクセスのサーバー間でしか動けない。正式サービス側へは移れない。
- 費用以外の細かい条件（レベルなど）は未発表の部分がある。

「とりあえずアーリーアクセス側で始めて、あとで正式側へ移る」は使えません。最初から可能な限り希望のサーバーで始めてください。

根拠：[S01] [S02] [S03]

→ [[server-transfer]]、[[irreversible-choices]]

## Steam版とPURPLE版

Steam版とPURPLE版でサーバーは分かれていません。どちらで始めても、同じサーバーで遊べます。
