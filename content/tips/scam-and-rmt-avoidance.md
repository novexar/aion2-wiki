ゲーム内通貨や代行の売り込みは、始めたばかりの時期ほど多く、巻き込まれたときの代償も大きくなります。NCの公式な警告と運営ポリシーにもとづいて、避けるべきことをまとめます。詳しい規約は [[rules-and-policies]] にあります。

## NCの公式警告（2026年10月4日）

NCは、グローバル開始前日の10月4日に、公式の告知板で「違法な通貨の購入に関する警告」を出しました。内容は次のとおりです。

- 第三者からの購入を監視している。
- ギーナ（Kinah）とキューナ（Quna）を、認められていない相手から買うことは利用規約で固く禁じられており、ゲームへのアクセス停止まで含む処分を受ける。
- NCは、取った処分の内容を公開する権利を持つ。
- 「最初で最後の警告」と明記している。

検知の方法や個別の売り手の名前は、告知にありません。

根拠：[S01]

通貨を入手する正規の方法は、ゲーム内のプレイと、NC自身のストアだけです。

根拠：[S01]

→ [[quna]]、[[market-and-exchange]]

## 処分の一覧

運営ポリシー（2026年9月17日から適用）の要点です。

| 行為 | 処分 |
| --- | --- |
| 未承認のプログラム・装置、ゴールドの稼ぎ、ボット | 統合アカウント（NCの全ゲーム）の停止。初回から |
| 有償の代行（実行・仲介・常習の依頼者） | 7日、次に30日、その後は永久 |
| RMT（現金取引）。有償の代行（ブースト）や、他サーバーのプレイヤーとのアイテム取引を含む | 30日、次に90日 |
| RMTの未遂 | 3日、7日、30日 |
| アカウントの売買 | 7日、30日、90日 |
| 取引所の登録・支払い・キャンセルの悪用 | 統合アカウントの停止 |
| 共有・盗難アカウントで、所有者の過失による違反 | 両方のアカウントが処分されうる |

根拠：[S02]

## 避けるための行動

1. **ギーナ・キューナを第三者から買わない**。取引所で買うか、NCのストアを使います。
2. **他のサーバーのプレイヤーとアイテムをやり取りしない**。NCは、これも現金取引として扱います。
3. **2つのアカウントの間でアイテムを移す計画を立てない**。経路は取引所だけで、取引にはメンバーシップが必要です。
4. **有償の代行を頼まない・受けない**。遠征、超越、聖域、悪夢が例に挙げられています。→ [[party-etiquette-and-contribution]]
5. **VPNを使わない、アカウントを共有しない**。信頼ステータスが外れ、取引所や両替所などの機能が制限される恐れがあります。
6. **サードパーティのプログラムを使わない**。ゲーム内のマクロはNCの機能なので別です。→ [[auto-attack-cancel]]

根拠：[S02] [S03]

## 信頼ステータス

NCは各アカウントに信頼ステータスを付け、持っていないと取引所や両替所などの機能が制限されることがあります。不審な活動やソフト、RMT、ボット、未対応地域からのプレイやVPNなどを理由に、変更や取り消しをする場合があります。理由なく外れたと思う場合は、再評価を求められます。

根拠：[S02]

## 巻き込まれたとき

- 怪しいプレイヤーは、選択して「通報」できます。通報が重なるとミュートから停止までの処分になります。
- 間違った取引や処分の復旧には期限があります。復旧の申請、盗難の報告、異議申し立ては15日以内です。
- サポートは、取引所や補給依頼のミス、強化の失敗などの損失は復旧しません。
