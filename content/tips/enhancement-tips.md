強化石とギーナは有限です。AION2では強化すると能力値だけでなく装備レベルも上がるため、入場条件を満たすために強化するのは正しい使い方です。ただし「強化できるから強化する」と、すぐ捨てる装備に素材を吸われます。この記事は、どこで止めるかの目安をまとめたものです。強化の仕組みと確率は [[enhancement]] にあります。

## 基本の考え方

装備を完成させてから次へ進むのではなく、次の装備を手に入れられる状態を作るために強化します。

1. 新しい装備を拾ったら、等級とアイテムレベルを今の装備と比べる。
2. すぐ上位が手に入るなら、今の装備に素材を使わない。
3. あと少しの装備レベルで新しい遠征に入れるなら、強化する。
4. 長く使う装備が揃ってきたら、武器など重要な部位に集中する。

根拠：[S01]

## 等級ごとの目安

| 装備 | 目安 |
| --- | --- |
| ストーリー途中の希少（緑） | 必要になったときだけ |
| すぐ交換する伝承（青） | +5前後まで、必要分だけ |
| Lv45まで使いそうな伝承 | 装備レベルが足りなければ追加 |
| 長く使う唯一（金） | +10まで本格的に |
| 唯一の+11以降 | 長期間使う装備を優先 |

根拠：[S01]

固定のルールではありません。「+5なら必ず止める」ではなく、次に何へ交換するかが分かっているかどうかで決めます。

## 序盤（希少・伝承）

- 敵を問題なく倒せているなら、強化せずに進めて構いません。
- 強化する理由は、倒すのに時間がかかる、被ダメージが大きい、次の装備レベル条件に届かない、の3つです。
- 防具を1つ更新するたびに最大まで強化すると、Lv45以降に使う強化石とギーナが足りなくなります。
- 魔石は、すぐ交換する段階では手持ちの安いもので空き枠を埋める程度にします。高価なものは長く使う装備まで残します。

根拠：[S01]

> **注意**：希少（緑）装備は抽出すれば強化石が戻るので、気にせず強化してよいと書く資料もあります。ただし抽出でギーナは戻りません。強化石が一気に減り始めるのは伝承（青）を強化し始めてからです。素材とギーナのどちらを重く見るかで判断してください。根拠：[S03] [S04]

→ [[extraction]]

## 少しずつ広く上げる

強化は段階が上がるほど費用が増え、成功率が下がります。1つの装備を何段階も上げるより、複数の装備をそれぞれ1段階ずつ上げるほうが効率はよいとされます。ただし例外があります。ベルトとアミュレットは最大まで育てたあとに交換しないため、強化し続ける価値があります。

根拠：[S03]

## Lv45以降の順番

迷ったら、次の順で確認します。

1. 長く使う武器とガーダー
2. アイテムレベルが大きく遅れている部位
3. ベルトとアミュレット
4. そのほかの防具・装身具

武器だけ非常に強く、防具に低い装備が残っているなら、武器を上げるより弱い防具を交換したほうが、少ない素材で装備レベルを伸ばせることがあります。

根拠：[S01] [S02]

### ベルトとアミュレットは育てる枠

ベルトとアミュレットは、より強いものが落ちたら交換する装備ではなく、段階的に育てる装備です。駐屯地の巻物やモノリスで集める素材を使い、Lv45直後から進めておく成長枠として扱います。

根拠：[S01] [S02] [S03]

→ [[belt-and-amulet]]、[[strongholds]]、[[monoliths-and-empyrean-traces]]

## 唯一装備は+10を基準にする

唯一は+15まで強化できます。+10までは安定して成功しますが、+11以降は成功率が設定され、失敗すると強化石とギーナを失います。

| 段階 | 考え方 |
| --- | --- |
| +0〜+10 | 使う唯一装備なら積極的に |
| +11〜+15 | 長期的に使う装備から |

次の装備が近いなら、現在の装備は必要な装備レベルを確保したところで止めます。

根拠：[S01]

## 装備レベルの節目

Lv45になると、装備レベルが次のコンテンツを開きます。強化の目標は「今の装備を完成させる」ではなく「次の節目を超える」ことです。

| 装備レベル | 次の目標 |
| --- | --- |
| 700 | クラオ洞窟・ドラウプニルなどの征服 |
| 1000 | アビスなどのLv45成長コンテンツ |
| 1400 | ウルググ峡谷・バクロンの空中島 |
| 1600 | 超越 |

根拠：[S02]

> **注意**：ストーリーの終盤と最初のLv45遠征に装備レベル1000が必要と書く資料もあります。遠征の入場条件はDB上、クラオ洞窟の征服が700です。実際の条件はゲーム内の表示で確認してください。

→ [[road-to-il-1000]]、[[what-to-do-at-45]]

## 新しい装備を捨てない

強化済みの装備を着ていると、拾った未強化の装備の数字が低く見えます。そこで捨てないでください。等級、アイテムレベル、基礎性能、強化後の伸びしろ、魔石スロットを見ます。アイテムレベルの高い唯一は、未強化でも強化後に更新候補になることがあります。

根拠：[S01]
