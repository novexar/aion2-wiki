AION2は素材も装備も種類が多く、所持品はすぐあふれます。倉庫の種類と使い分け、拡張のタイミング、間違えたときの戻し方を押さえておくと、整理に迷う時間が減ります。倉庫の基本仕様は [[storage-and-cube]] にあります。

## 3つの入れ物の使い分け

| 入れ物 | 内容 |
| --- | --- |
| キューブ | 持ち歩く所持品 |
| サーバー倉庫 | 同じサーバーのキャラクター全員で共有 |
| キャラクター倉庫 | そのキャラクターだけ |

- 多くの拘束アイテムはサーバー倉庫に入れられます。ポーション、スクロール、力の欠片などです。
- 復活の霊石、オードエネルギー、魂のコーデックス、外形アイテムは入れられません。迷ったらツールチップで確認します。
- サーバー倉庫が入れてくれないキャラクター固有の拘束アイテムは、キャラクター倉庫に入れます。
- 拘束ギーナ（Bound Kina）はどちらの倉庫にも入れられません。入るのは取引可能なギーナだけです。探索の報酬キューブは拘束ギーナを払います。

→ [[whats-bound]]、[[kina-and-bound-kina]]

## サブキャラから素材を渡す

サーバー倉庫は、サブキャラで集めた取引可能な素材とギーナをメインに渡す経路になります。サーバーを移ったキャラクターの分は、そのサーバーに残ります。

根拠：[S01] [S02]

→ [[kina-farming]]、[[server-shared-limits-and-alts]]

## 倉庫を開く方法

- **倉庫管理人のところへ行く**：Altを押しながらミニマップ横の人型アイコンを押し、倉庫管理人を選ぶと、キャラクターが自動で歩いていきます。
- **どこからでも**：メンバーシップがあると、キューブ右下の「遠隔倉庫」メニューからサーバー倉庫とキャラクター倉庫を開けます。「クイック保管」は、条件に合うアイテムを一度に預けます。

根拠：[S01]

→ [[membership]]

## 拡張のコツ

サーバー倉庫もキャラクター倉庫も、最初は1〜5行です。それ以降は1行増やすごとに費用が上がります。両方とも同じ価格表で、費用は別々に払います。

| 行 | 1行ごとのギーナ | 合計の累計 |
| --- | --- | --- |
| 6〜10 | 1,000／1,000／1,500／2,000／2,500 | 8,000 |
| 11〜15 | 3,500／5,000／6,500／9,000／15,000 | 47,000 |
| 16〜20 | 20,000／25,000／35,000／45,000／60,000 | 232,000 |
| 21〜25 | 80,000／150,000／150,000／200,000／300,000 | 1,112,000 |

- キューブには10回の拡張があり、1回10,000から1,000,000ギーナで、全部で約270万ギーナです。
- クライアント内の拡張券は1行ずつ開けます。どの入れ物も最大は80行です。

根拠：[S01]

> **注意**：費用の表は資料のデータマイニングによる値です。ゲーム内の表示を優先してください。

## 間違えたときの「アイテム回収」

メインメニューの「アイテム回収」で、間違えて処分したアイテムを戻せます。戻ったアイテムはキューブに入ります。

| 間違い | キャラクターごとの回数 |
| --- | --- |
| NPCに売却した | 年30回 |
| 抽出した（唯一等級以上のみ） | 年1回 |
| ソウルシンクで素材を使い切った | 年1回 |

- 回数は1月1日にリセットされます。
- スタック全体で1回と数えます。期限付きのアイテムは回収できません。
- 抽出を取り消すと、抽出で得た強化石とアビスポイントが戻り、ギーナは拘束ギーナで返金されます。外形は手元に残ります。

根拠：[S01]

NCのサポートによる復旧は別の仕組みで、期限は15日、強化の失敗や翼・アルカナの抽出は戻りません。根拠：[S03]

→ [[extraction]]、[[rules-and-policies]]

## 自動で拾わせる設定

ペットにドロップ品を拾わせる機能では、拾うものと拾わないものを決めるフィルタを設定できます。灰色の不要品でバッグが埋まるのを防げます。自動拾得の利用にはペット自動拾得の権利が必要です。

根拠：[S02]

→ [[pets-and-mounts]]

## 整理の目安

1. 使わない装備は、価値を確認してから抽出または売却する。誤抽出は年1回しか戻せない。
2. 取引可能な素材はサーバー倉庫に入れ、サブキャラやメインから使えるようにする。
3. 拘束ギーナは倉庫に入れられないので、貯めずに使う。
4. 売却前に、一度アイテム回収の残り回数を意識する。
