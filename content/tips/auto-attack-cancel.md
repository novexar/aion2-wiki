AION2では、通常攻撃（基本攻撃）がスキルの後隙の動作を途中で切ります。これを使うと、次のスキルが早く出て、同じ時間でたくさん攻撃できます。ゲーム内のマクロを使えば、この動きを2つのキーを押し続けるだけで再現できます。マクロの作り方の詳細は [[macros]] と [[rotation-and-skill-macros]] にあります。ここでは最短の手順と、よくある失敗をまとめます。

## 要点

- 左クリックは通常攻撃で、スキルの硬直を切る。
- マクロキーを1つ決め、スパムするスキルを入れる。
- マクロキーと左クリックを同時に押し続けるのが基本。
- バフ、移動、バーストは手動で押す。

根拠：[S01] [S02]

## 手順

1. **キーを割り当てる**：設定 → キー設定 → 一般 → ゲームプレイ → 「マクロ」。初期は未設定です。マウスボタンがよく使われますが、AION 1の操作モードではマウスのボタンをマクロキーにできません。
2. **ホットキーに複数のスキルを重ねる**：スキル画面（K）のクイックスロットで、1つのホットキーに最大4つのスキルを重ねられます。使うスキルは、一番下のものが準備できていれば優先して出ます。上にあるスキルはその隙間を埋めます。
3. **マクロを作る**：スキル画面の右上の「マクロ」で「マクロを追加」を押し、スキルではなくホットキーを選びます。追加したばかりのステップは通常攻撃になっているので、変更してください。
4. **遅延を設定する**：各ステップの遅延（ミリ秒）は10から始めます。PCが遅い場合は少し増やすとよいことがあります。練習用の人形で試してください。
5. **スキルの先行入力**：設定 → 戦闘 → 操作 → 一般操作モード設定の「スキルキュー」は、初期のままオンにします。

その後、左クリックとマクロキーを同時に押し続けます。うまく切れると、キャラクターに黒いシルエットが出ます。

根拠：[S01] [S02]

## マクロに入れるもの

| 場所 | 入れるもの | 理由 |
| --- | --- | --- |
| マクロの中 | 常にスパムしたい1〜2個のホットキー | ステップが増えるほどヒット数が落ちる |
| 押し続ける | 通常攻撃（左クリック） | マクロの中だと1周に1回しか出ず、キャンセルの回数が減る |
| 手動 | バフ、移動、バーストなど | マクロに入れると準備できた時点で毎回出てしまう |

- クールダウンのないスキルを、一番下の位置に置かないでください。上のスキルが一切出なくなります。
- 主力のダメージスキルを2つ、同じキーに重ねないでください。互いにじゃまをします。
- 同じクールダウンのスキルも同様です。
- チャージ型のスキルは、マクロの外で自分のキーを押し続けます。マクロでは最初の段階で出てしまいます。

根拠：[S01] [S02]

## うまくいかないとき

| 症状 | 原因と対処 |
| --- | --- |
| マクロキーが反応しない | AION 1の操作モードでマウスボタンを割り当てている。キーボードのキーにする |
| 切り替え後にマクロが止まった | スキルプリセットごとにマクロがある。プリセットを変えたら押し直し、使うプリセットごとに作る |
| 雑魚戦でバフが出た | バフがマクロに入っている。外して手動にする |
| 通常攻撃ばかり出る | 新規ステップが通常攻撃のまま。変更するか削除する |
| 押し続けても通常攻撃が止まる | Altを押している、またはAltと組み合わせたキーを使っている。Altの組み合わせにスキルを割り当てない |
| 並びと違う順で出る | 仕様。リストは優先度で、台本ではない |

根拠：[S01]

## 規約との関係

ゲーム内のマクロはNC自身の機能です。NCの運営ポリシーも行動規範も、これを禁止していません。一方、利用者の操作なしに動かすサードパーティのプログラムは禁止で、初回の違反でも統合アカウントの停止になります。マウスやキーボードのマクロソフトは名指しされていませんが、「未承認のプログラム、装置、機器」の禁止に含まれる可能性があり、アジア版では使わないよう案内されています。ゲーム内のマクロだけを使うのが安全です。
