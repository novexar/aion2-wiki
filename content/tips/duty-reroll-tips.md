使命（Duty）の任務と、週に12件買える指令（Command）は、どれも「5枠のランダム報酬」を表示します。どの任務を選ぶか、そして再抽選に払うギーナをどこで止めるかで、同じ手間でも手に入る報酬が変わります。任務そのものの説明は [[duty-quests]] にあります。

## 枠の確率

各任務は5枠の報酬を並べ、左から順に確率が下がります。

| 枠 | 確率 |
| --- | --- |
| 1枠目 | 必ず |
| 2枠目 | 50% |
| 3枠目 | 33% |
| 4枠目 | 25% |
| 5枠目 | 10% |

クエストごとに確率は違います。報酬欄をもう一度押すと正確な値が見られます。

根拠：[S01] [S02]

## 基本の戦略

1. 5件の任務を並べて見て、**1枠目（確定）に欲しい報酬がある**ものを選ぶ。
2. 該当がなければ、再抽選を数回だけ使う。
3. 欲しいものが1〜2枠目に出た時点で受ける。

報酬の候補は、ギーナ、強化石、魂結晶のほか、ヒドゥンキューブの鍵、小さなオードエネルギー、悪夢・覚醒戦・未知の狭間のチケットなどです。

根拠：[S01]

## 何を狙うか

序盤は次のものが勧められています。

- **ヒドゥンキューブの鍵**：世界に隠されたキューブを開けられます。中身は、運が良ければペット、新しい翼、外形などです。根拠：[S02]
- **魂結晶**：ペット育成に使います。毎日の任務で魂結晶が得られるという報告があります。根拠：[S03]
- **アリエルの痕跡の欠片**：ディーヴァニオン結晶の材料です。根拠：[S02]

使命は1日5件で、サーバーで共有されます。サブキャラでは増やせません。

根拠：[S01] [S03]

→ [[hidden-cubes]]

## 再抽選の費用

再抽選のギーナは回数ごとに上がります。

| 回数 | ギーナ |
| --- | --- |
| 1回目 | 1,000 |
| 2回目 | 2,500 |
| 3回目 | 6,000 |
| 4回目 | 14,000 |
| 5回目 | 35,000 |
| 6回目 | 85,000 |
| 7回目 | 200,000 |

資料の助言は「85,000で止める」です。それ以上は、狙う報酬の価値に見合いません。

根拠：[S01]

## 指令（コマンド）の再抽選

指令書は、首都の指令商人から1枚15,000ギーナで買えます。アビス下層でも売っており、高いグレードほど報酬の数が多くなります。報酬の確率と再抽選の考え方は使命と同じで、費用は1,000から300,000ギーナです。

- 毎週12件を首都で買うのが基本です。買い忘れた分は翌週に持ち越せません。
- 下位のグレードでも、報酬の種類は変わりません。
- 鍵や欠片が出ないときは、再抽選の価値があります。

根拠：[S01] [S02]

→ [[commands-and-command-scrolls]]

## 使うタイミング

- **Lv45になるまで、使命タブを開かない**：先に開くと、Lv45でも使命が翌日まで使えない不具合があります。根拠：[S01] [S04]
- 任務が終わったら翌日16時（日本時間）に更新されます。持ち越しはできません。
- ギーナが足りない序盤は、再抽選を深追いしない。強化にギーナが必要です。

根拠：[S01]
