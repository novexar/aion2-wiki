キューナ（Quna）は現金で購入する有償通貨です。ショップの外形やペット、ディーヴァパスのプレミアム、そして **交換所で他のプレイヤーからギーナを買う** ことに使います。ギーナと違ってゲームプレイでは直接手に入りませんが、メンバーシップ加入者はギーナをキューナに換えることもできます。

## 価格

| キューナ | 米ドル（PURPLE 基準） | 日本円（AION2 Times 掲載） |
| --- | --- | --- |
| 400 | $5.99 | 940円 |
| 1,000 | $14.99 | 2,350円 |
| 2,000 | $29.99 | 4,700円 |
| 4,000 | $59.99 | 9,400円 |

米ドル価格は NC の 2026年9月30日の商品告知にもとづく値で、販売開始はアーリーアクセス初日の 9月30日です。Steam 版は Steam ウォレットで支払うため価格が異なる場合があります。根拠：[S01] [S06]

> **要確認**：日本円の価格は日本語攻略サイトの記載で、公式告知の本文はこの調査では直接取得できませんでした。ゲーム内「キューナ ショップ」の表示を優先してください。根拠：[S03]

NC ヘルプセンターによると、PURPLE での決済は米ドル建てのみで、NCoin（NC の他ゲーム用通貨）ではキューナを買えません。根拠：[S01]

## 使い道

| 用途 | 目安 |
| --- | --- |
| ディーヴァパスのプレミアム | 1,500 キューナ（シーズン1「暁のレギオン／イスハルゲンの傭兵」）、1,000 キューナ（「世界の呼びかけ」） |
| パスのレベル購入 | 1レベル 50 キューナ |
| 外形セット（一部） | 2,200 キューナ（Genesis Daeva、Shadowlight Wind） |
| ヘルム・装飾パーツ、エモート | 各 300 キューナ |
| 復活の精霊石 | 100 キューナ |
| ヒドゥン キューブの鍵 | 50 キューナ（1日3個まで） |
| キューブ・倉庫の拡張券 | 200 キューナ |
| 名前変更 | 500 キューナ |
| **キャラクター枠の追加** | **1,000 キューナ／1枠**（初期4枠、最大8枠） |
| 交換所でギーナ箱を購入 | プレイヤーが決めた相場（メンバーシップ必須） |

根拠：[S01] [S02] [S04] [S06]

ショップには「現金で買う商品」と「キューナで買う商品」の両方があります。例えば外形セットは 3種が $29.99、2種が 2,200 キューナです。詳しくは [[cash-shop-and-cosmetics]] を参照してください。根拠：[S06]

## キューナはキャラクター単位

購入したキューナは **そのキャラクターに紐づき**、サーバー移動のときはキャラクターと一緒に移動します。別のキャラクターでは使えないため、使うキャラクターでログインして購入してください。A2 マイレージ（購入時に付く特典ポイント）も同様です。根拠：[S02]

データベースには「使用待機キューナ」という表示名があり、購入から 72 時間の待機時間を経て有償キューナに切り替わる旨の説明があります。根拠：[S05]

## ギーナとキューナの交換

交換所（Quna Exchange）では、プレイヤーが物質変換で作った **ギーナ箱**（40万・200万・1,000万ギーナの3種）を出品し、別のプレイヤーがキューナで買います。レートは NC ではなくプレイヤー同士の需給で決まります。出品にも購入にもメンバーシップが必要です。詳細は [[market-and-exchange]] を参照してください。根拠：[S01] [S02]

## 未成年の購入上限（日本）

| 年齢 | 1か月に買えるキューナの金額 |
| --- | --- |
| 15歳以下 | 5,000円まで |
| 16〜19歳 | 20,000円まで |
| 20歳以上 | 上限なし |

キューナに有効期限はなく、法律で認められる場合を除いて購入後の払い戻しはできません。根拠：[S07]

## 買う前の注意

- **ガチャはありません**。キューナの使い道はショップの見た目・消耗品とパスです。根拠：[S07]
- 外形・翼・ペットは見た目専用で、能力値は付きません。根拠：[S06]
- 使うキャラクター・サーバーを決めてから買う（キャラ単位のため）。根拠：[S02]
