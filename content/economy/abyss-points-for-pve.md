アビスポイント（Abyss Points、AP）は、対人戦（PvP）の通貨に見えますが、**PvE専のプレイヤーにも必要**です。スキルを強化する「スティグマの欠片」を買う主な手段だからです。しかも敵プレイヤーを倒さなくても、日課や補給依頼、ミニゲームで貯められます。ここではPvE専の視点で、買う物と稼ぎ方を絞って説明します。詳しい全体像は [[abyss-points-and-shop]] を見てください。

## なぜPvEでも要るのか

AION2 のよくある質問でも「PvEしかやらないがアビスポイントは要らないか」への答えは「要る」です。スティグマ（スキル強化）関連の購入に必要で、アビス回廊や日次依頼など対人しない稼ぎ方が用意されています。根拠：[S01] [S02]

| 項目 | 内容 |
| --- | --- |
| 主な買い物 | スティグマの欠片。1キャラ最大200個。50個ごとに 10,000 → 15,000 → 20,000 → 25,000 AP |
| 取引 | 個人取引不可 |
| 持ち越し | シーズンが変わっても持ち越される |

根拠：[S03] [S04]

## アビスに入る条件

| 項目 | 内容 |
| --- | --- |
| 解放 | Lv45、アイテムレベル1,000 |
| 滞在時間 | 週7時間（会員・非会員とも同じ）。水曜にリセットされ、余りは持ち越されない |
| 入口 | 天族はヴェルテロンの幻神の庭、魔族はアルトガルドの黒爪の村にあるアビスポータル |

根拠：[S02] [S03]

## 対人せずに稼ぐ

| 手段 | 内容 | AP |
| --- | --- | --- |
| 使命（Duty）・補給依頼・シーズンミッション | 日課のついでに進む | 少量ずつ |
| アビス回廊 | ソロ、IL1,000。遺物を持つ陣営の入口が攻防戦後に開き、1回5分 | あり |
| 時空の亀裂（敵陣営の封印ダンジョン・駐屯地） | 週に各1回 | 封印ダンジョン1,000、駐屯地3,000 |
| シューゴフェスタ | ミニゲーム報酬 | あり |

根拠：[S02] [S03] [S04]。金額の詳細は [[abyss-points-and-shop]]。時空の亀裂は3時間ごとに開き、入口は10分間、現地に約1時間滞在します。

補給依頼では、取引できない余った装備・素材を納品して AP に換えられるため、NPC に売る前に確認します。フィールドボスに1回攻撃を当てるだけでも宝箱が手に入り、取引不可のドロップは補給依頼に回せると助言されています。根拠：[S05]

闘技場（1v1・5v5）と戦術の闘技場（10v10）は AP が多く入りますが、プレイヤー同士の対戦です。1つの闘技場は週にマッチ報酬10回・勝利報酬30回まで（戦術の闘技場は各3回）で、1マッチ300AP、勝利500AP（戦術は1,000AP、勝利3,000AP）です。PvE専は無理に参加する必要はありません。根拠：[S06]

## PvE専の買い方

1. **スティグマの欠片を最優先**。最初の50個（1個1万AP）から。
2. ほかの入手先と併用します。上限は店ごとに別です。
   - 悪夢商店：1,500破片で1個、1キャラ35個まで（[[phantasmal-fragments-nightmare-shop]]）
   - フェスタ商店：百年人参の証で購入（[[centuryroot-tokens-festa-shop]]）
3. 下級アビスの魔石・霊石は、安く魔石枠を埋めたいときだけ。
4. 潜在力の石：アビスなどPvP向けの品は、PvEでは後回しです。

> **韓国版のみ**：韓国版ではチャプター終了時にポイントが持ち越され、週40万APの獲得上限が報告されています。グローバル版の上限はゲーム内で確認してください。

## 注意

- 時空の亀裂に入る前に、画面右下でPvEモードかPvPモードかを選びます。切り替えには70分のクールダウンがあります。根拠：[S02]
- 他陣営のプレイヤーに襲われる可能性があります。アビスのフィールドは対人が自由です。
- アビスの時間は週7時間なので、入る前に目的（欠片のため、補給依頼のため）を決めて入ります。
