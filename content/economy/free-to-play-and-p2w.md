AION2 は**基本プレイ無料**です。ダウンロードもストーリーもダンジョンもPvPも、お金を払わなくても遊べます。ただし、有料の要素が「何も差を生まない」わけではありません。ここでは、何が有料で、無課金だと何ができず、どこが議論になっているかを整理します。結論を先に言うと、**始めて数日の間は無課金で困りません。取引所を使う段階で、メンバーシップが必要になります。**

## 有料のもの

| 有料要素 | 内容 | 必要度 |
| --- | --- | --- |
| クァイリン特級メンバーシップ | 30日2,350円（米国$14.99）。取引所の購入、交換所、遠隔倉庫、オードエネルギー拡張など（[[membership]]） | 任意。経済を使うなら実質必要 |
| キューナ | 有償通貨。400で940円から（[[quna]]） | 任意 |
| ディーヴァパス | キャラごとのバトルパス。プレミアムは1,500キューナ（[[daeva-pass]]） | 任意 |
| 外形ショップ | 衣装・翼・ペット・武器スキン（[[cash-shop-and-cosmetics]]） | 任意 |
| ファウンダーズパック | 先行購入。販売は終了（[[founders-packs]]） | 終了 |

あせろぐは「ガチャなし」と説明しています。根拠：[S01] [S02] [S04]

> **補足**：ストアの表記は、Steam が「アプリ内課金」、PEGI が「ゲーム内購入、有償のランダムアイテム」です。確率型アイテムの確率は、NC の確率情報ページで開示されると、ディーヴァパスの告知にあります。根拠：[S02]

## 無課金でも同じ（できること）

| できる | 内容 |
| --- | --- |
| ストーリー・フィールド・ダンジョン・PvP | すべて遊べる |
| 遠征・超越の報酬 | オードエネルギーを1回注入して受け取れる |
| 取引所の出品 | 公式告知では非会員も出品できる（実機では出品もできない報告あり） |
| ギーナ稼ぎ | 通常ギーナも入手できる |
| ディーヴァパスの基本トラック | 無料で報酬を受け取れる |

根拠：[S01] [S03] [S04]

## 無課金だとできない・差が出る点

| 項目 | 非会員 | 会員 |
| --- | --- | --- |
| 取引所での購入 | 不可 | 可 |
| ギーナ↔キューナ交換所 | 不可 | 可 |
| 遠隔倉庫 | なし | あり |
| 報酬キューブへのオードエネルギー注入 | 遠征・超越で1回 | 遠征・超越・聖域で2回 |
| オードエネルギー上限 | 560 | 840 |
| そよ風商会 | 不可 | 可（[[wind-breeze-merchants]]） |

プレイヤー同士の経済と結びついた機能が、メンバーシップで開く構造です。報酬キューブへの2回注入は、同じ週により多くの報酬を受け取れることを意味します。ある解説者はこれを「基本無料だが、参加は無料ではない」と評しています。根拠：[S02] [S03] [S04]

## P2W だと言われる点・言われない点

| 論点 | 内容 |
| --- | --- |
| 公式の説明 | ショップの外形は「ゲームプレイや戦闘上の優位なし」。消耗品は「装備成長や長期的な強さに影響せず、プレイでも入手できる」 |
| パスの育成素材 | パスの報酬には強化石、突破石の欠片、ギーナ（刻印）が含まれ、プレミアムの方が多い。公式の「優位なし」は外形と消耗品の話で、パスには当てはまらない |
| 初期の評価 | 韓国・台湾版の発売直後には、ショップの消耗品とパックを「有料の優位」とする批判があり、運営が一部を撤回した |
| 長期プレイヤー | パスの素材は「すぐ追い越す」と低く評価する声もある |
| 経済 | ギーナをキューナに、キューナで素材を買えるため、お金で素材を集めやすくなる |

根拠：[S02] [S03] [S05]

結論として、**直接戦闘力を売る商品はない**とされますが、メンバーシップとパスを通じて、**素材の入手速度に差がつく**可能性があります。この差を大きいと見るか小さいと見るかは、人によって分かれています。

## 無課金で始めるときの目安

1. Lv45までは課金なしで進めます。取引所もLv45から解放です。
2. Lv45に着いたら、取引所で何を買いたいかを決めます。買うものがなければ、まだ加入しなくても構いません。
3. 加入するなら、取引所を使う日に有効化します。30日はボタンを押した時点から数えます。
4. 外形は後回しです。衣装の大半はプレイで入手できます。
5. 運営が認めていない第三者からのギーナ・キューナの購入は規約違反です。（[[trading-rules]]）
