クァイリン特級メンバーシップ（Special Quai Membership）は、AION2 唯一の月額課金です。ゲーム自体は基本プレイ無料で、入らなくてもストーリー・ダンジョン・PvP は遊べます。ただし **取引所での購入、ギーナとキューナの交換所、遠隔倉庫** などは会員向けなので、プレイヤー同士の経済を使うつもりなら実質的に必要になります。

## 基本情報

| 項目 | 内容 |
| --- | --- |
| 正式名称 | クァイリン特級メンバーシップ |
| 価格（日本） | 30日 2,350円 |
| 価格（米国） | 30日 $14.99（9月29日の英語版告知で $15.00 から改定） |
| 販売開始 | 2026年9月30日（水）22:00（日本時間）、ゲーム内メニュー［サブスク］から |
| 期間の数え方 | 「有効化」ボタンを押した時点から30日（購入時点ではない） |
| 効く範囲 | 購入した **サーバーの全キャラクター**。別サーバーには効かない |
| 追加購入 | 特典の残りが60日未満のときだけ購入可。1回ごとに30日延長、サーバーごとに月3回まで |

根拠：[S01] [S02] [S03]

> **注意**：当初は 10月5日販売の予定でしたが、9月23日の公式修正でアーリーアクセス初日の9月30日に前倒しされました。日本円は、販売前の時点では未発表で、その後に 2,350円と案内されています。ゲーム内の表示額を優先してください。根拠：[S02] [S03]

## 特典一覧

| 特典 | 非会員 | 会員 |
| --- | --- | --- |
| 取引所（Lv45で解放） | 公式告知は「出品のみ可、購入不可」。実機では出品も不可の報告あり | 出品と購入。同時出品は最大10件 |
| ギーナ↔キューナ交換所 | 利用不可 | 利用可 |
| 遠隔倉庫 | 倉庫NPCの前だけ | キューブ画面からどこでも倉庫を開ける |
| 報酬キューブへのオードエネルギー注入 | 遠征・超越で1回 | 遠征・超越・聖域で2回 |
| オードエネルギーの最大保有量 | 通常（560） | 840 |
| 会員専用商店「そよ風商会」 | 利用不可 | 利用可（[[wind-breeze-merchants]]） |
| シューゴフェスタ報酬の鍵の所持上限 | 12個 | 21個 |

根拠：[S01] [S02] [S03]

オードエネルギーの回復速度は会員でも同じです。増えるのは「ためられる量」と「1つのキューブに2回注入できること」だけです。詳しくは [[odyle-energy]] を見てください。根拠：[S01] [S02]

## 付かない特典に注意

- **個人取引（直接取引）**：公式の商品ページには「個人取引（1日5回）」の記載が残っていますが、グローバル版では BOT 対策として全員の直接取引が無効化されており、会員特典にもなっていません。友達に渡すために加入しても使えません。（[[trading-rules]]）
- **ワールド取引所**：9月28〜29日の改定で公式の特典一覧から外されました。表にあった時期の資料と食い違うため、現状は「特典に含まれない」と考えてください。
- **ディーヴァパスのプレミアム**：会員でも自動では開放されません。別課金です。（[[daeva-pass]]）
- **追加のアビス時間**：付きません。

根拠：[S01] [S03] [S04]

## 取引所の公式告知と実機報告の食い違い

| 資料 | 非会員の取引所 |
| --- | --- |
| NC 公式告知（資料 [S01] が引用） | 出品はできるが購入はできない |
| AION2 Times | 利用不可 |
| 実機（クライアント）の報告 | 出品欄自体がないという報告あり |

採用した解決：購入には会員が必要という点は全資料で一致しています。出品だけの扱いは資料により異なるので、「非会員は出品できるとは限らない」と考えてください。取引所を使うキャラのいるサーバーで有効化するのが安全です。根拠：[S01] [S02]

## 加入すべきか

| 状況 | 目安 |
| --- | --- |
| 始めて数日、Lv45 未満 | 急がない。取引所はLv45から |
| Lv45 に到達し、装備素材を買いたい | 検討する。有効化は取引所を使う日に合わせる |
| 毎週遠征・超越・聖域を回す | オードエネルギー上限と2回注入の恩恵が大きい |
| 友達とアイテムをやり取りしたい | 加入しても直接は渡せない。取引所経由になる |

有効化は「使う日」にしてください。購入しただけでは期間が始まりません。根拠：[S03] [S04]
