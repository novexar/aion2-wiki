魂の結晶（Soul Crystal）は、ペットの能力値盤面「ペット・ジーナス（種族理解度）」を回す「分析」に使う素材です。ペットを集めて育てる人にとっては、ギーナの次によく使う消耗品になります。ここでは**どこで手に入り、どこで買うのが安いか**をまとめます。盤面の仕組みは [[pet-genus]] を見てください。

## 種類

| 種類 | 使える範囲 |
| --- | --- |
| 共通の魂の結晶（Soul Crystal） | どの盤面の分析にも使える |
| 種族ごとの魂結晶（知性／野性／自然／変形／特殊） | その種族の盤面だけ |

特殊（Special）のペットには魂がなく、その盤面専用の結晶はとても少ないため、特殊の分析には共通の魂の結晶を先に使うのが助言されています。根拠：[S01]

## 使い道とコスト

| 項目 | 内容 |
| --- | --- |
| 分析（1回） | その盤面の魂結晶または共通の魂の結晶を4個＋ギーナ1,000。理解度経験値+100 |
| ロック（1〜8本） | 分析ごとに追加で 8／16／36／76／156／236／316／396 個。追加ギーナは 2,000〜99,000 |
| 理解度1→10 | 経験値250,000。分析だけなら約2,500回 |

根拠：[S01]

理解度10になるまではロックしないのが定石です。詳しい数字は [[pet-genus]] にあります。

## 入手先と、どこが安いか

| 入手先 | 量・価格 | 条件 |
| --- | --- | --- |
| そよ風商会（会員専用） | 1個 500 ギーナ | サーバーごとに週1,000個まで |
| フェスタ商店 | 百年人参の証50で魂の結晶100 | 月30回まで |
| ヒドゥンキューブ（鍵を使って開封） | 1回1,000個 | データマイン値。韓国版では100から1,000に変更と報告 |
| 征服の報酬キューブ | 1,000個 | テストプレイヤーの報告。要確認 |
| ペットの収集の節目 | 上限まで育てたペット1体につき1,000個の目安 | 魂は種族の結晶に自動変換される |
| サービス開始記念シューゴ出席簿 | 5,000個 | 2026年9月30日〜12月16日 |
| 悪夢商店 | 品目あり | 韓国版では50個の束売り。グローバル版は要確認 |

根拠：[S01] [S02] [S03] [S04]

> **注意**：「ヒドゥンキューブの鍵1回で1,000個」は Aion 2 Maps のデータマイン値で、韓国版の10月7日パッチノートも「100から1,000に」としています。グローバル版が最初から1,000なのか、韓国版と同じ更新が入ったのかは確認できていません。

## 買う順番の目安

1. **ログインボーナスと鍵の報酬**：無料で入ります。まずこれを使います。（[[hidden-cubes]]）
2. **フェスタ商店**：百年人参の証は毎日遊ぶほど貯まります。（[[centuryroot-tokens-festa-shop]]）
3. **そよ風商会**：会員なら 500 ギーナと最安です。サーバーで週1,000個まで買えます。（[[wind-breeze-merchants]]）
4. 余ったギーナ（刻印）は先に消費されるので、刻印ギーナで買えば通常ギーナを節約できます。（[[kina-and-bound-kina]]）
