百年人参の証（Centuryroot Token）は、毎時開催のミニゲーム「シューゴフェスタ」で手に入る通貨です。データベースの説明では「品質の良い百年人参を乾燥させたシューゴたちの収集品」で、**シューゴ フェスタ商店**で様々なアイテムを買えます。ゲームの進行に必須ではありませんが、魂の結晶やスティグマの欠片が買えるので、毎日の鍵を使い切る価値はあります。（遊び方は [[shugo-festa]]）

## 基本情報

| 項目 | 内容 |
| --- | --- |
| 取引 | 個人取引不可 |
| 入手先 | シューゴフェスタの各ミニゲーム（13種類の入手元）、サービス開始記念シューゴ出席簿 |
| 使い道 | フェスタ商店（WikiRealm はクライアント上の品目を49と記載） |
| シーズン終了時 | 持ち越される（誓いのコインやパス商店コインは消える） |

根拠：[S01] [S02] [S03]

ゲーム名の例は、「ジャンプ！ジャンプ！」「亡霊回避」「神秘的なトラック」「ヒドゥン ルギ」「オードの雫を収集」「ゴールドリンの宝物」「シューゴ商人の保護」「高く高く」「このタイルじゃない？」などで、アビスポイントも同じゲームで手に入ります。根拠：[S01]

## ローンチ配布

サービス開始記念シューゴ出席簿（2026年9月30日〜12月16日）では、4日目のログイン報酬に百年人参の証が 5,000 個入っています（天族・魔族とも）。根拠：[S01]

## フェスタ商店で買えるもの（DB の用途一覧）

| 区分 | 品目 |
| --- | --- |
| 成長素材 | スティグマ シャード（刻印）、ディーヴァニオン結晶（刻印）、知恵の石（刻印）、煌めくオード（刻印）、交感のキャンディー（刻印） |
| ペット | ペット：放浪商人のルギ |
| 翼 | 春花蝶の翼、紫花蝶の翼、栄光の翼、空虚のターリスラの翼、精霊の翼、楽しさがいっぱいの翼 |
| 外形（防具） | 光の道の痕跡、熟達した専門家（各7部位）。煌めく星の光（イヤリング・ネックレス） |
| 名画 | 「名画：…」シリーズ（アルコンの地下要塞の扉、エルデス神殿、シューゴ錬金術士など19種類） |

すべて「刻印」品で、買ったキャラクターに結びつきます。価格と週の購入上限は、この調査では DB から取得できませんでした。ゲーム内の商店で確認してください。根拠：[S01]

## 魂の結晶

| 項目 | 内容 |
| --- | --- |
| 交換レート | 50 百年人参の証 → 魂の結晶100（月30回まで） |
| 用途 | ペットのジーナス分析（[[pet-genus]]、[[soul-crystals]]） |

根拠：[S04]

> **韓国版のみ**：韓国版の10月7日更新で、魂の結晶が「50個の束、週15束まで」の販売に変わったとされます。グローバル版に適用されたかは未確認なので、ゲーム内の表示を優先してください。

## 使い方のコツ

1. 鍵が上限（12個、会員は21個）に近づく前に遊び、通貨を貯め続けます。
2. まずスティグマの欠片など、能力に直結するものを優先します。外形・翼は後回しです。（[[stigma]]）
3. 百年人参の証はシーズンを越えて持ち越せます。それでもイベントの商品が入れ替わる場合があるので、欲しい品が出たら早めに交換します。
4. スティグマの欠片は、アビス商店・悪夢商店にも並びます。上限が別なので、すべての店で買えます。（[[abyss-points-for-pve]]、[[phantasmal-fragments-nightmare-shop]]）
