誓いのコイン（Oath Coin）は、シーズン中の週間ミッションで貯める**期間限定の通貨**です。DB の説明では「シーズン ミッションおよびシーズンに属するコンテンツのランキング報酬から獲得できるコイン」で、**シーズン商店**で様々なアイテムを買えます。シーズンが終わると削除されるので、「貯めておく」のではなく「期限までに使う」通貨だと覚えてください。（ミッションの内容は [[season-missions]]）

## 要点

| 項目 | 内容 |
| --- | --- |
| 取引 | 個人取引不可 |
| シーズン1の期間 | 2026年9月30日〜12月16日（日次リセット、日本時間16:00） |
| 入手先 | シーズンミッション（クライアント上の入手元は70件、WikiRealm） |
| 順位報酬 | **グローバル版シーズン1では誓いのコインは出ない**（称号と外形のみ） |
| 使い道 | シーズン商店（44品目、WikiRealm） |
| シーズン終了時 | 削除される |

根拠：[S01] [S02] [S04]

> **注意**：DB には「誓いのコイン：シーズン2」「シーズン3」「チャプター1」が別アイテムで登録されています。これは韓国・台湾版で過去に使われた別シーズンのコインです。グローバル版のシーズン1で使うのは、無印の「誓いのコイン」と考えられます。ただし DB の無印コインのミッション表は「シーズン0」と表記されており、シーズン1の実際の報酬量は確認できていません。根拠：[S01]

## ミッションで得られる量（DB の例）

ミッションは段階が上がるほど多くなります。DB の例を示します（魔族向けの表記。「シーズン0」のデータで、数値は変わる可能性があります）。

| ミッション | 段階ごとの誓いのコイン |
| --- | --- |
| ストリート ファイター | 1,250／2,100／3,150／4,700／5,600 |
| 種族戦争 | 1,500／2,100／2,700 |
| 浮遊島をさすらう亡霊 | 1,120／1,570／2,020 |
| 休む暇もない | 1,000／1,400／1,800 |
| 栄光の傷痕 | 560／780 |

根拠：[S01]

これは段階ごとの報酬数で、1週間で全部を取れるわけではありません。ミッションのポイントは毎週水曜にリセットされます。根拠：[S02]

## 使い切るための手順

1. 毎週、シーズンミッションを進めて、高い段階の報酬を取ります。
2. 12月上旬には、商店に並ぶ品目と手持ちを確認します。
3. 消耗品や外形のうち、売り切れの心配がないものは終盤に交換します。
4. 残りのコインは最終週に使い切ります。シーズン終了の日付のメンテナンスで消えます。

> **注意**：持ち越されるのは、アビスポイント、夢幻の破片、百年人参の証です。誓いのコインとディーヴァパス商店コインは持ち越されません。根拠：[S02]
