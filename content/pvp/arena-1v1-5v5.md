闘技場（Arena）は、キューに並ぶと同じ強さ帯の相手と戦える**ランク戦**です。装備もスキルレベルもそのまま持ち込むため、装備が強い人が有利です。均一化された戦いをしたいなら [[arena-of-tactics-10v10]] を選びます。

根拠：[S01] [S02]

## 基本情報

| 項目 | 内容 |
| --- | --- |
| 解放レベル | Lv45（他のPvPと同時） |
| 形式 | 1v1（孤独の闘技場）と5v5（協力の闘技場） |
| ランク | クラスごとに毎シーズン集計 |
| 装備・スキル | **均一化されない**（自分の装備のまま） |
| キュー | ソロのみ（5v5も個人でマッチング） |
| 報酬 | 1戦ごとに300 AP、勝利で500 AP |
| 週の上限 | 参加報酬10回、勝利報酬30回 |
| シーズン報酬 | クラス別の称号（上位1,000位） |

根拠：[S01] [S02] [S04]

> **要確認**：チーム戦の人数は資料で割れています。NCの配信（2026年9月）と Aion 2 Maps は「5v5」、韓国・台湾のローンチと一部のプレビュー記事は「4v4」と書いています。パーティが5人になった仕様変更と対応するため5v5を採用していますが、ゲーム内の表示を確認してください。

根拠：[S01] [S02]

## 1v1のルール

- 先に3ラウンドを取った方が勝ち。
- ラウンドの間に体力は**回復しない**。次のラウンドは前のラウンドの終了時の体力で始まるため、いったん離れて回復する、隠れるといった駆け引きが起きる。
- 韓国サーバーの報告では、タンク系・近接系のクラスが多く使われる傾向がある。

根拠：[S02]

## 5v5のポイント

- 広いマップで、ペット（騎乗）で移動できる。
- 回復役を最優先で倒す、火力役を狙う、タンクに集中するなど、チームの連携が勝敗を分ける。
- 無敵系のスキルは勝敗を左右する。ただし韓国版のクラス調整（2026年3月）で、イミューン・イモータルの効果は30秒以内に連続で付与できなくなった。
- 全員揃ったフルチームでキューに入れるという記述と、ソロのみとする記述があります。グローバル版はソロでのマッチングが基本です。

根拠：[S02] [S01]

## 報酬の取り方

- 参加300 APと勝利500 APは、週の上限（参加10回・勝利30回）まで。上限を超えると報酬は入りません。上限に達したら他のコンテンツへ移るのが効率的です。
- アビスポイントの使い道は [[abyss-points-and-shop]]。
- 闘技場のランクはクラスごとの称号が出るだけで、**ランクバフはありません**。バフが付くのはアビスランクだけです（[[abyss-rank-and-season]]）。

根拠：[S01]

## 戦い方の基本

- 状態異常の解除（「抵抗」スキル）の使い方が勝敗を左右します。詳しくは [[status-effects-and-cc]]。
- PvP用の装備ライン・ステータスは [[pvp-stats-and-gear]]。
- PvPでは回復量が20〜30%減るという記述があります（資料間で差があり、要確認）。

根拠：[S01] [S03]

## 韓国版のみ

> **韓国版のみ**：韓国・台湾の初期（2025年11月）の闘技場は1v1と4v4で、装備差による不均衡（クラス間バランス）への不満が多く出ました。以降の調整は韓国・台湾サーバーのもので、グローバル版にそのまま当てはまるとは限りません。

根拠：[S02]
