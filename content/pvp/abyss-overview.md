アビス（The Abyss / エレシュランタ）は、別サーバーで暮らす天族と魔族が直接出会う、常時 PvP のフィールドです。グローバル版では **Lv45 かつ合計 IL（アイテムレベル）1,000** で「混沌のエレシュランタ下層」に入れます。PvP が目的の場所に見えますが、Lv45 の覚醒クエストやストーリー報酬の金ガーダー、PvE でも必要な「スティグマの欠片」の入手先でもあるため、PvE 専門でも一度は行く価値があります。

根拠：[S01] [S02] [S03]

## 入場条件と基本ルール

| 項目 | グローバル版 |
| --- | --- |
| キャラクターレベル | Lv45 |
| 合計IL | 1,000 以上 |
| 開放されている層 | 混沌のエレシュランタ下層のみ（同時入場 最大1,500人） |
| PvP | 常時オン。PvEモードにしていても攻撃される |
| 滞在時間 | **週7時間**。水曜の週間リセットで7時間に戻る（繰り越しなし） |
| メンバーシップ | 滞在時間の追加特典は **なし** |
| 対戦相手 | 自サーバーとペアになった相手陣営サーバー |

「Lv45 なのに入れない」場合は、まず合計 IL が 1,000 に届いているか確認してください。レベル条件と IL 条件は別です。

根拠：[S01] [S02] [S03] [S05]

> **韓国版のみ**：韓国・台湾版では中層・表層も開放され、層ごとに週7時間、旧情報では会員は週14時間という説明もあります。グローバル版は下層のみ・週7時間・会員特典なしです。古い海外情報をそのまま当てはめないでください。

根拠：[S02] [S03] [S07]

## 行き方

1. 天族はベルテロン「幻想神の庭」東展望台の像のそば、魔族はアルトガルド「黒爪村」インペトゥシウム下の道の像のそばにある **アビスポータル** に話しかける。
2. 「帰還の巻物（刻印）」1枚を消費して、自陣営のアビス拠点へ移動する。
3. 初回は拠点のシューゴ商人 **コロ（Koro）** にメインクエスト「ドラウプニル」（天族）／「忘れられた指揮官」（魔族）を提出する。報酬の **魂魄のガーダー（唯一）** を受け取り、Lv45 の覚醒クエストと地域クエストの最後の分が開放される。

根拠：[S01] [S03]

## アビスで何をするか

初めて入ったら、敵プレイヤーを探す必要はありません。基本の流れは次のとおりです。

1. 「指令（Commands）」やシーズンミッションで、今進められる目標を確認する。
2. 目標のモンスターがいる場所へ移動し、まとめて討伐する。
3. アビスポイントを回収し、アビス商店で必要な品（まずスティグマの欠片）と交換する。
4. 余裕があれば、[[artifact-siege]]（占領戦）や [[abyss-field-bosses]]（定時ボス）に陣営の集団として参加する。
5. 下層の「神の痕跡」200個を集めて [[abyss-monolith]] に共鳴させる（初回は約90分の目安）。

根拠：[S02] [S03]

## 週の予定（サーバー時間）

| コンテンツ | タイミング |
| --- | --- |
| アーティファクト占領戦 | 月・木・土 21:00 準備開始、21:10 戦闘開始 |
| 執行者タマサ／アルゴ／カイラ（ボス） | 月・木・土 21:30（占領戦の後） |
| 守護領主ナフマ（ボス） | 金・日 21:00、3か所 |
| 監視者カイラ（ボス） | 01:00 から3時間ごと |
| アビス回廊 | 占領戦後、自陣営が保持するアーティファクトごとに次の占領戦まで |
| 時空の亀裂 | 02:00 から3時間ごと、ポータルは10分間 |

> **注意**：これらはゲームクライアントの解析値で、NC が地域別の時刻表を公開しているわけではありません。地域によって1時間以上ずれるという報告があるため、ゲーム内の 3D マップのタイマーや通知で確認してください。

根拠：[S01] [S03] [S04]

## アビス回廊（Abyss Corridor）

占領戦の後、自陣営が確保したアーティファクトごとに「アビス回廊」の入口が次の占領戦まで開きます。IL1,000 で入れるソロの短時間インスタンス（5分）で、周囲に湧くモンスターを倒してアビスポイントを稼ぎます。入れるかどうかはアーティファクト画面で確認できます。

根拠：[S01] [S03] [S06]

## PvPを避けながら進めるコツ

- 入る前に目的（指令・ミッション）を決めておき、滞在時間を移動で浪費しない。
- 敵陣営の集団がいる場所に PvE 装備で単独で近づかない。
- 味方が多い場所で行動する。大型イベントも集団について行く。
- 攻撃されても毎回戦う必要はない。目的が討伐なら離脱を優先してよい。
- 倒されてもアビスポイント・経験値・アイテムは失わない。ただしプレイヤーに倒された場合、復活の精霊石でその場復活はできない（韓国公式ガイドブック準拠の説明）。

根拠：[S02] [S06]

## 装備とランク

アビス装備のセット効果はアビスランクに応じて伸び、ランク報酬の「アビスランクバフ」はグローバル版で唯一のランキングバフです（最高階級で PvP ダメージ +5%、PvP 被ダメージ −5%、アビス内ダメージ +5%）。詳細は [[abyss-rank-and-season]] と [[pvp-stats-and-gear]] を参照してください。

根拠：[S01]
